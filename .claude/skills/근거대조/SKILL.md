# 근거 대조

## 어느 지침을 쓰는가
- voice `문헌`, `종합` 카드: `_작업/카드 검증 지침.md`
- voice `영진` 카드: `_작업/영진 카드 근거 대조 지침.md`

요약하지 말고 해당 지침을 **전부** 읽은 뒤 작업합니다.

## 대량 실행 순서
1. `py -3 _작업/스크립트/lint.py`를 먼저 돌립니다. 오류(E)가 있는 카드는 검증으로 보내지 않고 먼저 고칩니다.
2. 대상 카드를 30~50장씩 나눠 검증자 에이전트(`.claude/agents/검증자.md`)에 맡깁니다. 동시 실행은 10개로 시작합니다. 지시에는 카드 번호 목록과 이 스킬의 해당 지침 경로만 줍니다.
3. 결과는 `_작업/검증/판정/<id>.json`에 쌓입니다. 검증자가 카드를 고치지 않았는지 `git status 영구/`로 확인합니다. 바뀐 카드가 있으면 되돌리고 보고합니다.
4. `py -3 _작업/스크립트/verify_apply.py .`로 판정을 카드 frontmatter에 반영합니다(1단계에서 구현).

## 지키는 선
- 검증자는 판정만 씁니다. 카드 내용 수정은 영진 님이 대기열에서 정합니다.
- status가 `검토됨`이나 `다시씀`인 카드도 판정은 하되, frontmatter 반영은 `verify_apply.py`가 결정합니다.
