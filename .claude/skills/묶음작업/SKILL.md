# 묶음 작업(수집)

요약하지 말고 아래 문서를 **전부** 읽은 뒤 작업합니다.

1. `CLAUDE.md`의 '수집' 절
2. `_작업/그룹 작업 지침.md`: 문헌 노트, 영구 노트, 구조 초안 형식
3. `_작업/Notion 묶음 작업 지침.md`: Notion 묶음의 표준 순서, 중복 방지, 건드리지 않을 것
4. `카드작성` 스킬

## 이 PC에서의 차이
- 지침의 `/home/user/nukuriring`는 보관함 루트(현재 작업 폴더)로 읽습니다.
- `python3`는 `py -3`로 바꿔 씁니다.

## 변환 전후로 하는 일
- 변환 전: 같은 주제의 기존 카드를 `ids.py`와 구조 노트로 확인합니다. 3단계 이후에는 `dupes.py`로 겹침을 먼저 거릅니다.
- 변환 후: `py -3 _작업/스크립트/lint.py --file <새 카드들>`로 점검하고, 검증자 에이전트로 새 카드를 검증합니다.
- 마지막에 `마무리` 스킬을 돌립니다.

## 작업자를 병렬로 돌릴 때
- 변환자 에이전트(`.claude/agents/변환자.md`)를 씁니다. 동시 실행은 10개로 시작합니다.
- 작업자마다 최상위 번호(또는 둘째 자리 알파벳 범위)를 따로 배정하고, 임시 파일은 `_작업/임시/<작업자 이름>/`에만 두게 합니다.
- 작업자는 `struct.py`, 번호표, `로그.md`, `진행 기록.md`, `01 색인.md`, `구조/`를 건드리지 않습니다. 이 파일들은 모든 작업자가 끝난 뒤 `마무리`가 한 번 갱신합니다.
