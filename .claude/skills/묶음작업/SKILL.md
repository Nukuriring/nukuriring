# 묶음 작업(수집)

요약하지 말고 아래 문서를 **전부** 읽은 뒤 작업합니다.

1. `CLAUDE.md`의 '수집' 절
2. `_작업/그룹 작업 지침.md`: 문헌 노트, 영구 노트, 구조 초안 형식
3. `_작업/Notion 묶음 작업 지침.md`: Notion 묶음의 표준 순서, 중복 방지, 건드리지 않을 것
4. `카드작성` 스킬

## 이 PC에서의 차이
- 지침의 `/home/user/nukuriring`는 보관함 루트(현재 작업 폴더)로 읽습니다.
- 파이썬 명령은 PC에서 `py -3`(임베딩·검색 시험은 `py -3.12`), 클라우드에서 `python3`이다.

## 변환 전후로 하는 일 (2026-10-13 운영 절차)
1. **넣기**: 새 자료 사본을 `_원자료/`의 알맞은 곳(claude.ai 대화는 `claude.ai/chats/`, 노트는 `로컬/`, Notion은 `notion/`)에 둔다.
2. **겹침 먼저**: 자료의 핵심 주장 3~5개로 `search.py`를 돌려 이미 있는 카드를 확인한다. 같은 주장이 있으면 새 카드를 만들지 않고 기존 카드의 출처 절에 더하거나 연결만 건다.
3. **변환**: 문헌 노트와 카드를 만든다(변환자 에이전트 또는 직접). 새 최상위 번호는 `_작업/번호표.md` 다음 번호.
4. **검증**: 새 카드를 검증자 에이전트로 판정하고(`verify_split.py` → `verify_apply.py`), 영진 voice 카드는 근거 대조 지침으로 본다.
5. **연결**: 새 카드마다 `search.py --like <id>`로 다른 클러스터 이웃을 보고 연결을 1~3개 건다. 임베딩이 낡았으면 PC에서 `embed.py`를 먼저 돌린다(바뀐 카드만 다시 계산).
6. **구조**: 새 줄기는 구조 노트 원본(`_작업/구조작성/`)에 넣고 렌더링한다. 색인 조각을 더한다.
7. 마지막에 `마무리` 스킬을 돌린다.

## 작업자를 병렬로 돌릴 때
- 변환자 에이전트(`.claude/agents/변환자.md`)를 씁니다. 동시 실행은 10개로 시작합니다.
- 작업자마다 최상위 번호(또는 둘째 자리 알파벳 범위)를 따로 배정하고, 임시 파일은 `_작업/임시/<작업자 이름>/`에만 두게 합니다.
- 작업자는 `struct.py`, 번호표, `로그.md`, `진행 기록.md`, `01 색인.md`, `구조/`를 건드리지 않습니다. 이 파일들은 모든 작업자가 끝난 뒤 `마무리`가 한 번 갱신합니다.
