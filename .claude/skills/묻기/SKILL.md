# 묻기 (보관함에 질문하기)

CLAUDE.md '질의' 절의 실행판이다. 위키 밖 지식으로 바로 답하지 않고, 먼저 보관함에서 찾는다.

## 1. 찾기
1. 질문의 핵심어로 `01 색인.md`와 해당 클러스터 개요(`구조/<클러스터>.md`)를 본다. 개요의 '다른 클러스터로 가는 길' 절은 영역을 넘는 질문의 출발점이다.
2. `찾기` 스킬의 `search.py`를 돌린다(PC `py -3.12 -P`, 클라우드 `python3 -P`). 질문 문장을 그대로 넣고, 원어를 아는 개념이면 원어를 덧붙인다. 상위 10장의 제목을 보고 고른다.
3. 고른 카드의 `## 연결` 절을 따라 한두 걸음 더 간다. `(반론)`, `(대조)`, `(유비)` 줄은 반론·비교 질문에서 먼저 본다.
4. 카드만으로 부족하면 문헌 노트와 `## 출처`의 원자료를 확인한다.

## 2. 답하기
- 근거 카드는 `[[파일명]]` 링크로 단다. 카드 번호만 쓰지 않는다.
- 저자의 주장(voice 문헌), 영진 님의 입장(voice 영진), Claude가 엮은 해석(voice 종합)을 문장마다 구분한다. 예: "코디는 …라고 본다[[…]]. 영진 님은 …라고 정리했다[[…]]. 두 카드를 엮으면 …라고 읽을 수 있다(종합)."
- 카드의 `verify`가 `부분`·`원문없음`·`모순`이면 그 사실을 밝힌다.
- 보관함에 없는 내용을 보탤 때는 '위키 밖 지식'이라고 밝힌다.
- 지문 소재를 묻는 질문이면 끝에 '소재로 쓸 때'를 두어, 대립 구도(누가 무엇에 반대하는가), 빠진 고리(보관함에 없는 쪽 입장), 원문 확인이 필요한 카드를 짧게 적는다.

## 3. 남기기
- 다시 볼 만한 답이면 `질문/YYYY-MM-DD 질문 요지.md`로 저장한다. frontmatter는 `type: 질문`, `created`, `cards: [번호, …]`. 본문은 질문, 답, 근거 카드 링크다.
- 답에서 새 연결이나 새 주장이 생겼으면 종합 카드 후보로 제안만 하고, 영진 님이 좋다고 하면 `카드작성` 스킬로 만든다.
- `_작업/로그.md`에 `- YYYY-MM-DD 질의: 질문 요지`를 덧붙인다.
