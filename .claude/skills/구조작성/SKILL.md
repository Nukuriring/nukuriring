# 구조 노트 작성

요약하지 말고 `_작업/구조작성 지침.md`를 **전부** 읽은 뒤 작업합니다. 완성된 예시는 `구조/지각의 철학.md`입니다.

## 이 PC에서의 차이
- 지침 §1의 '이 보관함에는 원자료가 없습니다'는 클라우드 사본 이야기입니다. 이 PC에는 `_원자료/`가 있으므로 원자료 링크가 열립니다. 그래도 구조 노트는 카드 제목과 구조초안을 근거로 짜고, 원자료는 판단이 어려울 때만 봅니다.
- `python3`는 `py -3`로 바꿔 씁니다.

## 원본과 렌더링
- 구조 노트는 `_작업/구조작성/<이름>.md`(원본, `{번호}` 자리표시자)를 고치고 `py -3 _작업/스크립트/render_hub.py . _작업/구조작성/<이름>.md`로 `구조/`에 렌더링합니다. `구조/`를 직접 고치면 다음 렌더링 때 덮어써집니다.
- 모든 구조 노트는 `_작업/구조작성/`에 원본이 있습니다. 원본이 없던 개요 다섯 개(`정치·사회·역사·법`, `자기지식과 투명성`, `윤리와 가치`, `행위와 실천이성`, `지각의 철학`)는 2026-10-13에 `구조/`의 파일을 거꾸로 변환해 원본을 만들었습니다. `구조/`를 직접 고치지 말고 원본을 고친 뒤 렌더링합니다.
- 구조 노트는 영진 님의 논증 설계가 들어가는 층입니다. 에이전트가 고친 구조 노트는 `status: 초안`을 유지합니다.
