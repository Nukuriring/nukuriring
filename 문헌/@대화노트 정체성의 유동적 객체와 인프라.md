# 정체성의 유동적 객체와 인프라 대화 노트

> 서지 확인 메모: 대화형 AI의 응답을 옮긴 노트가 많아 정확성이 보증되지 않는다. 카드는 노트가 이렇게 정리한다는 형태로 쓰고 voice를 종합으로 두었다. 외부 문헌의 내용은 원문 확인이 필요하다.

## 한 줄 요지
노트는 몰과 드 라에트의 유동적 객체, 이엔니옹의 애착, 마레의 쟁점 공중, 스타와 루들러의 인프라 특성을 모아 정체성이 인프라처럼 작동하고 고장 나면 우려 그룹이 수리를 요구한다는 모델을 정리한다.

## 문제 설정
- 정체성이 무엇을 하는가를 기능 중심으로 묻고, 정체성의 고장과 수리를 인프라 연구의 틀로 설명할 수 있는가.

## 논증 구조
1. 유동적 객체와 분명치 않은 고장을 정리하고 마비노기의 예를 든다.
2. 애착과 우려와 공중 형성의 경로를 여섯 단계로 정리한다.
3. 정체성의 개인적, 사회적 기능을 나열하고 콩의 세 국면에 대응시킨다.
4. 인프라의 일곱 특성을 정체성에 적용하고 우려 그룹의 수리 단계를 설명한다.
5. 억압 인프라를 음의 기능으로 읽는 답변과 해석적-인프라적 통합을 제시한다.
6. 통합 테제와 네 반론을 정리한다.

## 핵심 개념
- 분명치 않은 고장(ambiguous breakdown): 명시적 오류 없이 불편이 쌓이는 상태.
- 애착(attachment)과 사회존재론적 연합: 대상과 맺은 감정적 관계.
- 우려 그룹(concern group): 인프라 고장을 계기로 모이는 집단.
- 인프라 일곱 특성: 내재성, 투명성, 도달 범위, 학습과 상속, 표준화, 고장 시 가시화, 정치성.

## 영진의 독해 메모
- 노트에 영진의 평가는 거의 없다. 생성형 대화의 산물이므로 보조 자료로만 쓴다.
