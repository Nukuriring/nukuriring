# 사회철학연습 Response 0429: 정체성의 고장-수리 모델

> 서지 확인 메모: 영진의 수업 응답 글이다. 콩의 정체성 논문을 읽고 쓴 글이며, 고장과 수리와 우려의 어휘로 정체성을 다시 읽는다. 쪽수 개념은 없다.

## 한 줄 요지
영진은 콩이 말한 정체성의 통치와 생존과 저항이라는 세 겹의 기능을 고장과 수리와 우려의 어휘로 옮긴다. 억압 구조를 곳곳이 낡은 설비로 보고, 정체성을 서로 다른 고장을 호소하는 우려의 플랫폼으로 읽는다.

## 문제 설정
- 정체성이 억압의 도구이면서 저항의 근거일 때, 정체성을 어떤 기준으로 평가하고 어떻게 연대의 바탕으로 쓸 수 있는가.

## 논증 구조
1. 콩의 논문에서 정체성의 삼중 구조를 읽는다.
2. 억압 구조를 곳곳이 낡은 거대한 설비로 보고, 정체성을 고장 사례를 호소하는 우려의 플랫폼으로 읽는다.
3. 고장-수리 모델의 장점을 정상과 고장의 연속선, 공유된 우려의 가시화, 부분 수리의 누적으로 든다.
4. 동원 전략으로 고장 지도와 임시 수리의 구조적 연결과 우려 공유의 연대 언어를 제안한다.
5. 정체성의 정상 작동과 비정상 작동을 기능 수준에서 가르는 기준을 세운다.
6. 정체성의 살아짐을 타자기가 삶에 통합되듯 장치가 현상학적 경험이 되는 일로 설명한다.

## 핵심 개념
- 고장(breakdown)과 수리(repair): 정체성 장치의 기능 정지와 복구.
- 우려(concern): 같은 고장을 겪는 이들이 공유하는 관심.
- 우려의 플랫폼: 서로 다른 고장을 호소하는 사람들이 모이는 자리.
