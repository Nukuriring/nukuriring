# 컴퓨터활용능력 컴퓨터 일반 필기

## 서지 확인 메모
- 교재 서지가 필기에 없다. 확인 필요.
- 유니코드는 필기가 '65356가지'로 적었으나 2의 16제곱인 65,536으로 고쳐 적었다.
- 플래시 메모리를 필기는 '휘발성 메모리'라고 적었으나 같은 항목의 EEPROM 설명과 어긋나 비휘발성으로 고쳐 적었다. 확인 필요.
- 반이중의 예 '부전기'는 무전기로 읽었다.
- '웹브라우저', '공격 방식', '프린터설치'는 표제만 있어 카드로 만들지 않았다.
- 유틸리티 프로그램, 정보통신 서비스(USENET, IRC, ARCHIE, Gopher), 정보통신 기술 용어(VoIP, 와이브로, 블루투스, 테더링, RFID, 임베디드, 유비쿼터스, USN, IoT), 기타 용어(미러사이트, 포털사이트, 워터마크)는 용어 나열이어서 카드로 만들지 않았다.
- 필기에 철자 오류와 줄임 표현이 있어 카드에서는 바로잡아 적었다.

## 한 줄 요지
CPU와 기억 장치, 문자 코드, 네트워크 주소와 프로토콜, 멀티미디어 데이터, 정보통신 보안, 프로그래밍 언어를 항목별로 정리한 컴퓨터 일반 필기이다.

## 문제 설정
컴퓨터 일반 지식을 하드웨어, 데이터 표현, 네트워크, 보안, 소프트웨어의 항목별로 모아 정리한다.

## 논증 구조
1. 학습 필요 개념 목록: 누산기와 레지스터, 기억 장치 접근 속도, 유니코드, 플래시 메모리, 유틸리티 프로그램, 클립보드, 웹브라우저, 공격 방식, 프린터설치, IPv6.
2. 멀티미디어: 특징, 그래픽 기법, 이미지, 오디오, 동영상 데이터.
3. 정보통신: 통신 방향과 망 구성 형태, 규모에 따른 분류, 장비와 프로토콜, IP 주소와 도메인, OSI 7계층, 명령어, 서비스, 기술.
4. 정보통신 보안: 위협 용어, 위협 유형, 프록시 서버, 암호화 기법.
5. 프로그래밍 언어: 번역기, 객체 지향 언어, 클라이언트와 서버, 웹 프로그래밍 언어.

## 핵심 개념
- 레지스터와 누산기
- IP 주소와 DNS
- 프로토콜
- OSI 7계층
- 대칭키와 공개키

## 영진의 독해 메모
필기에 영진 본인의 독자적 주장은 없다. 'USN: 여러개 다 짬뽕' 같은 메모는 영진의 기억용 표현으로 보이나 카드로 옮기지 않았다.

## 파생 영구 노트
- [[69h 레지스터는 CPU가 처리할 명령어와 결과값을 임시 저장하며 누산기는 연산 결과를 저장한다]]
- [[69h1 기억 장치의 접근 속도는 레지스터, 캐시, 램, 롬, SSD, HDD, 광디스크 순으로 느려진다]]
- [[69h2 플래시 메모리는 EEPROM의 일종이며 전원이 꺼져도 정보를 유지하고 블록 단위로 저장한다]]
- [[69h3 문자 코드는 비트 수에 따라 BCD 64자, ASCII 128자, EBCDIC 256자, 유니코드 65,536자를 표현한다]]
- [[69h4 IPv4는 32비트 주소이고 IPv6는 주소 부족을 해결하려고 128비트로 늘렸다]]
- [[69h5 도메인은 IP 주소를 문자로 나타낸 주소이고 DNS가 문자 도메인을 숫자 IP로 변환한다]]
- [[69h6 멀티미디어는 통합성, 대용량성, 양방향성, 디지털성, 비선형 구조를 특징으로 한다]]
- [[69h7 그래픽 기법은 디더링, 모델링, 렌더링, 안티앨리어싱, 모핑 등 처리 목적에 따라 구별된다]]
- [[69h8 비트맵 이미지는 픽셀로 표현해 계단 현상이 생기고 벡터 이미지는 수식으로 계산해 계단 현상이 없다]]
- [[69h9 오디오 데이터는 샘플링 간격이 좁을수록 원음에 가깝고 파일 크기는 샘플링 값을 곱해 계산한다]]
- [[69h10 동영상 데이터는 코덱으로 신호를 변환하고 스트리밍으로 재생하며 MPEG 규격이 용도별로 나뉜다]]
- [[69h11 통신은 방향에 따라 단방향, 반이중, 전이중으로 나뉜다]]
- [[69h12 망 구성 형태는 성형, 버스형, 링형, 트리형, 망형이 있고 장애 영향과 확장성이 서로 다르다]]
- [[69h13 통신망은 규모에 따라 LAN, MAN, WAN으로 나뉘고 이용 범위에 따라 인트라넷과 엑스트라넷 등이 있다]]
- [[69h14 통신 장비는 연결 범위에 따라 구분되고 OSI 7계층의 계층에 대응한다]]
- [[69h15 프로토콜은 무엇을 어떻게 언제 통신할지 정한 규약이며 흐름 제어, 동기화, 오류 제어를 맡는다]]
- [[69h16 FTP, SMTP, POP3, IMAP, MIME, HTTP, TELNET은 파일 전송, 전자우편, 웹, 원격 접속을 맡는다]]
- [[69h17 IPCONFIG, NSLOOKUP, TRACERT, PING, FINGER, NETSTAT는 연결 상태와 주소를 확인하는 명령어이다]]
- [[69h18 해킹, 크래킹, 웜, 트로이목마, 백도어, 스니핑, 스푸핑, 피싱, 키로거, DDoS는 침입 방식과 목적으로 구별된다]]
- [[69h19 정보보안 위협은 가로막기, 가로채기, 변조, 위조 네 유형으로 나뉜다]]
- [[69h20 프록시 서버는 방화벽과 캐시 기능을 하며 방화벽은 첨부파일과 내부의 위험에는 대처하지 못한다]]
- [[69h21 대칭키 방식은 단순하고 빠르지만 키 관리가 어렵고 비대칭키 방식은 복잡하고 느리지만 키 분배가 쉽다]]
- [[69h22 컴파일러는 소스를 한 번에 번역해 실행이 빠르고 인터프리터는 한 줄씩 번역해 번역이 빠르다]]
- [[69h23 객체 지향 언어는 절차형 언어의 문제를 해결하며 추상화, 캡슐화, 상속성, 다형성을 특징으로 한다]]
- [[69h24 서버는 정보를 제공하고 클라이언트는 제공받으며 둘 다 처리 능력을 가져 분산 처리에 적합하다]]
- [[69h25 클립보드는 데이터를 일시적으로 보관하는 임시 저장 공간이며 가장 최근 항목 하나만 기억한다]]
