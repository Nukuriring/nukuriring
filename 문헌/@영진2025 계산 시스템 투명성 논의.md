# 계산 시스템 투명성 논의

> 서지 확인 메모: 글의 앞부분은 계산 시스템 투명성 논의의 문헌 지형을 정리하고, 중간은 크릴의 논증을 소개하고, 뒷부분은 영진 님의 질문과 논증이다. 인용된 문헌의 목록은 글 말미에 있으나 일부 항목만 실려 있다. 지형 정리는 문헌 카드로, 질문과 논증은 영진 카드로 옮겼다.

## 한 줄 요지
크릴이 세 투명성 범주를 서로 독립적이라고 본 데 대해, 영진은 정상 작동이 기능으로 규정되므로 실행 불투명성의 요점이 기능적 투명성에 의존하며 알고리즘 지식이 구조 지식과 실행 지식에 선행한다고 논한다.

## 문제 설정
- 계산 시스템의 (불)투명성을 이해한다는 것의 개념적 본질은 무엇이며, 크릴의 세 범주는 정말 독립적인가.

## 논증 구조
1. 투명성 논의의 세 지형: 법적-윤리적 논의, 불투명성의 원인, 개념적-철학적 이해.
2. 크릴의 세 범주와 실행 투명성의 존재 논증 두 가지(@Creel2020 노트).
3. 질문 지점: 정상 작동 중에는 실행 불투명성이 요점이 없고, 요점은 오작동에서 생긴다. 그런데 정상 작동은 기능으로 규정된다.
4. 논증: P1 알고리즘 지식의 선행성, P2 구조 지식의 의존성, P3 실행 지식의 판단 의존성, P4 알고리즘 불투명성의 의미. 결론은 세 범주가 위계적이고 상호 의존적일 가능성이다.
5. 진단: 알고리즘 지식은 시스템의 정체와 목적에 대한 목적론적 이해를 준다(물음표가 붙은 진단).

## 핵심 개념
- 알고리즘 투명성(기능적 투명성), 구조적 투명성, 실행 투명성, 정상 작동, 아티팩트, 목적론적 이해

## 영진의 독해 메모
- 이 노트의 논증 3에서 5가 영진 님의 주장이다(「계산 시스템 투명성 논의」 후반, 2025-06-19).

- [[41q1 크릴은 복잡한 계산 시스템의 투명성을 알고리즘 투명성과 구조적 투명성과 실행 투명성의 세 종류 지식으로 나눈다]]
