# Could a Machine Think?

> 서지 확인 메모: 아주 짧은 필기여서 마지막 항목이 끊겨 있다. 필기에 적힌 내용만 옮겼다.

## 한 줄 요지
필기는 기호 조작 기계가 생각할 수 있는가라는 물음에서 시작해, 설의 중국어 방 논증이 논점을 선취한다는 지적과, 고전 AI로는 의식 있는 지능을 만들 수 없다는 처칠랜드의 입장을 적는다.

## 문제 설정
- 기호 조작(SM) 기계는 생각할 수 있는가.

## 논증 구조
1. 효과적으로 계산 가능한 함수는 모두 재귀적으로 계산 가능하다.
2. 설의 중국어 방 논증: 구문론과 기호 조작만으로는 이해(지향성)를 재현하기에 부족하다.
3. 이 전제는 구문론만으로 의식 있는 지능을 만들 수 있다는 고전 AI의 가정에 대해 논점을 선취한다.
4. 고전 AI는 실제 성능에서 실패했고, 뇌에서 영감을 얻은 계산 모델을 보면 고전 AI는 애초에 의식을 낳을 수 없는 구조이다.

## 핵심 개념
- 기호 조작 기계, 중국어 방 논증, 고전 AI, 논점 선취

## 영진의 독해 메모
- 영진 님의 질문이나 해석은 필기에 들어 있지 않다.
