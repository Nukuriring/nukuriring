# Understanding from Machine Learning Models

> 서지 확인 메모: 영진 님의 논문은 설리반이 기계 학습 모델로부터 얻는 이해의 본성을 탐구하고 딥러닝 모델이 과학적 설명을 제공할 가능성을 논의한다고만 적는다. 설리반의 주장 내용은 원자료에 없으므로 원문으로 확인해야 한다.

## 한 줄 요지
설리반은 기계 학습 모델에서 얻는 이해의 본성을 탐구하며 딥러닝 모델이 과학적 설명을 제공할 가능성을 논의한다.

## 문제 설정
- 딥러닝 모델은 이해나 앎을 생산하거나 세계에 대한 설명 가능한 모델을 제공할 수 있는가.

## 논증 구조
1. 원자료에는 논증 단계가 적혀 있지 않다. 영진 님의 논문은 설리반을 보게와 비슷한 문제를 다루는 인식론적 갈래의 예로 소개한다.

## 핵심 개념
- 기계 학습 모델로부터의 이해, 과학적 설명

## 영진의 독해 메모
- 영진 님의 논문에는 설리반에 대한 독해 메모가 없고 인식론적 갈래의 예로만 인용된다.
