# 67r DCNN이 인간보다 훨씬 많은 데이터를 요구한다는 점은 두 학습이 다른 메커니즘이라는 논거로 쓰인다

DCNN이 인간이나 동물과 같은 학습 메커니즘을 구현하는지 묻는 논의에서 한 논거는 DCNN이 인간보다 훨씬 많은 학습 데이터를 요구한다는 점이다. 성공한 DCNN은 대개 수백만 개 규모의 데이터로 훈련해야 인간과 비슷한 성능에 이르고, 이미지 분류 DCNN은 1,400만 장의 이미지가 든 ImageNet으로 학습한다. AlphaGo의 신경망은 16만 개의 인간 대국 데이터를 학습한 뒤 1억 회 이상의 자기 대국을 해야 최상위 성능에 이르렀다. 반면 유아는 몇 번의 노출만으로 새로운 물체나 단어를 배우고, 인간 바둑 고수 이세돌이 평생 둔 대국은 5만 판 이하이다. 발제문은 이 대비가 DCNN이 인간과 같은 학습 메커니즘을 쓴다고 보기 어렵게 한다고 정리한다. DCNN이 인간처럼 범주를 추론하고 일반화할 수 있다고 해도 데이터를 근본적으로 다른 방식으로 처리하고 있을 가능성이 높다.
