# 69h25 클립보드는 데이터를 일시적으로 보관하는 임시 저장 공간이며 가장 최근 항목 하나만 기억한다

클립보드는 데이터를 일시적으로 보관해 두는 임시 저장 공간이다. 클립보드의 내용은 여러 번 사용할 수 있지만 가장 최근에 저장된 것 하나만 기억한다. 시스템을 다시 시작하면 클립보드에 저장된 데이터는 사라진다.

- 상위: [[69h 레지스터는 CPU가 처리할 명령어와 결과값을 임시 저장하며 누산기는 연산 결과를 저장한다]]
- [[69h 레지스터는 CPU가 처리할 명령어와 결과값을 임시 저장하며 누산기는 연산 결과를 저장한다]]: 임시 기억 장소라는 점에서 레지스터와 대비해 볼 수 있다.
