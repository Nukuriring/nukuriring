# 51e1b 바르트에게 텍스트는 인용이 모이는 다층의 공간이고 단일성은 기원에 놓이지 않고 독자라는 목적지에 놓인다

현대적 서기는 텍스트와 동시에 태어나며 글쓰기 이전이나 이후에 존재하지 않는다. 글쓰기가 지시하는 것은 언어 자체의 수행이며 글쓰기의 움직임이 곧 내용이다. 텍스트는 하나의 신학적 의미를 내놓는 단어의 나열로 읽히지 않고 기원 없는 여러 글쓰기가 섞이는 다층의 공간이고, 글 쓰는 사람이 할 수 있는 일은 여러 구절을 맞세우고 충돌시키고 혼합하는 것뿐이고 창조는 그의 몫이 되지 못한다. 저자를 부여하는 일은 텍스트에 한계를 부여하는 일이므로 비평의 역할은 해독에 머물지 않고 얽힌 것을 풀어 보여 주는 반신학적 활동이 된다. 텍스트의 다양성은 독자라는 장소에 모이고, 독자의 탄생은 저자의 죽음을 대가로 치러야 한다.
