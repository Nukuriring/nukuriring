# 51g3d 전통적 다중 호문클루스 논증은 뇌를 담지자만 다루는 통사론적 기계로 만들어 지각 경험을 회고적 보고로 환원한다

데란다는 자신의 모델이 전통적 다중 호문클루스 구조 논증과 다르다고 주장한다. 전통적 논증은 표시의 담지자적 속성이 내용적 속성을 결정하지 않는다는 전제와, 뇌는 담지자하고만 관계하고 현상적 경험은 내용하고만 관계한다는 전제를 함께 취한다. 첫째는 참이지만 둘째는 거짓이라는 것이 데란다의 진단이다. 두 전제를 모두 받아들이면 뇌가 다루는 내용과 현상적 내용이 분리되어 일상의 지각 경험이 모두 회고적 보고에 불과해진다. 데란다의 모델은 각 인식 행위자가 담지자와 내용 각각에 상호작용하도록 허용하므로 이 문제를 갖지 않는다.
