# 3g 맥도웰은 전인격적 정보 처리가 동물에게 아무것도 말해 주지 않는다고 본다

맥도웰(John McDowell)은 1994년 논문에서, 데닛(Daniel Dennett)이 인격 수준의 내용 파악을 전인격적(sub-personal) 정보 처리 체계가 만든 내용에 접근하는 일로 설명한다고 정리한다. 이 그림을 개구리에 적용하면 개구리는 자기 내부의 정보 교환에 접근하여 환경을 아는 셈이 되지만, 개구리는 지각에서 주변 환경을 향하고 얻는 정보도 사물에 관한 정보이다. 맥도웰에 따르면 정보 처리 체계는 물리적 영향을 처리 가능한 정보로 바꾸는 통사론적 엔진(syntactic engine)이고, 환경에 능숙하게 적응하는 동물은 의미론적 엔진(semantic engine)이다. 처리 결과를 내용인 것처럼 해석하는 '마치' 내용 부여(as-if content)로는 진정한 내용이 구성되지 않으므로, 정보 처리 기관은 동물에게 아무것도 말해 주지 않는다. 감각은 주체가 환경에 열려 있는(openness) 양상이다. 맥도웰은 이 주장이 인지과학을 위협하지 않는다고 덧붙인다: 정보 처리 설명은 인과적 설명으로 옳을 수 있고, 다만 지각이 무엇인지 밝히는 구성적 설명이 되지는 못한다. 마지막 절에서 그는 세계가 마음에 비개념적 항목을 건넨다는 생각과, 직관과 개념을 경험적 작업으로 맞추려는 기획을 버려야 한다고 말한다.
