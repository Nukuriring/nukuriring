# 20f7d 톰슨의 대칭성 논변은 욕구의 반내적항목 절반만 지지하고 비개념성 절반에는 별도 논거가 필요하다

톰슨은 세련된 행위철학을 지각의 표상주의와 최고 공통 요소(highest common factor) 이론의 자리에 놓고, 원함이라는 공통 요소로의 환원을 거부한다. 그러므로 행위에 대한 선언주의를 지지하는 셈이다. 반공통요소 논변은 지각의 인식론에서 맥도웰이 직접 편 논변이기도 하다. 맥도웰은 지각의 인식론에서는 선언주의자이고 경험의 내용에 관해서는 개념주의자라는 두 얼굴을 가진다. 트래비스가 맥도웰과 맞서는 지점은 개념적 내용이다. 따라서 톰슨의 대칭성 논변은 욕구가 성공과 실패에 공통인 보장된 내적 항목으로 환원되지 않는다는 반내적항목 절반을 강하게 지지하고, 욕구에 개념적 내용이 있는지는 판정하지 않는다. 비개념성 절반은 돌 밀기 논변에서 나온 얇은 개념 틀과 직관적 주어짐의 노선과 트래비스의 침묵 테제가 따로 맡아야 한다. 반표상성의 기제도 다르다. 지각에서는 감각의 침묵과 직접성이 일하고, 행위에서는 합리화 표의 대칭이 일한다. 톰슨을 트래비스의 무차별한 동맹으로 인용하면 과대 인용이 된다.
