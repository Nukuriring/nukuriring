# 68h 교환은 금전 이외의 재산권을 서로 이전하기로 약정하는 유상, 쌍무, 낙성, 불요식 계약이다

제596조는 교환이 당사자 쌍방이 금전 이외의 재산권을 상호 이전할 것을 약정함으로써 효력이 생긴다고 규정한다. 필기는 교환을 유상, 쌍무, 낙성, 불요식 계약으로 분류한다. 교환은 금전 이외의 재산권을 이전하기로 하는 당사자 간 의사표시의 합치로 성립한다.

## 연결
- 상위: [[68 민법 필기는 계약법과 물권법의 두 갈래로 구성되고 민법총론의 법률행위 규율이 두 갈래에 공통으로 쓰인다]]
- 다음: [[68i 임대차는 목적물의 사용과 수익을 차임 지급과 맞바꾸는 유상, 쌍무, 낙성, 불요식의 계속적 채권계약이다]]
- 가지: [[68h1 교환의 반대급부는 금전 이외의 재산권이어야 하고 보충금이 있어도 교환이며 일방이 금전을 지급하면 매매이다]]
- 가지: [[68h2 교환은 유상계약이어서 담보책임이 준용되고 쌍무계약이어서 동시이행과 위험부담이 준용된다]]
- [[68g 매매는 재산권 이전과 대금 지급의 약정으로 성립하는 유상, 쌍무, 낙성, 불요식 계약이다]]: 재산권과 금전을 맞바꾸는 매매와 대비되는 계약이다.
- [[68a1 유상계약에는 매매에 관한 규정, 특히 매도인의 담보책임 규정이 준용된다]]: 교환이 유상계약으로 분류되는 근거이다.
- [[68h1 교환의 반대급부는 금전 이외의 재산권이어야 하고 보충금이 있어도 교환이며 일방이 금전을 지급하면 매매이다]]: 교환의 목적물과 보충금을 이어서 다룬다.
