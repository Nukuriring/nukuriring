# 42u 크릴의 실행 투명성 정의는 실행 지식의 이해만으로 투명성이 달성된다고 보지만 정상 작동에 대한 규범적 판단이 더해져야 한다

크릴(Creel 2020)은 복잡한 계산 시스템에 대해 우리가 가질 수 있는 지식을 알고리즘에 대한 지식, 구현에 대한 지식, 특정 실행에 대한 지식으로 나누고 각각에 기능적 투명성, 구조적 투명성, 실행 투명성을 대응시킨다. 실행 투명성은 프로그램과 하드웨어, 입력 데이터, 머신 코드 번역 사이의 상호작용으로 생기는 아티팩트를 탐지하게 해 주는 투명성이다. 나는 기능적 투명성이나 구조적 투명성과 구별되는 이 특유한 범주가 있다는 데 크릴에게 동의한다. 그러나 그 범주를 특정 실행 인스턴스에 대한 지식의 획득과 결여로 규정하는 일은 부적절하다고 논증한다. 실행 투명성에는 실행 지식의 이해에 더해 시스템의 작동이 문제적이라는 규범적 판단이 필요하기 때문이다. 이는 실행 투명성이 시스템의 정상 작동에 대한 규범적 이해에 의존한다는 주장이다.

## 연결
- 상위: [[42 자기지식 세미나는 외재주의와의 충돌에서 출발해 여러 이론 유형을 거쳐 투명성과 합리적 행위자성으로 나아간다]]
- 다음: [[42v 투명성 현상은 나 자신의 믿음을 묻는 물음에는 세계의 사실을 고려해 답하고 남의 믿음을 묻는 물음에는 그 사람의 심리 사실을 고려해 답하는 비대칭에서 드러난다]]
- 가지: [[42u1 연구자가 실행 지식을 충분히 이해해도 아티팩트를 탐지하지 못할 수 있으므로 실행 지식의 이해는 실행 투명성의 충분조건이 아니다]]
- 가지: [[42u2 실행 지식과 규범 지식은 각각 독립적으로 아티팩트를 식별하게 해 주지 못하므로 규범 투명성을 별개 범주로 세울 이유가 없다]]
- 가지: [[42u3 계산 현상학은 살아진 세계에 자신을 두고 인지 과정을 분리한 뒤 계산 모델의 메커니즘과 비교하는 세 단계로 딥러닝을 해석한다]]
- 가지: [[42u4 딥드림에서 이두근을 덤벨의 기준으로 삼은 일은 최적의 파악 실패이자 유도 제약 위반이어서 연구자들의 판단은 임의적 선입견이 되지 않는다]]
- [[42u1 연구자가 실행 지식을 충분히 이해해도 아티팩트를 탐지하지 못할 수 있으므로 실행 지식의 이해는 실행 투명성의 충분조건이 아니다]]: 실행 지식의 이해가 충분조건이 아님을 보이는 논증이다.
- [[42u1a 기능 지식과 구조 지식의 이해는 규범적 판단 없이 각 투명성에 충분하지만 실행 지식의 이해는 그렇지 않아서 실행 투명성이 가장 뚜렷이 구별된다]]: 기능적 투명성과 구조적 투명성과의 차이를 짚는 카드이다.
- [[41q2 실행 불투명성은 시스템이 정상 작동하는 동안에는 요점이 없고 정상 작동은 기능으로 규정되므로 그 요점은 기능적 투명성에 의존한다]]: 같은 문제의식을 초고에서 정리한 다른 묶음의 카드이다.
- [[41q1 크릴은 복잡한 계산 시스템의 투명성을 알고리즘 투명성과 구조적 투명성과 실행 투명성의 세 종류 지식으로 나눈다]]: 크릴의 세 범주를 정리한 다른 묶음의 카드이다.
- [[41q1a 크릴은 하드웨어와 입력 데이터가 만드는 아티팩트와 딥드림 사례로 실행 투명성이 독자적 범주라고 논증한다]] (다음 단계): 크릴의 독자적 범주 논증 위에서 정상 작동에 대한 규범적 판단을 더해야 한다는 보완이 나온다. (제안: Claude)
- [[41q2b 알고리즘 지식은 계산 시스템의 정체와 목적에 대한 목적론적 이해를 주므로 크릴의 독립성 주장과 충돌한다]] (다음 단계): 알고리즘 지식이 목적론적 이해를 준다는 지적은 실행 투명성에 규범적 판단이 더해져야 한다는 수정과 이어진다. (제안: Claude)
- [[67e 시스템의 정상 작동을 정하는 일과 정확도와 형평성의 상충을 정하는 일은 둘 다 사실 지식에 더해 명시적인 규범 선택을 요구한다]] (다음 단계): 실행 투명성에 규범적 판단이 필요하다는 주장이 AI 전반의 규범 선택 요구로 일반화된다. (제안: Claude)
- [[20e7 톰슨에 따르면 자연적 결함은 종의 자연사가 대는 척도에서 나오며 개체에 내재적 비판을 가한다]] (전제): 종의 자연사가 정상 작동의 척도를 대므로 정상 작동에 규범적 판단이 필요하다는 주장이 성립할 바탕이 된다. (제안: Claude)
- [[52e2c 영진은 정체성이라는 장치의 정상 작동과 비정상 작동을 기능 수준에서 가르고 평가 기준을 공동체의 유지 보수 하나로 모은다]] (사례): 정상 작동에 규범적 판단이 필요하다는 주장이 정체성 장치에서는 공동체의 유지 보수라는 기준으로 구체화된다. (제안: Claude)
- [[52e8 몰과 드 라에트의 유동적 객체는 정체성을 유지하면서 환경에 따라 형태와 기능이 바뀌고 정상과 고장의 경계가 모호하다는 노트의 정리]] (반론): 정상 작동에 규범적 판단을 더하는 구도는 정상과 고장의 경계가 모호한 유동적 객체 앞에서 시험받는다. (제안: Claude)
