# 42d5a 메리와 전도된 메리는 물리적으로 같아도 다른 순수 현상적 믿음을 가지므로 믿음 내용은 물리적 속성에 수반하지 않는다

메리가 흑백 방을 나와 토마토를 처음 볼 때 얻는 믿음 가운데 관계적 개념과 지시적 개념에 순수 개념이 결합한 믿음 redC=R, redI=R, E=R는 모두 선험적이지 않고 인지적으로 의미가 있다. 따라서 redC, redI, E, R의 인식적 내포는 서로 모두 다르다. 전도된 메리는 같은 상황에서 redC=G, redI=G, E=G를 얻으므로 두 사람은 다른 현상적 믿음을 갖는다. 그런데 두 사람은 붉은 토마토를 처음 본 뒤에도 물리적, 기능적, 환경적 쌍둥이이다. 현상적 믿음의 내용이 서로 다르다는 점은 믿음 내용이 물리적이고 기능적인 속성에 개념적으로 수반하지 않음을 보여 준다. 순수 현상적 개념에서는 주체들이 물리적으로 같은데도 두 개념의 인식적 내용이 갈리는 상황이 생기는 것이다.
