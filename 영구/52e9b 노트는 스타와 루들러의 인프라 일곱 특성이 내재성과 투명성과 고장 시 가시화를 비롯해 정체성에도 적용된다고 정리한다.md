# 52e9b 노트는 스타와 루들러의 인프라 일곱 특성이 내재성과 투명성과 고장 시 가시화를 비롯해 정체성에도 적용된다고 정리한다

노트는 인프라 연구의 일곱 특성이 정체성에 적용된다고 정리한다. 일곱 특성은 내재성, 투명성, 도달 범위, 학습과 상속, 표준화, 고장 시 가시화, 정치성과 가치 내포이다. 정체성 범주는 교육, 노동, 가족, 병원 서류, 플랫폼 프로필 같은 수많은 제도 안에 묻혀 작동한다(내재성). 일상이 순조로우면 정체성 수행을 의식하지 않다가 차별과 부딪혀야 존재를 인식한다(투명성). 한 곳에서 고안된 규범이 멀리 파급되고(도달 범위), 언어와 예절과 몸짓은 구성원이 되며 체화하는 회원권 규칙이며(학습과 상속), 여권의 성별 칸이나 광고 API 세그먼트처럼 규약화된 필드가 정체성을 기계적으로 호출한다(표준화). 편향 알고리즘과 강제 아우팅 같은 고장에서 평소 보이지 않던 작동 논리가 드러나고(고장 시 가시화), 어떤 범주를 인정하거나 배제할지는 권력과 가치 판단을 지닌다. 노트는 이 적용이 설득력 있는 이유로 정체성이 세금과 복지와 감시의 흐름을 라우팅하는 배관처럼 기능한다는 점, 고장과 수리 경험이 같은 패턴을 보인다는 점, 인프라 연구가 이미 시간대와 달력 같은 비물질 인프라를 다루었다는 점을 든다. 억압은 배관 설계 문제로, 해방은 수리와 재배치 작업으로 사유할 여지가 생긴다고 정리한다.
