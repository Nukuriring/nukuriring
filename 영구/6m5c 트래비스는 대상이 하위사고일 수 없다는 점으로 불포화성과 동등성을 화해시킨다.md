# 6m5c 트래비스는 대상이 하위사고일 수 없다는 점으로 불포화성과 동등성을 화해시킨다

트래비스는 분해 안에서 어떤 부분도 다른 부분보다 통일에 더 책임지지 않는다는 동등성(parity)을 세운다(pp.22–23). 프레게의 불포화성 발언은 이를 위협하는 듯하다: 1882년 편지는 통일의 책임을 술어 쪽에 지우는 것처럼 보이고, 1892년과 1919년 글은 적어도 한 부분이 불포화적이어야 부분들이 서로 달라붙는다고 말한다(p.23). 트래비스의 해소는 프레게가 '주어'로 부른 것이 대상이라면 바로 그 이유로 그것은 하위사고일 수 없다는 데서 시작한다(p.24): 그 자리의 하위사고가 할 일은 어떤 대상을 참이 걸리는 자로 만드는 것인데 "no object can make itself the one which plays this role"(p.24). 그러므로 술어적 하위사고가 결합하는 상대는 지시적 하위사고이고, 둘 다 분해 전체의 문맥 밖에서는 자기 과제를 수행하지 못하므로 동등성은 이 둘 사이에서 성립한다. 이 과정에서 그는 술어와 개념을 가른다: 술어는 무엇에 대해 술어할지라는 완성을 요구하고, 개념은 자기 아래 떨어질 수 있는 것들을 요구하며 완성은 요구하지 않는다(pp.24, 26). 남는 비대칭은 개념과 대상이 사고에 관계하는 방식에 있다. 개념은 술어적 하위사고에서 추상된 성분으로서 구성요소가 아니어도 사고 안에 나타나고, 대상은 지시적 하위사고가 지목하는 것으로서 표상에 대해 사물이 외적인 만큼 사고에 외적이다(pp.25–26). 2장 §2.7은 같은 생각을 접착 작용(adhesive agency)이 분해 안의 모든 부분에 퍼져 있다는 주장으로 다시 펼친다(p.49).
