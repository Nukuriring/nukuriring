# 69h5 도메인은 IP 주소를 문자로 나타낸 주소이고 DNS가 문자 도메인을 숫자 IP로 변환한다

IP는 인터넷에서 컴퓨터를 구분하는 유일한 주소이다. 주소는 DHCP로 자동 할당하거나 IP, 서브넷 접두사, 게이트웨이, DNS를 수동으로 정한다. 도메인은 IP 주소를 문자로 표현한 인터넷 주소이고 DNS는 문자 도메인을 숫자 IP로 변환한다. URL은 자원의 위치를 나타내는 표준 주소 체계이며 프로토콜, 호스트 주소인 도메인, 포트 번호, 파일 경로의 순서로 적는다. 도메인은 국제 인터넷 주소 관리 기구나 KISA에서 관리하고, 도메인의 실제 주소는 NSLOOKUP으로 확인한다.

## 연결
- [[69h4 IPv4는 32비트 주소이고 IPv6는 주소 부족을 해결하려고 128비트로 늘렸다]]: 도메인이 문자로 나타내는 IP 주소의 구조를 다룬다.
- [[69h17 IPCONFIG, NSLOOKUP, TRACERT, PING, FINGER, NETSTAT는 연결 상태와 주소를 확인하는 명령어이다]]: 도메인의 실제 주소를 확인하는 NSLOOKUP을 포함한 명령어를 다룬다.
- 관련 주제(다른 묶음): DNS, URL
