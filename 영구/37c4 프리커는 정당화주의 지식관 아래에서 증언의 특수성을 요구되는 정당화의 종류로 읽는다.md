# 37c4 프리커는 정당화주의 지식관 아래에서 증언의 특수성을 요구되는 정당화의 종류로 읽는다

프리커는 증언이 지식의 특수한 원천이라는 말이 여러 뜻을 가질 수 있다고 보고, 그 말을 증언이 다른 점에서는 완전히 일반적인 지식관의 예외라는 뜻으로 받아들이지 않는다. 그녀는 지식이 서로 다른 방식으로 얻어지더라도 어떤 기술 수준에서는 한 종류의 것임을 보이는 일을 지식 개념 설명의 적합성 조건으로 삼는다. 그런 포괄적 지식관은 인과론이나 신빙론일 수도 있지만, 프리커는 주체가 자기 믿음을 적절히 옹호할 수 있음을 지식의 필요조건으로 보는 정당화주의(justificationist) 지식관을 택한다. 이 지식관 아래에서 증언이 환원 불가능한 지식 원천이라는 주장은 증언적 믿음에 어떤 종류의 정당화가 요구되는지에 관한 주장으로 나타나며, 지식이 적절한 정당화를 요구한다는 논제의 반례가 되지 않는다. PR 논제가 바로 그런 주장이다(pp.126–127).
