# 43l1 브룸은 요구를 속성 의미와 출처 의미로 나누고 합리성의 요구를 출처 의미로 다룬다

브룸은 요구를 속성 의미(property sense)와 출처 의미(source sense)로 나눈다. 속성 의미는 생존이 제대로 기능하는 간을 요구한다는 말처럼 어떤 속성이 어떤 조건을 필요로 한다는 뜻이고, 출처 의미는 법, 도덕, 합리성, 신중함 같은 출처가 처방해서 생기는 요구이다. 두 의미는 논리적 성질이 달라서 구별해야 하며, 브룸은 합리성이라는 출처의 요구만 다룬다. 속성 의미를 양상 해석으로 풀면 비행기에서 뛰어내릴 때 생존이 낙하산을 필연적으로 요구한다는 거짓이 나오므로 필연성의 범위를 조건문 전체에 두어야 한다. 설명적 해석은 간을 기계로 대체한 가능 세계를 반례로 맞고, 접속법 해석은 생존이 엄지손가락을 까딱이는 일까지 요구하게 만든다. 그래서 설명 조건을 더하는 방향으로 해석을 고친다. 출처 의미의 요구는 규범적이지 않을 수 있어서 그것을 만족시킬 이유가 없을 수도 있고, 국지적이어서 신중하지 않은 사람에게 요구되는 바가 신중한 사람이 했을 일과 다를 수 있다. 키제베터가 규칙 의미(code sense)라고 부르는 요구가 이 출처 의미에 해당하는 것으로 보이지만 대응 관계는 확인이 필요하다.
