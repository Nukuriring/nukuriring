# 42e2a 내감 이론에 대한 흔한 비판은 기관과 감각 경험과 주의의 부재에 기대지만 슈메이커는 감각 경험의 부재를 논거로 삼지 않는다

첫째 조건과 관련해 우리의 심리 상태를 지각하는 일을 맡는 기관이 없다는 데에는 거의 모든 내감 이론가가 동의한다. 다만 일부는 기관 대신 심리 상태를 지각하는 일을 고유하게 수행하는 능력(faculty)이 있다고 주장한다. 둘째 조건에서 외부 대상을 지각할 때는 대상과 구별되는 경험이 일어나는데, 믿음이나 욕구 같은 지향적 상태를 지각할 때는 그런 경험이 일어나는 것 같지 않다. 감각이나 느낌 같은 현상적 상태를 지각할 때에도 그것과 구별되는 경험이 있는지 불분명하다. 여섯째 조건과 관련해 외부 대상은 주의로 서로 다른 측면에 주목할 수 있지만 우리 심리 상태는 그렇게 하기 어려운 듯하다. 내감 이론을 비판하는 사람들은 이런 차이를 근거로 삼기도 하지만, 슈메이커는 이 논문에서 둘째 조건의 차이로 내감 이론을 비판하지 않는다.
