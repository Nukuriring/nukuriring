# 44b3 보상이론은 내적 욕구를 보상 시스템이 어떤 사태의 표상에 양의 신호를 내도록 배선된 상태와 동일시한다

보상이론은 내적 욕구를 뇌의 보상·처벌 시스템의 상태와 동일시한다. P를 내재적으로 욕구한다는 것은 P를 보상으로 구성한다는 것과 같고, 이는 도파민 기반 보상 회로가 P의 표상에 양의 학습 신호를 내도록 배선되어 있다는 뜻이다. 회로가 음의 값을 내면 내적 혐오(averse desire)가 성립한다. 필기가 정리한 학습 메커니즘은 이러하다. 개체는 환경 상태 P를 무의식적으로 표상하고, 유전과 경험으로 정해진 기준에 따라 일부 표상이 양이나 음의 값을 가진 보상이나 처벌로 분류된다. 시스템은 예측한 보상과 실제 보상의 차이를 계산하고, 오차가 양이면 도파민 신호로 직전의 인과 연결을 강화하며 음이면 약화한다. 여기서 보상은 예측 오차에 기반한 강화 신호를 가리키는 기술적 개념이다. 행동 충동과 쾌·불쾌와 주의 편향 같은 욕구의 전통적 징후는 이 신호의 후행 결과로 재해석된다.
