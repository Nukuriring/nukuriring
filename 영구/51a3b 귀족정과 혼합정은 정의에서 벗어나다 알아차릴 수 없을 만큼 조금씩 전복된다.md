# 51a3b 귀족정과 혼합정은 정의에서 벗어나다 알아차릴 수 없을 만큼 조금씩 전복된다

5권 7장은 귀족정의 파당 원인으로 소수가 관직의 명예를 독점한다는 점을 든다. 인민이 덕에서 소수와 동등하다고 믿거나 빈부 격차가 극단적일 때, 혹은 더 훌륭한 한 사람이 홀로 지배하려 할 때 파당이 일어난다. 혼합정은 민주정과 과두정이 잘 섞이지 않아서, 귀족정은 여기에 덕까지 잘 섞이지 않아서 전복된다. 시민들이 체제의 한 가지를 포기하면 다음에 더 큰 것을 바꾸기가 쉬워져 마침내 전체 제도가 바뀌므로 변화는 알아차리기 어렵다. 외부 영향의 사례로 아테네인은 어디서나 과두정을, 라케다이모니아인은 어디서나 민주정을 전복했다는 언급이 있다.
