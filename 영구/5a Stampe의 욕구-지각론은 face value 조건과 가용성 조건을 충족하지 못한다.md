# 5a Stampe의 욕구-지각론은 face value 조건과 가용성 조건을 충족하지 못한다

Stampe의 지각으로서의 욕구(desire as perception) 이론이 성립하려면 두 조건이 필요하다. 하나는 욕구가 생길 때마다 'p가 좋게 보인다'는 내용을 부여할 수 있어야 한다는 face value 조건이고, 다른 하나는 그 사실을 해당 지각 경험을 통해 식별하고 포착할 수 있어야 한다는 가용성(availability, 응답글의 한국어 표기로는 '유효성') 조건이다. 욕구-지각을 비인식적 지각과 인식적 지각으로 나누어 검토하면, 비인식적 갈래는 가용성 조건을 위반하고 인식적 갈래는 face value 조건을 충족하더라도 가용성 조건을 충족하지 못하므로, 어느 갈래도 두 조건을 함께 충족하지 못한다. 갈증을 느끼는 경우 비인식적 지각만으로는 물 마시기, 주스 마시기, 입 헹구기, 체온 낮추기 가운데 무엇이 좋게 보이는지를 하나로 정할 수 없으며, "해당 비-인식적 지각은 각 선언지에 대해서 모두 공평하다". 인식적 지각이 'p를 획득하는 것이 좋을 것이다(It would be good to obtain p)'라는 내용을 고정하려면 Stampe가 기대는 일종의 bridging principle이 필요한데, 그 원리는 추론처럼 보이고 욕구-지각 경험 안에 내장되어 있다고 보기 어렵다. Claude는 두 조건을 트래비스가 정식화한 표상주의의 둘째 요소(face value)와 넷째 요소(인지 가능성)에 대응시키고, 비인식적 갈래의 문제를 미결정성으로, 인식적 갈래의 문제를 indicating을 표상으로 분류한 범주 오류로 정리했다(대화 속 설명).
