# 60e5 □의 진리 조건은 접근 가능성 관계로 주어지고 K-타당성은 K-반례의 부재로 정의된다

□A가 모든 가능세계에서 A가 참이라는 뜻이라고 보는 것은 □를 더 포괄적인 양상으로 쓰기에 적절하지 않으므로, 세계들 사이의 이항관계 접근 가능성 R을 도입한다. R이 무엇인지는 □의 의미에 따라 달라지며, 예컨대 미래 시제 논리에서 R은 세계들 사이의 보다 이름 관계가 된다. K-모델은 공집합이 아닌 세계의 집합 W, 접근 가능성 R, ⊥와 →의 진리 조건을 따르는 할당 a의 삼중체 ⟨W, R, a⟩이고, ⟨W, R⟩ 부분을 프레임이라 부른다. 진리 조건은 (□) aw(□A) = T iff wRv인 모든 v에 대하여 av(A) = T이고, (◇) aw(◇A) = T iff wRv인 어떤 v가 있는데 av(A) = T이다. 문장 목록 H가 K-만족 가능하다는 것은 어떤 K-모델과 세계 w에서 aw(H) = T라는 것이고, 논증 H/C가 K-반례를 가진다는 것은 H와 ¬C가 K-만족 가능하다는 것이다. 논증 H/C는 K-반례를 갖지 않을 때 K-타당하고, 문장 A는 논증 /A가 K-타당할 때 K-타당하다.
