# 42u1a 기능 지식과 구조 지식의 이해는 규범적 판단 없이 각 투명성에 충분하지만 실행 지식의 이해는 그렇지 않아서 실행 투명성이 가장 뚜렷이 구별된다

크릴은 기능적 투명성을 전체 시스템의 알고리즘적 작동에 대한 지식으로, 구조적 투명성을 알고리즘이 코드에 어떻게 구현되는지에 대한 지식으로 정의한다. 기능적 투명성이 달성되면 시스템이 입력을 출력으로 바꾸는 고수준 논리 규칙을 알고, 구조적 투명성이 달성되면 쓰인 코드가 프로그램의 결과를 가져오는 방식을 이해한다. 이 두 유형에서는 대상 모델의 정상 작동에 대한 규범적 지식의 이해가 필수적이지 않다. 기능적 투명성과 관련된 지식을 기능 지식, 구조적 투명성과 관련된 지식을 구조 지식이라 하면, 기능 지식의 이해는 기능적 투명성에, 구조 지식의 이해는 구조적 투명성에 충분하다. 그러나 앞서 본 대로 실행 지식의 이해는 실행 투명성에 충분하지 않다. 이 차이가 기능적 투명성과 구조적 투명성을 실행 투명성에서 가장 뚜렷이 구별하는 요소이다.
