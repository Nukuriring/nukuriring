# 67p3a 심층망은 입력 공간을 접어 결정 경계를 재사용하므로 선형 영역의 수가 지수적으로 늘어난다

심층 신경망이 같은 수의 노드를 가진 얕은 신경망보다 훨씬 많은 선형 영역을 만들 수 있다는 점은 수학적으로 증명되어 있고, 발제문은 이를 Montufar 등(2014)의 분석으로 소개한다. 얕은 신경망이 입력 공간에 복잡한 결정 경계를 그으려면 많은 선을 일일이 그어 공간을 나누어야 한다. 심층 신경망은 첫 번째 계층에서 입력 공간을 한 번 접고 다음 계층에서 또 접어, 계층을 거칠 때마다 앞서 직선으로 그린 결정 경계를 여러 번 재사용한다. 얕은 구조라면 따로 그어야 했을 여러 경계선을 한 번의 접기로 동시에 처리하므로 선형 구간의 수가 지수적으로 늘어나는 효과가 생긴다. 학습 과정에서 신경망은 입력 공간의 대칭을 발견해 쉽게 접히는 부분을 찾고 그 방향으로 결정 경계를 형성한다. 이 설명에 따르면 심층 신경망은 얕은 구조보다 적은 비용으로 훨씬 복잡한 패턴을 학습한다.
