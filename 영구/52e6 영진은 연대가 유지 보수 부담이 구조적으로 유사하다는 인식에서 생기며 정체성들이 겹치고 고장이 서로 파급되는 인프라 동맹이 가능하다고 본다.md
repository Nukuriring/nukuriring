# 52e6 영진은 연대가 유지 보수 부담이 구조적으로 유사하다는 인식에서 생기며 정체성들이 겹치고 고장이 서로 파급되는 인프라 동맹이 가능하다고 본다

영진은 정체성 기반 정치가 단편화를 부추긴다는 비판에 제안서에서 응답한다. 정체성이 공유된 노동과 돌봄으로 묶인 깨지기 쉬운 집합체라면 연대는 유지 보수의 공유된 경험으로 이루어진다고 영진은 본다. 퀴어 장애인, 흑인 페미니스트, 미등록 노동자처럼 정체성이 다른 집단은 서로 다른 고장을 만나도 유지 보수 노동이 주변화된 주체에게 구조적으로 집중되는 점에서 같다. 정체성 객체는 겹치고 교차하고 서로를 조건짓기도 해서 한 정체성의 고장이 다른 정체성으로 파급되고, 하나의 고장 난 객체를 둘러싼 공중이 다른 객체의 고장과 얽힌다. 이 모델은 양립하지 않는 요구와 서로 다른 이해와 충돌하는 애착을 지닌 정체성 공중이 서로를 강화해야 할 정치적 긴급성을 인식할 수 있게 설명한다. 영진은 이를 STS 용어로 네트워크화된 취약성의 정치이자 인프라 동맹이라 부르고, 메타 정체성으로 융합하지 않고 유지 보수 투쟁을 상호 인식으로 잇는 연합이라고 설명한다.
