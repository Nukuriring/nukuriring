# 67p 버크너는 딥러닝의 성공을 설명하는 세 관점을 소개하고 서로 보완한다고 본다

버크너는 딥러닝이 이렇게 잘 작동하는 이유를 설명하려는 세 가지 주요 관점을 소개한다. 첫째는 계층적 특징 구성(hierarchical feature composition)이고, 둘째는 입력 변환을 통한 잡음 조정(nuisance-variation adjustment)이며, 셋째는 선형 영역의 수(number of linear regions)이다. 이 설명들은 때로 경쟁 구도로 제시되지만 버크너는 서로 양립할 수 있고 딥러닝의 성능을 여러 측면에서 이해하게 해 준다고 본다. 첫째는 뇌의 시각 체계와의 유사성에, 둘째는 구조에 담긴 사전 편향에, 셋째는 결정 경계의 복잡도에 주목한다.

## 연결
- 상위: [[67 딥러닝은 투명성과 공정성의 규범 선택 문제와 마음의 학습 모델이라는 두 물음을 낳는다]]
- 다음: [[67q 경험주의자는 DCNN이 순수한 픽셀 입력에서 범주를 학습한다는 점을 타뷸라 라사 가설의 개념적 입증으로 읽는다]]
- 가지: [[67p1 계층적 특징 구성 설명에 따르면 DCNN은 포유류 시각 체계처럼 단순한 특징에서 복잡한 특징으로 위계적으로 조합한다]]
- 가지: [[67p2 잡음 조정 설명에 따르면 DCNN의 구조는 사전 편향으로 가설 공간을 줄이고 현실의 문제가 그 가정에 맞아서 잘 작동한다]]
- 가지: [[67p3 선형 영역 설명에 따르면 DCNN은 유사성 공간에서 더 복잡한 결정 경계를 그린다]]
- 가지: [[67p4 세 설명은 유용한 부분 구조의 반복 재사용이라는 공통 측면을 가진다]]
- [[67n 인공신경망은 출력과 정답의 오차를 층을 거슬러 전파하며 가중치를 조정해 학습한다]]: 합의된 설명이 없다는 문제의식이 출발점이다.
- [[67p1 계층적 특징 구성 설명에 따르면 DCNN은 포유류 시각 체계처럼 단순한 특징에서 복잡한 특징으로 위계적으로 조합한다]]: 첫째 관점을 정리한다.
- [[67p2 잡음 조정 설명에 따르면 DCNN의 구조는 사전 편향으로 가설 공간을 줄이고 현실의 문제가 그 가정에 맞아서 잘 작동한다]]: 둘째 관점을 정리한다.
- [[67p3 선형 영역 설명에 따르면 DCNN은 유사성 공간에서 더 복잡한 결정 경계를 그린다]]: 셋째 관점을 정리한다.
- [[67p4 세 설명은 유용한 부분 구조의 반복 재사용이라는 공통 측면을 가진다]]: 세 관점의 공통 측면을 정리한다.
