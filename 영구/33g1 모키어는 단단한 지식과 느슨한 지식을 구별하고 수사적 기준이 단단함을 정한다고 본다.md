# 33g1 모키어는 단단한 지식과 느슨한 지식을 구별하고 수사적 기준이 단단함을 정한다고 본다

모키어는 믿음이 단단하거나(tight) 느슨할 수 있다고 정의한다. 단단한 믿음은 큰 다수가 높은 확실성으로 갖고 그것에 의존하는 대부분의 사람이 검증을 요구하지 않는 믿음이다. 느슨한 믿음은 당대의 수사적 기준을 충족하는 증거를 내놓을 능력이 제한되어 있어서, 서로 양립할 수 없지만 해결되지도 않는 생각들이 공존하는 믿음이다. 정리글은 이 개념에서 지식의 참됨과 단단함이 별개라고 읽는다. 참인 믿음도 당대의 기준으로 입증하지 못하면 느슨하고, 거짓 믿음도 다수가 확신하면 단단하다. 증거의 기준 자체가 문화 진화의 대상이며, 모키어는 앞선 현자들의 저술이 증거인 사회와 실험에 의존하는 사회가 아주 다를 것이라고 말한다. 3장은 느슨한 영역에서 새 생각이 옛 생각과 혼합 균형으로 공존할 수 있고 아미시나 지구 평면론자 같은 소수 믿음이 틈새에서 살아남는다고 논한다. 한편 효과적인 지식은 빨리 퍼져서, 박테리아를 죽이는 조치가 감염률을 낮춘다는 것이 보여지자 전염병의 미생물설을 의심하는 사람이 거의 없어졌지만, 독기설에 기댄 배수가 말라리아를 줄인 경우처럼 작동한다는 사실은 참이라는 논리적 증거가 되지 못한다.
