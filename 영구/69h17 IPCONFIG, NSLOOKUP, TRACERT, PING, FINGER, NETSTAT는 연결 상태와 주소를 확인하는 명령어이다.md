# 69h17 IPCONFIG, NSLOOKUP, TRACERT, PING, FINGER, NETSTAT는 연결 상태와 주소를 확인하는 명령어이다

IPCONFIG는 IP 주소를 확인하고, NSLOOKUP은 도메인의 실제 주소를 확인한다. TRACERT는 라우터의 경로를 추적하고, PING은 통신 선로를 점검한다. FINGER는 사용자 정보를 확인하고, NETSTAT는 내 컴퓨터에 연결된 정보와 포트를 확인한다.

## 연결
- [[69h5 도메인은 IP 주소를 문자로 나타낸 주소이고 DNS가 문자 도메인을 숫자 IP로 변환한다]]: 도메인의 실제 주소를 확인하는 NSLOOKUP의 배경인 DNS를 다룬다.
- [[69h14 통신 장비는 연결 범위에 따라 구분되고 OSI 7계층의 계층에 대응한다]]: TRACERT가 추적하는 라우터를 다룬다.
- 관련 주제(다른 묶음): 네트워크 진단
