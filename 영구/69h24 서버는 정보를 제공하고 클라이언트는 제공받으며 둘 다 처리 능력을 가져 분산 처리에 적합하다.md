# 69h24 서버는 정보를 제공하고 클라이언트는 제공받으며 둘 다 처리 능력을 가져 분산 처리에 적합하다

정보를 제공하는 쪽이 서버이고 정보를 제공받는 쪽이 클라이언트이다. 클라이언트와 서버 모두 처리 능력을 가지고 있어 분산 처리 환경에 적합하다. HTML은 하이퍼텍스트 문서를 만드는 언어이고 XML은 HTML의 단점을 보완하며, HTML5는 플러그인 없이 웹 서비스를 이용하게 한다. ASP, PHP, JSP는 서버 측 언어이고, 필기는 이 언어들이 운영체제마다 다르다고 적는다.
