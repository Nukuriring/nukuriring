# 69h15 프로토콜은 무엇을 어떻게 언제 통신할지 정한 규약이며 흐름 제어, 동기화, 오류 제어를 맡는다

프로토콜은 정보를 주고받기 위해 무엇을 어떻게 언제 통신할지 정한 통신 규약이다. 흐름 제어는 패킷의 흐름을 조정해 안정성을 유지하고, 패킷은 데이터 통신에서 다루는 데이터 단위이다. 동기화는 송신과 수신이 같은 상태를 유지하게 하고, 오류 제어는 전송 중 발생한 오류를 검출하고 복원한다. 표준 프로토콜인 TCP는 메시지를 송수신 주소와 정보로 묶어 패킷 단위로 나누고 흐름 제어와 데이터 에러 검사를 한다. IP는 패킷의 주소를 해석하고 경로를 결정해 다음 호스트로 전송한다.
