# 67 딥러닝은 투명성과 공정성의 규범 선택 문제와 마음의 학습 모델이라는 두 물음을 낳는다

이 줄기는 딥러닝을 두 방향에서 다룬다. 첫째 방향은 딥러닝을 사회에 배치된 시스템으로 보고 투명성과 공정성을 따지는 영진 님의 기말 논문과 Barocas와 Selbst 논문 발제이다(67a~67e). 67a는 불투명성이 책임 소재의 쟁점이 되는 이유를 쓰고, 67b는 크릴의 유형론을 이어받아 실행 투명성이 실행 지식과 정상 작동에 대한 규범적 이해에 달려 있다고 정리한다. 67c와 67d는 데이터 마이닝에서 정확도와 형평성이 충돌할 때 어떤 가치 질서로 선을 그을지, 속성 선택의 비용 편익 기준이 왜 오류를 고칠 유인을 주지 못하는지 묻고, 67e는 두 논의의 공통 구조를 사실 지식과 명시적 규범 선택의 결합으로 종합한다. 둘째 방향은 버크너의 책을 정리한 발제로, 학습의 원리와 합성곱 신경망의 구조(67n, 67o), 딥러닝의 성공을 설명하는 세 관점(67p), 경험주의와 본유주의의 논쟁과 인간 학습과의 비교(67q~67s), 마음을 설명하는 모델로서의 지위(67t)를 다룬다. 67u는 AI가 인간의 학습 방식을 바꾸고 있다는 영진 님의 관찰로 끝난다. 두 방향은 모델의 내부를 어떻게 이해하고 평가할 것인가라는 물음에서 만난다.

## 연결
- 가지: [[67a 딥러닝의 불투명성은 정확성과 공정성의 평가와 피해자의 구제를 어렵게 하므로 투명성은 책임 소재의 쟁점이 된다]]
- 가지: [[67b 실행 투명성의 달성 방법은 결여한 지식에 따라 달라지고 실행 지식과 규범적 이해가 서로 보완할 때 가장 효과적이다]]
- 가지: [[67c 데이터 마이닝의 정확도와 형평성의 충돌은 사회가 추구할 가치 질서를 다시 점검하라는 요청이다]]
- 가지: [[67d 속성 선택의 비용 편익 기준은 오류가 덜 수익적인 집단에 몰릴 때 기업에게 오류를 고칠 유인을 주지 못한다]]
- 가지: [[67e 시스템의 정상 작동을 정하는 일과 정확도와 형평성의 상충을 정하는 일은 둘 다 사실 지식에 더해 명시적인 규범 선택을 요구한다]]
- 가지: [[67n 인공신경망은 출력과 정답의 오차를 층을 거슬러 전파하며 가중치를 조정해 학습한다]]
- 가지: [[67o 버크너에 따르면 현대 DCNN은 골든 에이지 신경망과 깊이와 다종성과 간헐적 연결과 명시적 정규화에서 다르다]]
- 가지: [[67p 버크너는 딥러닝의 성공을 설명하는 세 관점을 소개하고 서로 보완한다고 본다]]
- 가지: [[67q 경험주의자는 DCNN이 순수한 픽셀 입력에서 범주를 학습한다는 점을 타뷸라 라사 가설의 개념적 입증으로 읽는다]]
- 가지: [[67r DCNN이 인간보다 훨씬 많은 데이터를 요구한다는 점은 두 학습이 다른 메커니즘이라는 논거로 쓰인다]]
- 가지: [[67s 적대적 예제는 DCNN이 인간과 다른 방식으로 패턴을 인식한다는 논거로 쓰인다]]
- 가지: [[67t 기계론적 설명을 지지하는 논자들은 DCNN이 인지 이면의 과정을 밝혀 마음의 블랙박스를 열 수 있다고 본다]]
- 가지: [[67u 영진은 체스와 바둑에서 AI가 인간을 압도한 뒤 인간의 학습 방식이 AI의 방식을 따라 바뀌고 있다고 본다]]
- [[67a 딥러닝의 불투명성은 정확성과 공정성의 평가와 피해자의 구제를 어렵게 하므로 투명성은 책임 소재의 쟁점이 된다]]: 이 줄기의 출발점으로 불투명성이 책임 소재의 쟁점이 되는 이유를 다룬다.
- [[67b 실행 투명성의 달성 방법은 결여한 지식에 따라 달라지고 실행 지식과 규범적 이해가 서로 보완할 때 가장 효과적이다]]: 기말 논문의 중심 주장으로 실행 투명성의 달성 조건을 다룬다.
- [[67c 데이터 마이닝의 정확도와 형평성의 충돌은 사회가 추구할 가치 질서를 다시 점검하라는 요청이다]]: 발제 말미의 물음으로 정확도와 형평성의 충돌을 가치 질서의 점검으로 읽는다.
- [[67n 인공신경망은 출력과 정답의 오차를 층을 거슬러 전파하며 가중치를 조정해 학습한다]]: 둘째 방향의 출발점으로 인공신경망이 학습하는 원리를 다룬다.
- [[67p 버크너는 딥러닝의 성공을 설명하는 세 관점을 소개하고 서로 보완한다고 본다]]: 둘째 방향의 중심으로 딥러닝이 잘 작동하는 이유를 설명하는 세 관점을 다룬다.
- 관련 주제(다른 묶음): 설명 가능한 AI, 알고리즘 공정성, 계산 현상학, 경험주의와 본유주의, 인공지능과 인간 학습
