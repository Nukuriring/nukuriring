# 42a 외재주의는 심적 내용이 주체의 내부만으로 정해지지 않는다고 보므로 내용에 대한 특권적 접근이 가능한지가 자기지식의 첫 문제가 된다

퍼트남의 쌍둥이 지구 사고실험과 버지의 관절염 사고실험은 내재적으로 같은 두 사람이 서로 다른 내용을 생각할 수 있음을 보여 준다고 읽힌다. 이 읽기에서 외재주의는 심적 내용이 주체의 내재적 속성에 수반하지 않는다는 주장이다. 외재주의가 옳다면 내가 무엇을 생각하는지 알려면 환경의 관련 사실을 알아야 할 것 같고 그 앎은 경험적 관찰을 요구한다. 그렇다면 내가 내 생각을 내성만으로 안다는 전통적 자기지식 관념이 흔들린다. 좁은 내용을 내세워 이 문제를 비켜 가려는 시도는 버지식 논증과 직접지시 이론 앞에서 막힌다. 따라서 넓은 내용에 대한 특권적 접근이 어떻게 가능한지 직접 설명해야 한다.

## 연결
- 상위: [[42 자기지식 세미나는 외재주의와의 충돌에서 출발해 여러 이론 유형을 거쳐 투명성과 합리적 행위자성으로 나아간다]]
- 다음: [[42b 외재주의와 선험적 자기지식이 양립하는지는 양립론과 환원 논증과 느린 전환 논증이 부딪히며 가려진다]]
- 가지: [[42a1 외재주의는 심적 내용이 주체의 내재적 속성에 수반하지 않는다는 주장으로 읽힌다]]
- 가지: [[42a2 퍼트넘의 쌍둥이 지구 사고실험은 내재적으로 같은 두 사람의 말이 다른 뜻을 지닌다고 논증한다]]
- 가지: [[42a3 버지의 관절염 사고실험은 믿음의 내용도 언어 공동체의 쓰임에 따라 달라진다고 논증한다]]
- 가지: [[42a4 환경 외재주의는 세계의 대상과 속성에 기대고 사회적 외재주의는 언어 공동체의 쓰임에 기댄다]]
- 가지: [[42a5 버지식 논증이 성립하면 우리 심적 상태의 거의 모든 내용이 언어 공동체에 의존하는 넓은 내용이 된다]]
- 가지: [[42a6 좁은 내용을 현상적 내용으로 읽는 제안은 버지식 논증과 직접지시 이론에 막힌다]]
- 가지: [[42a7 포더는 좁은 내용을 환경에서 넓은 내용으로 가는 함수로 보지만 함수는 진릿값을 갖지 못한다]]
- 가지: [[42a8 좁은 내용이 없다면 넓은 내용에 대한 특권적 접근을 좁은 내용에 대한 접근으로 대신하는 길이 막힌다]]
- [[42a2 퍼트넘의 쌍둥이 지구 사고실험은 내재적으로 같은 두 사람의 말이 다른 뜻을 지닌다고 논증한다]]: 퍼트남의 사고실험을 정리한 카드이다.
- [[42a3 버지의 관절염 사고실험은 믿음의 내용도 언어 공동체의 쓰임에 따라 달라진다고 논증한다]]: 버지의 사고실험을 정리한 카드이다.
- [[42a8 좁은 내용이 없다면 넓은 내용에 대한 특권적 접근을 좁은 내용에 대한 접근으로 대신하는 길이 막힌다]]: 좁은 내용으로 우회하는 길이 막히는 이유를 정리한 카드이다.
- [[42b 외재주의와 선험적 자기지식이 양립하는지는 양립론과 환원 논증과 느린 전환 논증이 부딪히며 가려진다]]: 양립 여부를 둘러싼 논증들을 정리한 카드이다.
- [[57h2 내부화된 그림 앞에서 열리는 선택지는 회의주의와 무적의 이성과 하이브리드 지식 개념이다]] (전제): 외재주의가 던지는 특권적 접근의 문제는 내부화된 그림 앞에서 선택지가 갈리는 논의의 배경이다. (제안: Claude)
- [[38e1 트래비스는 환경을 얻으면 오류 가능성에 노출된다는 프레게의 말을 재발성에서 끌어낸다]] (전제): 외재주의는 내용이 내부만으로 정해지지 않는다고 보고, 트래비스의 오류 가능성 논점은 그 귀결로 읽힌다. (제안: Claude)
- 관련 주제(다른 묶음): 외재주의, 넓은 내용, 좁은 내용
