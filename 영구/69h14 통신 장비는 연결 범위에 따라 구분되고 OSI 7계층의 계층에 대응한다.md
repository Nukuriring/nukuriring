# 69h14 통신 장비는 연결 범위에 따라 구분되고 OSI 7계층의 계층에 대응한다

허브는 여러 대의 컴퓨터를 연결하고, 리피터는 디지털 통신 선로에서 약해진 신호를 증폭해 재생한다. 브리지는 같은 프로토콜을 쓰는 두 통신망을 연결하고, 라우터는 인터넷 접속에 반드시 필요하며 최적의 경로를 설정해 전송한다. 게이트웨이는 서로 다른 네트워크로 들어가는 입구로서 서로 다른 네트워크를 연결하고, 모뎀은 아날로그와 디지털 신호를 서로 변환해 전송한다. OSI 7계층은 네트워크를 계층별로 나누고 표준을 정의한 것이다. 물리 계층에는 허브와 리피터, 데이터 링크 계층에는 이더넷과 랜카드와 브리지와 스위치, 네트워크 계층에는 라우터와 IP, 전송 계층에는 게이트웨이와 TCP가 대응한다. 세션 계층은 송수신 측의 관련성을 유지하고, 표현 계층은 코드 변환과 데이터 암호화와 압축을 맡으며, 응용 계층은 사용자와 응용 프로그램이 접근하게 한다.
