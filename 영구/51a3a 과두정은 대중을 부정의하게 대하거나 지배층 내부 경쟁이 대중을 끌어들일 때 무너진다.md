# 51a3a 과두정은 대중을 부정의하게 대하거나 지배층 내부 경쟁이 대중을 끌어들일 때 무너진다

5권 6장은 과두정이 주로 두 방식으로 변화한다고 정리한다. 첫째는 지배자가 대중을 부정의하게 대하는 경우로, 관직 밖의 부유한 대중에서 파당이 일어나거나, 귀족들 안에서 파당이 일어난 틈을 인민이 타거나, 별다른 이유 없이 인민이 소수 지배를 용납하지 못하는 경우이다. 둘째는 내부에서 시작되는 변화이다. 귀족들이 경쟁심에서 인민을 정치에 끌어들여 정적을 제거하려 하거나, 지배자가 군중의 환심을 사려 하거나, 지배층 안에 또 다른 과두정을 만들려 할 때 내부 투쟁이 생긴다. 필기는 전시에 용병을 쓰게 되는 경우와 평시에 서로 불신해 군사권을 중간 계급에 맡겼다가 권력을 잃는 경우도 적는다.
