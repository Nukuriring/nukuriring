# 54j3 두 이야기가 동형적이어도 한 이야기가 다른 이야기 속에서 재현되면 동형성이 무너져 주제 공유에는 추가 정당화가 필요하다

영진은 대화 상대의 해석, 곧 이성계의 이야기와 극단의 이야기가 급진성이라는 주제를 공유한다는 명제에 불만을 가진다. 동형적인 구조는 보통 의미를 보존한다. 요소들이 일대일로 짝지어지고 배열도 서로 대응하므로, 여러 이야기가 동형적이면 대개 주제를 공유한다고 말할 수 있다. 한 이야기가 다른 이야기의 등장인물에 의해 재현될 때는 사정이 달라진다. 재현되는 이야기에는 재현하는 인물이나 집단의 서술적 목소리가 개입하고, 내화는 세계 속의 재현이라는 지위를, 외화는 재현이 이루어지는 세계라는 지위를 가져 두 이야기는 동등한 힘을 갖지 않는다. 이 순간 상정된 동형성이 무너지므로, 이성계의 이야기에서 급진성이 초래한 파국과 비슷한 일이 극단의 이야기에서 일어나더라도 거기서 곧바로 주제의 공유를 추론할 수 없다. 영진은 외화와 내화가 주제를 공유할 수 없다고 주장하지 않고, 동형성이 재현 관계로 훼손된 뒤에 주제 공유를 말하려면 추가 정당화가 필요하다고 주장한다. 그 정당화가 무엇인지는 별도의 탐구가 필요하다고 영진은 적는다.
