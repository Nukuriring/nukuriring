# 51a5a 참주정을 보존하는 방책은 피지배자를 왜소하게, 서로 불신하게, 행위 능력이 없게 만드는 세 목적을 가진다

5권 11장은 참주정을 보존하는 방법을 열세 가지로 나열한다. 돌출하는 사람을 잘라내고, 공동식사와 정치 클럽과 교육을 막고, 자부심을 낳는 것을 경계하며, 학파와 학문 동아리를 없애고, 거주 이동을 제한하고, 말과 발언을 감시하고, 피지배자를 갈라 서로 이간하고, 가난하게 만들고, 과도한 세금을 매기고, 여가를 없애고, 외부 분쟁을 계속 유발하는 것 등이다. 필기는 이 모든 방책이 피지배자가 스스로를 왜소하게 생각하게 하고, 서로를 철저히 믿지 못하게 하며, 행위하는 능력을 잃게 만든다는 세 목적을 가진다고 정리한다. 참주는 아첨꾼이 득세하는 가운데 편집증적으로 변해 가고, 이 방책은 모두 악하다는 평가가 붙는다.
