# 67c 데이터 마이닝의 정확도와 형평성의 충돌은 사회가 추구할 가치 질서를 다시 점검하라는 요청이다

영진은 발제 말미의 질문에서 데이터 마이닝이 일으키는 정확도와 형평성의 충돌이 이제 사회가 추구할 가치 질서를 다시 점검하라는 실질적 요청으로 부상했다고 쓴다. 알고리즘은 높은 예측력을 주면서 역사적이고 구조적인 차별도 정교하게 재현한다. 민감 속성을 지워도 우편번호, 학력, 소득 같은 대리 변수가 편향을 다시 부호화한다. 그래서 얼마만큼의 성능 저하를 감수하더라도 형평성을 확보해야 하는지를 물을 수밖에 없다고 영진은 본다. 그에게 중요한 물음은 정확도에 우선하는 가치가 무엇인지, 그 가치를 어떤 규범 틀로 인식할지 정하는 일이다. 모델의 정확도와 형평성을 동시에 만족시킬 수 없다면 원리적으로라도 선을 어떻게 그어야 하는지를 이어서 묻고, 몇 가지 규범 이론으로 엉성한 스케치를 시도한다.

## 연결
- 상위: [[67 딥러닝은 투명성과 공정성의 규범 선택 문제와 마음의 학습 모델이라는 두 물음을 낳는다]]
- 다음: [[67d 속성 선택의 비용 편익 기준은 오류가 덜 수익적인 집단에 몰릴 때 기업에게 오류를 고칠 유인을 주지 못한다]]
- 가지: [[67c1 규범 윤리 입장을 명시하면 설계의 투명성과 학제 간 공통 언어와 규제의 예측 가능성이 높아진다]]
- 가지: [[67c2 롤스적 차등 원리는 최소 수혜 집단에게 이익이 되는 수준까지 모델의 공정성을 희생하도록 허용한다]]
- 가지: [[67c3 공리주의는 사회 전체의 효용이 가장 커지는 공정성과 정확도의 가중치에서 상충을 정당화한다]]
- 가지: [[67c4 칸트적 원리는 모델이 인격을 도구로 만들 위험이 있으면 정확도 손실과 무관하게 상충을 허용하지 않는다]]
- 가지: [[67c5 센과 누스바움의 능력 접근은 집단별 핵심 역량의 훼손 여부로 정확도와 공정성 상충의 정당성을 정한다]]
- 가지: [[67c6 롤스와 공리주의와 칸트와 능력 접근은 정확도와 형평성의 상충을 평가하려고 서로 다른 정보를 먼저 정해야 한다]]
- [[51h1a5 프록시와 중복 부호화는 금지된 변수를 지워도 집단 소속이 다른 특징에 남게 하고 정확한 모델일수록 사회의 불평등을 정확히 재현한다]]: 민감 속성을 지워도 편향이 남는 이유를 논문 필기 쪽에서 설명한 카드이다.
- [[51h1g 저자는 데이터 마이닝의 차별을 오류 기반과 정확성 기반으로 나누고 정확성 기반 차별은 개별 기업의 책임으로 풀 수 없는 구조적 불평등의 반영이라고 본다]]: 정확도를 낮추어야만 차별이 줄어드는 역설을 저자의 결론으로 정리한 카드이다.
- [[52d3 콩은 사후에 편향을 걷어 내는 약한 공정성과 억압에 맞서 사회를 공정하게 만드는 강한 공정성을 구별한다]]: 공정성 논의가 기술적 교정에서 사회적 가치 선택으로 옮겨 가야 한다는 다른 주장과 견줄 수 있다.
- [[67c1 규범 윤리 입장을 명시하면 설계의 투명성과 학제 간 공통 언어와 규제의 예측 가능성이 높아진다]]: 질문이 이어지는 첫 단계로 규범 틀을 명시하는 일의 편익이다.
- [[51h1a4 특징 선택은 집단마다 분류의 정확도를 다르게 만들고 통계적으로 합리적인 판단이 동시에 불공정할 수 있다]] (다음 단계): 정확도와 형평성의 충돌이 구조적 불평등에서 나온다는 진단은 가치 질서를 다시 점검하라는 요청으로 이어진다. (제안: Claude)
