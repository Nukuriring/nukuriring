# 2c 트래비스는 looks에서 looking like와 looking as if를 구별한다

looks-indexing을 검증하려면 'looks'가 무엇을 가리키는지 정해야 하며, 트래비스는 일상 어휘 'looks'에 적어도 두 개념이 압축되어 있다고 본다. 첫째 개념인 looking like(LL)에서 'X가 Y처럼 보인다'는 X가 Y라면 보일 방식대로 보인다는 뜻이고, 이렇게 보이는 모습을 demonstrable look이라 부른다. 피아가 자매처럼 보이는 일이나 판 메이헤런(van Meegeren)의 그림이 페르메이르(Vermeer)의 그림처럼 보이는 일이 여기에 속하며, 이런 진술은 그것이 Y라는 결론을 함축하지 않는다. 둘째 개념인 looking as if(LAI)는 'It looks like it is a lemon'처럼 그것이 Y임을 시사하는 어법이다. 정교한 밀랍 레몬은 레몬처럼 보이지만, 판 메이헤런의 그림이 위작임을 아는 사람이 'It looks as if it is a Vermeer'라고 말하면 거짓을 말하게 된다. 대화 속 설명에 따르면 §4는 LAI가 face value를 고정할 수는 있어도 그 고정이 indicating 관계에 기대고 있음을 보이며, 맥도웰의 'ostensible seeing'을 두 개념을 섞은 개념으로 비판한다. 원자료의 정독은 §3에서 멈추었으므로 §4의 논증은 원문으로 다시 확인해야 한다.
