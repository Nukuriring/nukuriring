# 51h1b 차별적 취급 법리는 보호집단 변수를 직접 쓰는 형식적 차별과 마스킹만 포착하고 비의도적 메커니즘은 놓친다

필기에 따르면 차별적 취급은 비슷한 처지의 사람을 달리 대하는 형식적 차별과 차별 의도라는 두 갈래로 이루어진다. 모델이 인종이나 성별을 입력 변수로 쓰면 결과와 상관없이 분류 자체가 법적 해악이므로 책임이 생기지만, 실제 데이터 마이닝에서 이런 경우는 드물다. 마스킹은 알고리즘으로 이루어져도 위장이라는 점에서 차별적 취급의 전형이나 의도의 증명이 어렵다. 레이블, 수집, 특징 선택, 프록시에서 생기는 차별에는 의도나 동기가 없고 McDonnell-Douglas 틀은 의도가 있거나 차별이 없거나 둘 중 하나로 가르므로 책임이 생기지 않는다. 결과를 알면서 모델을 쓰는 경우도 지식과 의도가 서로 다른 심리 상태이므로 책임을 묻기 어렵고, 이 법리는 인간 결정자의 편견을 다루는 쪽에 맞추어져 있다고 필기는 정리한다.
