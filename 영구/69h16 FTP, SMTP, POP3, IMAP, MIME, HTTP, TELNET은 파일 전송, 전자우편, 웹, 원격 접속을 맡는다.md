# 69h16 FTP, SMTP, POP3, IMAP, MIME, HTTP, TELNET은 파일 전송, 전자우편, 웹, 원격 접속을 맡는다

FTP는 파일을 송수신하는 프로토콜이며 바이너리와 ASCII를 제공하고, 처리 능력이 없어 파일을 실행할 수 없으며 계정이 없어도 쓸 수 있다. 전자우편은 ASCII 코드로 전송한다. POP3는 메일 서버에서 사용자 컴퓨터로 받을 때 쓰고, SMTP는 컴퓨터에서 다른 사람 계정으로 보낼 때 쓴다. IMAP은 프로그램으로 메일 서버에 접근하게 하고, MIME는 멀티미디어 내용을 확인하고 실행시켜 준다. HTTP는 하이퍼텍스트 문서를 전송하는 프로토콜이고, TELNET은 다른 컴퓨터에 접속해 원격 제어하는 프로토콜이다.
