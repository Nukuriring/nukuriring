# 52d 알고리즘 공정성 지표는 분배 정의에 묶여 있어 구조적 억압과 비분배적 정의를 놓친다는 비판이 영의 논의에서 나온다

카시르자데(Kasirzadeh)와 콩(Kong)의 두 논문은 알고리즘 공정성의 수학적 지표가 재화를 집단들에 어떻게 나누는지에 관한 분배 정의의 관념에 기대고 있다고 본다. 두 논문이 이 관념에 맞서 끌어오는 자원은 영의 구조적 부정의 논의이다. 카시르자데는 구조적 부정의를 알고리즘 공정성의 범위에 넣어야 하는 이유를 논하고, 콩은 교차성을 속성의 교차로 이해하는 지배적 해석을 억압의 교차에 주목하는 해석으로 바꾸자고 제안한다. 두 논문이 같은 영의 틀을 쓴다는 연결은 카드 작성자가 짚은 것이다. 영진은 콩의 논문을 읽고 쓴 응답 글에서 하위집단 균등 접근이 지닌 장점과 한계를 평가했다.

## 연결
- 상위: [[52 사회정치 묶음은 억압과 권력과 인종과 알고리즘 공정성에서 정체성과 연대로 이어지며 영진의 유동적 객체 구상이 이를 하나의 모델로 모은다]]
- 다음: [[52e 영진은 정체성을 통치와 생존과 저항이 교차하는 장치로 읽고 이를 고장과 수리와 유지 보수라는 어휘로 옮겨 유동적 객체 이론을 세운다]]
- 가지: [[52d1 카시르자데는 알고리즘 공정성의 수학적 지표가 국소적 분배 정의에 묶여 구조적 부정의를 수용하지 못한다고 논한다]]
- 가지: [[52d2 콩에 따르면 교차적 공정성의 지배적 해석은 보호 속성의 조합으로 정의한 하위집단 사이의 통계적 균등이다]]
- 가지: [[52d3 콩은 사후에 편향을 걷어 내는 약한 공정성과 억압에 맞서 사회를 공정하게 만드는 강한 공정성을 구별한다]]
- 가지: [[52d4 영진은 PA의 장점을 개념적 단순성과 교차성의 도입과 정책 개입에 쓸 경성 데이터의 제공으로 정리한다]]
- [[52d1 카시르자데는 알고리즘 공정성의 수학적 지표가 국소적 분배 정의에 묶여 구조적 부정의를 수용하지 못한다고 논한다]]: 구조적 부정의를 알고리즘 공정성에 들이려는 카시르자데의 논문이다.
- [[52d2 콩에 따르면 교차적 공정성의 지배적 해석은 보호 속성의 조합으로 정의한 하위집단 사이의 통계적 균등이다]]: 하위집단 균등을 교차적 공정성의 지배적 해석으로 보고 비판하는 콩의 논문이다.
- [[52a1 영은 정의를 제도적 규범을 평가하는 관점으로 규정하고 의사결정과 분업과 문화로 초점을 옮긴다]]: 분배 패러다임을 떠나 정의의 범위를 넓히는 영의 논의이다.
- [[51h1 데이터 마이닝은 의도 없이도 과거의 편견과 불평등을 재생산하고 현행 고용차별법은 이를 효과적으로 규제하지 못한다]]: 데이터 마이닝이 편견을 재생산하는 경로를 다룬 법적 논의이다.
