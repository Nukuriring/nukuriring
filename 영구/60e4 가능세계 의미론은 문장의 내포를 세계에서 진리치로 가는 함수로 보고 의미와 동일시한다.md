# 60e4 가능세계 의미론은 문장의 내포를 세계에서 진리치로 가는 함수로 보고 의미와 동일시한다

의미론은 문장의 진리 조건을 주는 방식을 연구하며, 명제 양상 논리에서는 ⊥, →, □에 올바른 진리 조건을 부여해 복합 문장의 진리치가 부분에서 어떻게 정해지는지 설명한다. 내포 논리에서는 진리치가 세계에 상대적으로 할당되므로 세계들의 집합 W와 할당 함수 a의 쌍 ⟨W, a⟩가 기본 모델이다. W = {r, u, v}이고 g가 풀은 녹색이다, s가 눈은 녹색이다, d가 개는 애완동물이다일 때 ar(g) = T, ar(s) = F, ar(d) = T, au(g) = F, au(s) = T, au(d) = T, av(g) = T, av(s) = F, av(d) = F로 진리치를 할당하는 모델이 예로 주어진다. 문장 A의 내포 a(A)는 W의 원소에 진리치 T 또는 F를 할당하는 함수이고, 세계 w에서 A의 외연 aw(A)는 그 함수를 w에 적용한 특정 진리치이다. 가능세계 의미론은 이렇게 정의된 문장의 내포를 의미와 동일한 것으로 본다. ⊥와 →의 진리 조건은 aw(⊥) = F와 aw(A→B) = T iff aw(A) = F 또는 aw(B) = T이고, 다른 연결사의 진리 조건은 여기서 도출된다.
