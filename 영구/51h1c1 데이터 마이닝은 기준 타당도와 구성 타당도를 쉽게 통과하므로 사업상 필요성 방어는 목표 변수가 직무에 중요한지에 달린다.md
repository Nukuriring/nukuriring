# 51h1c1 데이터 마이닝은 기준 타당도와 구성 타당도를 쉽게 통과하므로 사업상 필요성 방어는 목표 변수가 직무에 중요한지에 달린다

필기에 따르면 EEOC 지침은 기준 관련 타당도, 내용 타당도, 구성 타당도의 세 검증을 요구하고 데이터 마이닝 모델은 기준 관련 타당도나 구성 타당도로 쉽게 검증된다. 목표 변수가 직무와 충분히 관련이 없으면 사업상 필요성 방어가 아예 실패하고, 필기는 범죄 전력을 암시하는 광고를 근거로 한 불리한 판단을 고용주가 정당화하기 어렵다는 예를 든다. 목표 변수가 직무와 관련 있다면 모델은 정의상 그 특성에 예측적이며 프록시 차별은 특성의 실제 분포를 반영하는 올바른 최적화의 결과이다. 반면 편향된 표본이나 잘못된 레이블에서 나온 모델은 오류가 결과를 충분히 왜곡할 때에만 직무 관련성이 약해진다. 법원이 지침의 검증 없이도 직무 관련성을 인정한 Ricci 판결과 상식에 기대는 경향 때문에, 필기는 정당한 직무 특성을 예측하는 모델이 이 방어로 책임을 면할 것이라는 결론에 이른다.
