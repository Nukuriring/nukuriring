# 52e9d 노트는 인프라가 없던 집단에도 고장과 우려와 수리의 궤적이 적용된다고 보고 억압 인프라를 음의 기능으로 읽어 음에서 영과 양으로의 이동을 말한다

노트는 정체성-인프라 모델이 인프라가 이미 갖추어진 뒤에만 작동한다는 반론을 상정한다. 1960년대 이전 흑인에게는 공간 지도도 프라이드 축제도 없었다는 점이 근거이다. 노트의 답은 넷이며 첫째로 정체성은 혜택이 아닌 삶을 짜는 형식이다. 분리 표지와 통행증과 동성애 처벌법도 공간, 의사소통, 법적 지위, 자원 흐름을 구획했으므로 부재와 배제와 감시도 기능이다. 둘째로 민권운동과 스톤월(Stonewall)과 장애 해방 운동은 없는 것을 새로 만드는 싸움 이전에 분리 버스나 군형법 같은 음수 기능을 영으로 되돌리거나 양수 기능으로 바꾼 과정이다. 셋째로 고장은 혜택이 끊긴 순간과 억압 인프라가 한계를 넘는 순간을 모두 포함한다. 넷째로 난민이나 무국적자처럼 주어진 코드가 없는 집단은 기능 없음 자체가 고장이다. 노트는 이 모델이 서로 다른 위치(음, 영, 양)에서 같은 고장, 우려, 수리의 궤적을 따르는 모든 집단을 설명한다고 정리한다.
