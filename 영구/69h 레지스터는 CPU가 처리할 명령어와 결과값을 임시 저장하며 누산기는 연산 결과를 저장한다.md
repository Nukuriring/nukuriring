# 69h 레지스터는 CPU가 처리할 명령어와 결과값을 임시 저장하며 누산기는 연산 결과를 저장한다

레지스터는 CPU의 구성 요소로서 CPU에서 처리할 명령어나 결과값 등을 일시적으로 기억하는 임시 기억 장소이다. 프로그램 카운터는 다음에 실행할 명령어의 번지를 기억한다. 명령 레지스터는 현재 실행 중인 명령의 내용을 기억한다. 누산기는 연산된 결과를 일시적으로 저장한다. 필기는 누산기를 이해하려면 먼저 레지스터가 무엇인지 이해해야 한다고 정리한다.

## 연결
- [[69h1 기억 장치의 접근 속도는 레지스터, 캐시, 램, 롬, SSD, HDD, 광디스크 순으로 느려진다]]: 레지스터를 가장 빠른 기억 장치로 놓는 접근 속도의 순서를 다룬다.
- [[69h25 클립보드는 데이터를 일시적으로 보관하는 임시 저장 공간이며 가장 최근 항목 하나만 기억한다]]: 같은 임시 저장 공간인 클립보드의 성질을 다룬다.
- 관련 주제(다른 묶음): CPU 구조, 레지스터
