# 42a2 퍼트넘의 쌍둥이 지구 사고실험은 내재적으로 같은 두 사람의 말이 다른 뜻을 지닌다고 논증한다

쌍둥이 지구(Twin Earth)는 물과 겉모습이 모두 같지만 분자 구조가 XYZ인 물질이 물을 대신하는 행성이다. 지구의 영어 단어 물(water)은 H2O를 가리키고 쌍둥이 지구의 같은 단어는 쌍둥이물(twater)을 가리키므로 두 단어의 지시가 다르고, 의미가 지시를 정하는 한 의미도 다르다. 분자 구조를 모르던 1750년대의 오스카와 쌍둥이 오스카는 보고 맛보고 느끼는 모든 면에서 내재적으로 같다. 그런데도 두 사람이 물은 축축하다고 말할 때 뜻하는 바가 다르다. 따라서 의미는 주체의 내재적 속성만으로 개별화되지 않고 넓다. 퍼트넘은 처음에 심리 상태는 좁아서 두 사람이 공유한다고 생각했다.

## 연결
- [[42a1 외재주의는 심적 내용이 주체의 내재적 속성에 수반하지 않는다는 주장으로 읽힌다]]: 이 사고실험이 겨누는 외재주의 주장의 정식화이다.
- [[42a3 버지의 관절염 사고실험은 믿음의 내용도 언어 공동체의 쓰임에 따라 달라진다고 논증한다]]: 같은 구조를 사회적 요인으로 바꾼 버지의 사고실험이다.
- [[42a4 환경 외재주의는 세계의 대상과 속성에 기대고 사회적 외재주의는 언어 공동체의 쓰임에 기댄다]]: 퍼트넘 유형과 버지 유형이 서로 다른 외부 조건에 기댄다는 구별이다.
