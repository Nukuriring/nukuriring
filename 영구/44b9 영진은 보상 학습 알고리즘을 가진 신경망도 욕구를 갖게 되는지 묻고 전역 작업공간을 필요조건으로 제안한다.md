# 44b9 영진은 보상 학습 알고리즘을 가진 신경망도 욕구를 갖게 되는지 묻고 전역 작업공간을 필요조건으로 제안한다

영진은 보상이론의 정의를 따르면 보상 학습 알고리즘을 가진 신경망도 욕구를 가진다고 보아야 하는 듯하다고 지적한다. 신경망이 욕구 같은 심적 상태를 가질 수 있는지는 논란이 있지만, 영진의 직관은 특정 표상을 전역 작업공간에 올리고 여러 입력을 모아 처리하는 능력이 심적 상태를 갖는 필요조건이라는 것이다. 응답문은 이를 욕구를 가지려면 통합된 주체성 같은 것이 작동할 여지가 있어야 한다는 말로 풀이한다. A&S의 정의에서 욕구는 보상 회로이므로, 이런 작업공간이나 주체성 없이도 욕구라는 상태를 가질 수 있게 된다.

## 연결
- [[44b3 보상이론은 내적 욕구를 보상 시스템이 어떤 사태의 표상에 양의 신호를 내도록 배선된 상태와 동일시한다]]: 지적의 대상이 되는 정의이다.
- [[44b8 영진은 욕구를 보상 신호로 환원하면 욕구가 이유 공간에서 맡던 정당화 기능이 상위 인지로 넘어가는지 묻는다]]: 같은 응답문의 둘째 물음이다.
- 관련 주제(다른 묶음): 전역 작업공간, 주체성, 인공 신경망의 심적 상태
