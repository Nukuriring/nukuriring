# 41q1 크릴은 복잡한 계산 시스템의 투명성을 알고리즘 투명성과 구조적 투명성과 실행 투명성의 세 종류 지식으로 나눈다

크릴(Creel)의 논의는 숙련되고 지식 있는 계산 시스템의 개발자와 사용자도 겪는 불투명성에 집중한다. 정보 은폐나 공개 부족, 사용자의 이해 부족에서 생기는 불투명성은 다루지 않는다. 크릴은 투명성을 세 종류의 지식으로 나눈다. 알고리즘 투명성(기능적 투명성)은 프로그램이 어떤 알고리즘을 예화하는지 아는 것이다. 구조적 투명성은 코드로 구현된 알고리즘의 구조, 곧 코드가 알고리즘을 어떻게 구현하는지 아는 것이다. 실행 투명성은 특정 하드웨어와 데이터 위에서 프로그램이 특정 인스턴스에서 실행된 방식을 아는 것이다. 영진의 정리에 따르면 크릴은 각 유형의 투명성이 다른 유형을 요구하지 않고도 드러날 수 있다고 명시적으로 주장한다.

## 연결
- 상위: [[41q 계산 시스템 투명성 논의는 법적 윤리적 차원과 불투명성의 원인과 투명성의 개념적 이해라는 세 지형으로 나뉜다]]
- 다음: [[41q2 실행 불투명성은 시스템이 정상 작동하는 동안에는 요점이 없고 정상 작동은 기능으로 규정되므로 그 요점은 기능적 투명성에 의존한다]]
- 가지: [[41q1a 크릴은 하드웨어와 입력 데이터가 만드는 아티팩트와 딥드림 사례로 실행 투명성이 독자적 범주라고 논증한다]]
- [[41q 계산 시스템 투명성 논의는 법적 윤리적 차원과 불투명성의 원인과 투명성의 개념적 이해라는 세 지형으로 나뉜다]]: 크릴의 분류가 놓인 투명성 논의의 지형이다.
- [[41q1a 크릴은 하드웨어와 입력 데이터가 만드는 아티팩트와 딥드림 사례로 실행 투명성이 독자적 범주라고 논증한다]]: 실행 투명성이 독자적 범주임을 보이는 크릴의 두 논증이다.
- [[41q2a 영진은 알고리즘 지식이 구조 지식과 실행 지식에 선행한다는 논증으로 크릴의 세 범주가 위계적이고 상호 의존적일 가능성을 보인다]]: 독립성 주장을 반박하는 영진의 논증이다.
- 관련 주제(다른 묶음): 기능적 투명성, 구조적 투명성, 실행 투명성
