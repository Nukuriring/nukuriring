# 45o 필기는 아크라시아의 문제를 두 전제에서 아크라시아가 불가능하다는 결론이 나오는 논증으로 제시한다

필기는 아크라시아(akrasia)를 더 나은 판단을 알면서도 그에 반하는 행동을 의식적으로 선택하는 일로 규정한다. 전통적 논증은 두 전제를 둔다. 하나는 사람이 더 원하는 것을 선택한다는 것이고, 다른 하나는 사람이 더 낫다고 판단한 것을 더 원한다는 것이다. 이 두 전제에서는 자신이 더 낫다고 판단한 것을 하지 않는 일이 있을 수 없다는 결론이 나온다. 그러나 금연이 최선임을 알면서도 담배를 피우는 경우처럼 아크라시아는 경험상 실재하므로, 두 전제를 그대로 두면 모순이 생긴다. 필기는 데이비슨이 두 전제를 버리지 않고 더 낫다고 판단한다는 개념을 정밀하게 구분하여 이 모순을 푼다고 정리한다. 이 필기는 외부 도구가 쓴 답변으로 보이는 문서여서, 원문과 대조하지 않은 요약이다.
