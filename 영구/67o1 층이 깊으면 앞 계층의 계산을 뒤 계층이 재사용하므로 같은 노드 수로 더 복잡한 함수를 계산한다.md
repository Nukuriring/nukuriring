# 67o1 층이 깊으면 앞 계층의 계산을 뒤 계층이 재사용하므로 같은 노드 수로 더 복잡한 함수를 계산한다

깊이를 늘린 구조의 핵심은 다층의 표현 학습이다. 1980년대에 단층 퍼셉트론에 은닉층을 하나 더한 것만으로 XOR처럼 선형 분리가 불가능한 함수를 구현할 수 있게 되었고, 그 뒤 더 깊이 들어가며 얻는 이점은 한층 미묘하다. 깊이의 이점은 복잡한 함수를 점진적으로 구성하고 입력 신호를 반복 변환해 학습과 추론의 계산 복잡도를 기하급수적으로 줄이는 데 있다. 버크너가 드는 sum-product network는 덧셈 노드와 곱셈 노드만으로 다항식을 계산하는 모델이다. 얕은 망은 식을 전개된 형태로 다뤄 모든 곱셈과 덧셈을 한 번에 수행해야 하므로 연산량이 급격히 늘어난다. 깊은 망은 하위 층에서 계산한 곱셈 결과를 상위 층에서 여러 번 재사용해 식을 인수분해된 형태로 계산한다. 버크너는 이 대비를 숙련된 기술자 한 명이 자동차를 처음부터 끝까지 수작업으로 조립하는 방식과 조립 라인에서 각 노동자가 맡은 작업을 하며 복잡한 특징을 점진적으로 조립하는 방식의 차이에 견준다.
