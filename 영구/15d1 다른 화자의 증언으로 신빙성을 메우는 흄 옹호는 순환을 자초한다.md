# 15d1 다른 화자의 증언으로 신빙성을 메우는 흄 옹호는 순환을 자초한다

청자가 화자 X의 증언이 사실로 드러난 사례를 직접 관찰하지 못했을 때, 다른 화자 Y의 증언으로 X의 신빙성에 관한 정보를 얻으면 된다는 흄 옹호는 순환을 전혀 고려하지 않은 응수이다. Y의 증언이 청자에게 지식이 되려면 Y의 신빙성도 인정되어야 하고, 반복 관찰이 없는 상황에서 Y의 신빙성은 다시 다른 화자 Z의 증언에 기대야 하기 때문이다. 이런 응수는 코디의 순환 비판을 스스로 불러들이는 이상한 논리 전개이다. 흄 쪽에는 이 의존 사슬을 끊을 더 설득력 있는 반론이 필요하다.
