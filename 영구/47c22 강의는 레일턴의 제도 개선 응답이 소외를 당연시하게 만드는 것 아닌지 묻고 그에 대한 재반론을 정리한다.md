# 47c22 강의는 레일턴의 제도 개선 응답이 소외를 당연시하게 만드는 것 아닌지 묻고 그에 대한 재반론을 정리한다

레일턴의 응답은 사회적, 정치적 제도를 개선하면 결과주의가 삶을 교란하는 정도를 줄이고 장기적으로 각자 세계를 개선하려는 것보다 나은 결과를 낳는다는 것이다. 질문은 개인적 목표를 이런 시각에서 바라보는 것이 이미 그로부터 소외된 것 아닌지, 제도가 마련되지 않은 상황에서 안정된 삶이 어려운 것 아닌지이다. 제도가 개인의 헌신을 당연시하게 만들어 결과주의의 요구가 지나치다고 느끼지 못하게 한다면 더 나쁜 것 아닌지, 삶의 중심이 되는 근본 계획의 확립이 좋은 삶의 객관적 요소 아닌지도 묻는다. 필기가 정리한 재반론은 사회 개혁이 근본 계획을 실현하게 돕는 사람의 수가 어렵게 만드는 사람의 수보다 클 것이며, 윌리엄스의 논리는 현재 덜 소외된 사람들에게 유리한 보수적 입장을 지지하게 된다는 것이다. 결과주의의 근본 가치는 가능한 많은 사람이 최선의 삶을 누리는 것이라고 필기는 쓴다. 마지막으로 불편부당한 목표를 공유하지 않는 사람이 도덕적으로 그르므로 비난받아야 하는지 질문이 남는다.
