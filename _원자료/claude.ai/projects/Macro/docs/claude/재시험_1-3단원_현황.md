## 배경

- 사용자가 학습 자료 I–III(고전학파 모형 세 편)을 받은 뒤 "1,2,3강 재시험 보고싶어"라고 요청했다(2026-10-06). 여기서 '1,2,3강'은 진단 평가의 1–3단원을 가리킨다.
- 형식은 진단 평가와 같다. 같은 템플릿으로 만든 별도 페이지이며, 단원마다 제출하고 객관식·계산·OX 판단은 즉시 채점, OX 이유와 서술형은 Claude가 채점한다.
- 숫자와 상황을 모두 바꾸고, 진단에서 약했던 고리에 문항을 더 배정했다. 성적표에 진단 점수(1단원 19/23, 2단원 19/29, 3단원 16/32) 칸과 백분율을 함께 보인다.
- 2판(2026-10-06): 1단원 채점 뒤 사용자가 "여전히 너무 어렵네"라고 했고, 2·3단원 서술형을 작은 물음으로 쪼개자는 제안에 동의했다("응응..."). R2-8과 R3-10(각 8점 서술)을 2점짜리 네 문항씩으로 나누었다. 새 유형 `short`(단답 서술, 3줄 입력, Claude 채점)를 템플릿에 추가했다. 배점 합계는 그대로이다.

## 검증

- 서브에이전트 한 개가 수치, 정답의 유일성, 사실, 학습 노트와의 일치, 문체를 대조했다. 정답과 수치 오류는 없었다.
- 반영한 주요 수정:
  - R2-8 모범 답안: 캉티용은 장기의 비례 관계도 그대로 받아들이지 않았다(경로에 따라 가격마다 오르는 폭이 다름). 흄만 장기 비례를 받아들인 것으로 고쳤다. 2판에서 R2-8d는 한 사람만 골라 쓰게 했다.
  - 케인스의 임금 인하 비판(R1-4 해설, R1-5 ㅂ, R1-6 모범 답안·채점 기준): '소득과 소비 감소' 논거를 교재 §2.9와 학습 II §6의 논거(명목임금 교섭, 케인스 효과의 차단, 물가 하락에 따른 기대 악화)로 바꾸었다.
  - R3-4 발문: 논리만으로 X가 되는 자기모순을 없앴다("실업자가 있다는 사실만으로도 … 판단할 수 있다").
  - R1-1: 프리드먼(1968)의 원래 진술(목표 합의, 양립 가능성, 수단의 역할)과 스노든·베인의 정리를 구별했다.
  - 그 밖에 R2-5 발문(처음에 통화량 일정), 노동수요량·노동공급량 용어, R2-7 ③ 해설, R3-8 해설의 단정 완화, 서술형 모범 답안의 문장 수.
- 페이지 동작: 로컬 렌더링에서 콘솔 오류와 가로 넘침이 없었고, 게시 뒤 `answers` 컬렉션을 읽어 저장소 연결을 확인했다. 2판에서 단답 서술의 입력, 제출, 채점 대기 표시를 로컬에서 확인했다.

## 채점 절차

- 진단 평가와 같은 db 스키마를 쓴다. 답안은 `answers/r1`~`answers/r3`, 채점 결과는 `grades/r1`~`grades/r3`에 쓴다: `{items:{"문항id":{score, max, comment}}, summary, gradedAt}`. OX는 `max: 2`, 서술형은 `max: 8`, 단답 서술(`short`)은 `max: 2`.
- 사용자가 "재시험 N단원 제출했어"(또는 "N강 채점좀")라고 하면 `answers/rN`을 읽어 각 문항의 `rubric`으로 채점한다. 요약(summary)에는 진단 점수와 비교한 변화와, 진단 약점이 해소되었는지를 쓴다.
- 문항 원본: 세션 작업 폴더의 `retest/data.js`와 `retest/template.html`(1판은 `data_v1.js`, `template_v1.html`). 사라졌으면 아티팩트를 `Artifact read`로 읽어 HTML 안의 `ITEMS` 배열을 쓴다.
