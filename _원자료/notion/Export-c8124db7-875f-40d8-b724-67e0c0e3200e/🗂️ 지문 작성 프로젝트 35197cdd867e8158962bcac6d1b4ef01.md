# 🗂️ 지문 작성 프로젝트

## 개요

수능·LEET 철학·인문 지문 출제 작업 공간입니다.

각 지문 작업은 아래 프로세스 보드에서 단계별로 관리합니다.

---

## 프로세스

| 단계 | 설명 |
| --- | --- |
| 자료 조사·정리 | 원자료 발굴·수집·명제 추출·자료 노트 산출 (philo-source) |
| 지문 초고 | 자료 노트를 입력으로 지문·문항·해설 작성 (philo-passage) |
| 문항 설계 | 선지·보기·배점 확정 |
| 검토 | 출제 기준 점검·교열 |
| 완료 | 최종 납품 |
