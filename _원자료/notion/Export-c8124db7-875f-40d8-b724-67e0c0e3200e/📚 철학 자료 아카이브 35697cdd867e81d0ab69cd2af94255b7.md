# 📚 철학 자료 아카이브

철학 공부에서 모은 발제·정리·응답·기말논문·강의노트와 외부 참고문헌의 통합 아카이브.

## 구조

이 페이지에는 두 개의 **DB**와 두 개의 **인덱스 페이지**가 있습니다.

### 📊 DB (자료 본체)

- **참고문헌 라이브러리** — 외부 PDF·도서·스캔본·이미지 (1,122개). 메타데이터만 (위치 색인용).

[철학 자료 마스터](%F0%9F%93%9A%20%EC%B2%A0%ED%95%99%20%EC%9E%90%EB%A3%8C%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%EC%B2%A0%ED%95%99%20%EC%9E%90%EB%A3%8C%20%EB%A7%88%EC%8A%A4%ED%84%B0%2027c33d25dfbd47c0be2ece3747dec80d.md)

- **철학 자료 마스터** — 본인이 직접 쓴 글 (302개). 본문 추출되어 노션에서 검색·인용 가능.

### 📂 인덱스 페이지 (탐색 가이드)

[📂 분야별 가이드](%F0%9F%93%9A%20%EC%B2%A0%ED%95%99%20%EC%9E%90%EB%A3%8C%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%F0%9F%93%82%20%EB%B6%84%EC%95%BC%EB%B3%84%20%EA%B0%80%EC%9D%B4%EB%93%9C%2035797cdd867e81728cd8dc1e59212b3f.md)

- **분야별 가이드** — 분석철학·고대·메타윤리 등 18개 분야로 두 DB를 동시에 탐색

[👤 인물별 가이드](%F0%9F%93%9A%20%EC%B2%A0%ED%95%99%20%EC%9E%90%EB%A3%8C%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%F0%9F%91%A4%20%EC%9D%B8%EB%AC%BC%EB%B3%84%20%EA%B0%80%EC%9D%B4%EB%93%9C%2035797cdd867e81da8fccd5883ca12d7c.md)

- **인물별 가이드** — Cavell·Plato·Kant 등 인물별로 본인 글 + 외부 자료 함께 모임

## 사용법

- **분야별 / 인물별 가이드**에서 헤딩을 펼쳐 자료 모음을 한눈에
- 각 row의 **원본경로** 속성으로 디스크의 원본 파일 경로 확인 (절대경로)
- 마스터 DB의 row를 클릭하면 추출된 본문이 페이지 안에 들어 있음 (검색·인용 가능)
- 라이브러리 DB는 메타만 — 원본 PDF는 디스크에서 열어볼 것

## 검토 필요

- 일부 row의 `검토 필요` 체크박스가 ON: 동일 파일명이 여러 폴더에 있거나 정체가 모호한 항목
- 비철학으로 보이는 라이브러리 row는 분야 미배정 + 파일명 키워드(`민법`, `경제학` 등)로 필터링해 일괄 삭제 가능
