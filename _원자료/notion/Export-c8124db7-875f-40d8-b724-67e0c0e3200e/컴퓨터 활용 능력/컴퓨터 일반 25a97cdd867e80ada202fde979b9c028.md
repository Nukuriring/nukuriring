1. 누산기

누산기가 무엇인지 이해하기 위해서는 먼저 레지스터가 무엇인지 이해할 필요가 있다. 레지스터는 CPU의 구성 요소로 **CPU에서 처리할 명령어나 결과값 등을 일시적으로 기억하는 임시 기억 장소이다.**

레지스터의 종류로 다음과 같은 것이 있다.

(1) 프로그램 카운터: 다음에 실행할 명령어의 번지를 기억한다.

(2) 명령 레지스터: 현재 실행 중인 명령의 내용을 기억한다.

(3) 누산기: 연산된 결과를 일시적으로 저장한다.

IP 주소에는 IPv4가 있고, IPv6가 있다.

일단 공통적인 특징으로:

IP 주소는 중복되지 않는다.

숫자로 8비트씩 4부분, 총 32비트로 구성된다.

A 클래스에서 E 클래스까지 총 5단계로 구성되어 있다.

IPv6는 v4가 가지는 주소 부족 문제를 해결하기 위해 개발되었으며, 16비트씩 8부분, 그래서 총 128비트로 구성되어 있다.

호환성, 확장성, 융통성, 연동성이 뛰어나다. 주소는 유니캐스트, 애니캐스트, 멀티캐스트 3종류의 형태로 분류한다.

- 멀티미디어 데이터

(1) 이미지 데이터 표현 방식

**비트맵 방식,** 픽셀을 통해 이미지를 표시. 

계단 현상 발생, 사실감 있는 사진을 빠르게 표현할 수 있다.

ex) jpeg: 손실, 무손실 둘 다 지원. 압축률이 좋고 조정 가능하지만 고주파 이미지 불리함. 

GIF: 무손실 지원, 움직이는 256색 표현, 투명 배경 지, 

PNG: 무손실 지원, 투명 배경 지원(알파)

 

**벡터 방식:** 

선과 곡석을 벡터 식으로 계산해서 표현하기 때문에 계단 현상이 발생하지 않으며, 메모리를 적게 차지한다.

ex) ai, wmf 등 파일

(2) 오디오 데이터

**샘플링:** 

저장 간격을 좁게 잡으면 원음과 가까워 지고, 멀리 잡으면 달라진다.

샘플링 레이트: 초당 샘플링 횟수.

오디오 파일 크기 계산법: 샘플 추출률 x 샘플 크기 x 채널(모노, 스테레오) x 시간 → 크기가 계산이된다.

ex)

WAV: 무손실, 무압축 방식(크기가 크다)

MP3: MPEG-1의 압축 방식을 사용하여 압축률이 높음

FLAC: 무손실 압축 방식

AIFF: 애플에서 개발한 무손실 무압축

MIDI: 컴퓨터와 전자악기 간의 통신규약. 시퀀싱 가능. 16개 악기 동시 연주 가능. 연주 정보만 저장되므로 크기가 작음. 

(시퀀싱: 음악제작)

구성 형태

(1) 스타형, 성형, 집중형

중앙 노드와 1대1로 연결, P2P. 

중앙 제어 장치에 의해 신뢰성 좌우. 고장 발견, 유지 보수, 확장이 쉽다.

(2) 버스형

한개의 회선에 여러 단말 장치 연결.

회선 양 끝에 종단 장치 필요

단말 장치 하나가 고장 나도 전체 영향 없음.

기밀성이 낮고, 통신회선의 제한이 있다.

(3) 링형, 루프형, 원형, 환형

인접한 단말기를 서로 연결

양방향 전송 가능

통신망 하나가 고장나면 전체 마비

단말 장치 추가, 제거 기밀보호 어려움

(4) <트리형, 계층형, 분산형

나뭇가지 모양으로 계층적 연결

분산처리 시스템 구성 방식

확장이 많으면 트래픽 과중

(5) 망형, 매쉬형, 그물형, 완전형

모든 지점의 단말기를 연결

응답시간이 빠르고 연결성이 높다

통신량 많을 수록 유리.

확장이 어렵고. 회선 장애시 다른 경로로 전달 가능.

- 규모에 따른 분류

LAN: 근거리 통신망

- 학교, 회사, 연구소 등 건물이나 지역 내에서 사용하는 네트워크
- MAN: 도시간 통신망
    - 도시, 대단위 아파트 단지 등을 대상을 구성하는 통신망
- WAN: 광대역 통신망
    - 국가와 대륙, 전 세계에 걸쳐 형성되는 통신망
- ISDN: 종합 정보 통신망
    - 전화, 데이터, 화상 등 모든 정보의 교환과 전송을 디지털 통신망에서 가능하게 한 것
- VAN: 부가가치 통신망
    - 회선을 빌려서 통신처리와 같은 기능을 붙여 제 3자에게 재판매하는 통신망
- INtranet: 기업 내 통신망
    - 조직 내부의 업무를 위해 사용되는 통신망
- Extranet: 인트라넷 확장
    - 인트라넷을 확장하여 납품업체나 고객업체 등 관련 있는 기업들 간의 원활한 통신을 위한 시스템
- WLAN: 무선랜
    - 무선접속 장치가 설치된 곳을 중심으로 초고속 인터넷을 사용할 수 있는 근거리 통신

- 통신 장비와 프로토콜

(1) 통신 장비

허브: 여러 대의 컴퓨터를 연결하는 장치

리피터: 디티절 통신 선로에서 감쇠된 전송 신호를 증폭하여 신호를 재생하는 장치

브리지: 같은 프로토콜을 사용하는 2개의 통신망을 연결하는 장치

라우터: 인터넷을 접속할 때 반드시 필요한 장비 최적의 경로를 설정하여 전송하는 장비

게이트웨이: 서로 다른 네트워크로 들어가는 입구, 서로 다른 네트워크를 연결하는 장치

모뎀: 아날로그를 부호화하여 디지털로 변환하거나 디지털을 복호화하여 아날로그로 변환시켜 통신신호를 전송함. 

(2) 프로토콜

정보를 주고 받기 위해 무엇을, 어떻게, 언제 통신할 것인지를 정한 통신규약.

프로토콜의 주요 기능: 흐름 제어: 패킷 흐름을 조정하여 안정성 유지(패킷: 데이터 통신에서 다루어지는 데이터 단위)

동기화: 송/수신이 같은 상태를 유지

오류 제어: 전송 중 발생한 오류를 검출, 복원하는 것.

표준 프로토콜

TCP: 메시지를 송 수진의 주소와 정보로 묶어 패킷 단위로 나눈다. 흐름 ㅔ어, 데이터 에러 검사

IP: 패킷 주소를 해석하고 경로를 결정하여 다음 호스트로 전송

FTP: 파일, 송수신 프로토콜 - BInary ASCii 제공, 처리 능력이 없어서 파일을 실행할 수 없음.

계정이 없어도 사용할 수 있음

전자우편: ASCII 코드로 전송. 

POP3: 메일 서버에서 사용자 컴퓨터로 수신하기 위해 쓰는 프로토콜

SMTP: 컴퓨터에서 다른 사람 계정으로 송신

MIME: 멀티미디어 내용을 확인하고 실행시켜 줌

IMAP: 메일 서버에 프로그램을 이용하여 액세스

HTTP: 하이퍼텍스트 문서를 전송하기 위한 프로토콜

TELNET: 다른컴퓨터에 접속하여 원격제어 할 수 있는 프로토

- IP주소와 도메인

자동주소: DHCP

수동주소: IP, 서브넷접두사(서브넷마스크), 게이트웨이, DNS

도메인: IP 주소를 문자로 표현한 인터넷 주소.

URL: 자원 위치를 나타내는 표준 주소 체계

형식) 프로토콜:// 호스트주소(도메인) 포트번호 파일경로

- 국제 인터넷 주소 관리 기구 or KISA에서 관리
- 도메인의 실제 주소 확인: 시작-cmd-NSLOOKUP.

DNS - 문자 도메인을 숫자 IP로 변환

- 정보통신 용어

네트워크를 계층 별로 나누고 표준을 정의한

OSI 7계층

(1) 물리 계층: 허브, 리피터

(2) 데이터 링크 계층: 이더넷, 랜카드, 브리지, 스위치

(3) 네트워크 계층: 라우터, IP

(4) 전송 계층: 게이트웨이, TCP

(5) 세션 계층: 송수신측의 관련성을 유지

(6) 표현 계층: 코드 변환, 데이터 암호화, 압축

(7) 응용 계층: 사용자, 응용 프로그램 접근
