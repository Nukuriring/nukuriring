## 4. 표기 규칙

- `[p. N]`은 인쇄본 N쪽이 시작되는 위치이며, EPUB에 들어 있는 쪽 대응표(page map)에서 가져왔다. 인쇄본 쪽수로 인용할 때 그대로 쓸 수 있다.
- 각주 표지는 `[^n]`이고, 주석 본문은 파일 끝의 `## Notes`에 모았다. 주석 번호는 강의마다 새로 시작한다.
- 원문의 이탤릭(책 제목, 외국어)은 `*…*`로 남겼다.
- **연표**: `3. Chronology`의 표는 `- **연도** 사건` 형식의 목록으로 옮겼다.
- **표와 그림**: 표 5.1, 5.2 등 일반 표는 Markdown 표로 옮겼다. 그림 13개는 `img/` 폴더에 이미지 파일(`fig05-1.jpg` 등)로 저장하고, 본문의 해당 위치에 캡션과 함께 연결했다. 11강의 멩거 욕구 척도표는 번호 없는 이미지 표여서 `img/lec11_menger-table.jpg`로 저장했다.
- 각 md 파일 머리에는 영어로 된 메타데이터(출처, 쪽수, 절 목록, 인접 파일, 단어 수, 처리 방식)를 두었다.

## 5. 폴더 구조

```
BackhouseTribe2018_History-of-Economics/
├─ 00_파일안내.md             이 문서
├─ summaries/                 강의별 정리글 (lec00 서론, lec01–09 작성), 중간 보고 mid09
│   └─ img/                   정리글 그림: 강의별 하위 폴더 lec00/ ~ lec09/, 중간 보고 mid09/ (PNG와 그림 스크립트)
└─ source_md/                 정제 텍스트 (정리글 작성용)
    ├─ 00_front-matter.md     판권면, 강의별 쪽수와 파일명을 붙인 목차
    ├─ 00_introduction_…md    서론
    ├─ lec01_…md ~ lec24_…md  24강 (4강은 두 파일)
    ├─ img/                   그림 이미지 14개
    └─ manifest.json
```

## 6. 함께 읽을 자료

- 19강(케인스 혁명), 20강(현대 거시경제학), 21강(인플레이션과 필립스 곡선)은 스노든·베인 『Modern Macroeconomics』의 2~7장, 백하우스 『Interpreting Macroeconomics』(1995)의 8~10장과 같은 시기를 다룬다. 이 세 강의는 사상사의 관점에서 쓴 짧은 개관이므로, 두 책을 읽기 전에 지도로 삼기 좋다.
- 14강(화폐경제학)과 17강(케인스)은 스노든·베인의 2장, 백하우스 1995의 5~7장(홉슨, 워커, 미국 제도학파)과 연결된다. 16강(로빈스)은 백하우스 1995의 9장에 나오는 로빈스식 선험주의를 이해하는 배경이 된다.
