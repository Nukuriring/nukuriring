## How to compile into one essay

Concatenate in this order: `01` → `02` → `03` → `04`. Each file is a single `#` H1 chapter with `##` sections beneath, so the result reads as one continuous document. (`00` is the index and can be dropped from the compiled essay or kept as a front-matter map.)

Quick command (run in the folder): `cat 0[1-9]_*.md > _Compiled_Essay.md` (or list explicitly: `cat 01_*.md 02_*.md 03_*.md 04_*.md 05_*.md > _Compiled_Essay.md`)
