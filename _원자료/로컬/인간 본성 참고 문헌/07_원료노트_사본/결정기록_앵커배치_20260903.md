# 인간 본성(천현득 2016) — 앵커·배치 결정 기록 (2026-09-03)

## 원천
- 천현득, 「포스트휴먼 시대의 인간 본성」, 『철학』 126(2016), 157-182. 단일 저본(원료 노트 생략, 소스 혼입 금지 — 영진 지시).

## 결정
1. **앵커 = 수특 p96 기원 본질주의(EBS27-HA-11-01)**. p88 종차별은 2027 9평 [4~9]가 (가)로 밀착 사용해 배제.
2. **배치 = 1안(이중 걸기)**: ¶1 정의문 = 인간 본성 본질주의(앵커 KEY '본질·속성·정체성' 재출현, 이감 단일 표준형) + 〈보기〉 = 수특 96 크립키 알파/베타 논증 축약(2026 수능 실물 형태). 천현득 verdict(비가단성)는 본문 착지 귀속형.
3. 오카샤 '경첩'은 도입 진입 장치로 쓰지 않음(실물에 논리 경첩 없음). 관계적 본질주의는 논문 마디로만 유지 — 〈보기〉 대질 재료(계통=기원으로 종 소속 결정 ↔ 개체 기원 본질).

## 근거(실물)
- 평가원: 2026 수능 칸트(저본 확장+〈보기〉 앵커) · 2027 6평 형평(앵커 축약 재서술이 (나) 말미 2문단) · 2027 9평 종차별((가) 밀착+(나) 별도 논문). 공통 = 앵커는 정의문·(가)·말미·〈보기〉 중 한 자리에 통째/축약 재출현, 새 내용은 별도 저본, 추론 경첩 없음.
- 이감 단일 28편: ⓐ밀착 재구성(드레이·정의주의·데닛·토대론·예악론) / ⓑ¶1 정의문 앵커+가지 교체(물리주의→잭슨, 스피노자→셰퍼, 쾌락주의→노직, 상대주의→맥팔레인, 인격동일성→업로딩).

## 회피 경보
- 이감 2023_061 = 인간 향상 (가)후쿠야마·더글러스/(나)해리스·페르손·사불레스쿠 → 향상 찬반(광역 수준)·후쿠야마 도입 금지. 보스트롬·포스트휴먼 도입도 2023_058·2025_003 기출.
- 평가원 2014 6평 B형(코퍼스 단일 [31]) 본질주의↔반본질주의: "반드시 가져야만 하고 다른 대상과 구분해 주는 속성" · "모든 X에 대해 그리고 오직 X에 대해서만" · 까투리 예 · 갓난아이 반례(사람=이성적 동물). → E1 정의문 문구 변주 필수, 이성 능력 예시 회피.

- 시즌6 5회차(파핏 비동일성)도 수특 96 앵커 — 회차 배분은 영진 판단.

## 원천 spine(마디 + 전환 강제)
- M0 훅: 향상 찬반 양측이 인간 본성을 전제(후쿠야마·카스 / 사불레스쿠) → 도전1(과학 양립)·도전2(규범 역할). ※기출 반복 위험, 훅으로 쓰지 않음.
- M1 본질주의 E1~E4 + 기능 4종(서술·분류·설명·규범). → "이 기능을 감당하는가"가 이후 전 마디의 잣대.
- M2 다윈주의적 도전: 생물종≠자연종(마이어 개체군 사고), 공시·통시 변이 → 본질주의는 서술 일부만, 분류·설명·규범 불가. 대안 조건 2(반론 회피+기능 수행).
- M3 관계적 본질주의(오카샤): E3 포기, 계통 관계 → 분류만 → 본성 관점 아님. 인간과학은 서술·설명이 핵심 → 잣대 재조정(분류 못 해도 서술·설명 하면 대안).
- M4 법칙론적 관점(마셔리): 대부분 공유+진화 결과(적응 한정 아님) → 서술 O·분류 X(의도적)·설명 독특·규범 X. 비판(다형성 배제·진화/문화 이분법) → 램지 LTC(가능한 인간만 서술, 지나치게 느슨).
- M5 인과 본질주의(사무엘스): HPC종 H1~H3, 본성=설명항(기저 메커니즘) → 설명 O·분류 X·규범 X, '이중 서술' 주장은 착각(천현득 판정).
- M6 소결: 다목적 개념 부재, 맥락별 다수 개념.
- M7 규범 역할: 뷰캐넌 제거 논증(HN·T·N→C1·C2) vs 공통분모 비가단성(윌슨) → 광역/국소 구분 → 국소 수준에서 역할(변경 비용·위험 정보, 사실-규범 연결).

## 분절 후보(영진 픽 대기)
- A안(개념 축 6문단, 추천): M1 → M2 → M3 → M4(램지 삭제 또는 1문장) → M5 → 착지 M6+M7 비가단성 1~2문장 귀속형. 〈보기〉 앵커(개체 기원 본질)와 M3 계통 결정이 대질.
- B안(개념 4 + 규범 2): M1 → M2 → M4·M5 압축 → M7 뷰캐넌 → 비가단성·국소. 오카샤 삭제(〈보기〉 대질 재료 소실).
- 분량 기준: 이감 단일 1,240~1,590자·5~6문단 / 2026 수능 단일 1,252자·6문단.

## 개정(09-03 후속 — 영진 반려 반영)
- 〈보기〉 이중 걸기 보류(〈보기〉는 지금 생각하지 않음). **연계 실체 = 본문 ¶1 한 문단**이 수특 96을 받는다.
- 주제의식 = 주장이 아니라 교육 축: '인간 본성' 한 낱말에 겹친 세 층위 ⓐ필연(본질)·ⓑ전형(완고)·ⓒ당위를 구별하게 한다. 백화점식 서베이(오카샤·램지·기능 4종 표 나열) 폐기.
- **¶1 구성 확정**: 수특 96 문장("대부분의 사람들은 자신이 인간 이외의 다른 어떤 것도 될 수 없다고 생각한다. 하지만 이것은 단지 내가 본질적으로 인간이라는 속성을 가지고 있다는 것을 말하는 것일 뿐이다")을 그대로 받아, 메타 발화 없이 곧장 "그렇다면 인간이라는 종의 본질, 곧 인간 본성은 무엇인가"로 넘긴다. '수특은 침묵했으니 우리가 묻는다'식 친절 설명 금지.
- 문단 골격: ¶1 앵커 수용·물음 / ¶2 본질주의(ⓐ→ⓒ 결합) / ¶3 다윈 도전(ⓐ 붕괴) / ¶4 오카샤 계통(앵커 회수, ⓐ≠ⓑ) / ¶5 마셔리·사무엘스(ⓐ 없는 ⓑ, ⓑ↛ⓒ) / ¶6 뷰캐넌→비가단성(ⓑ→ⓒ 차단, 국소 개입). 분량 초과 시 ¶5·¶6 병합.

## 최종 확정(09-03 컨펌) — 이전 절의 앵커·골격을 대체한다
- **앵커 = 수특 299(실전 2회, 업로딩/체화)**. 수특 96은 폐기. 연계 실체 = ¶1이 수특 299 문장을 재서술: "인간의 신체가 지닌 한계가 극복될 수 있다 … 인간의 본질은 뇌에 구현된 알고리즘과 계산적 구성" / "생물학적 신체의 속박에서 벗어나 인지나 신체 능력을 훨씬 쉽게 향상". 키워드 접점 = 본질·신체의 한계·능력 향상·보스트룀. ⚠수특 299는 김성연 1회차 배정 — 회차 배분은 영진 판단.
- **시점 = 윤리학자**(구름 중심: 응용윤리 현역). 형이상학(본질주의 E1~E4·오카샤·마셔리·사무엘스·램지)은 전부 제거, 다윈 도전은 ¶2 안 2문장.
- **탐구 주제(우산 물음)** = "인간 향상 논쟁에 기여할 수 있는 인간 본성 개념은 어떤 것인가". 주장이 아니라 탐구.
- **골격(4~5문단)**: ¶1 앵커·훅(보스트롬 vs 카스, 양측 본성 전제) → ¶2 본질주의적 본성 = 기준 제공 방식, 다윈 이후 존재하지 않음 → ¶3 진화적 본성(뷰캐넌 정의) = 존재하나 T·N으로 기준 못 줌, 뷰캐넌 제거 결론 → ¶4 재반론 = 기여 방식 오상정, 비가단성(뷰캐넌 자인) → 광역/국소, 정보 제공이 기여 → ¶5 착지·회수(도출≠기여, 신체 한계 극복 = 어떤 한계를 얼마의 대가로). ¶4·¶5 병합 가능.
- **인물** = 보스트롬(훅)·카스(훅)·뷰캐넌. 후쿠야마 금지(이감 2023_061). 향상 찬반은 훅·회수에만.
- **가제** = 「인간 본성은 인간 향상에 반대하는 근거가 되는가」(1순위) / 「인간 향상 논쟁에서 본성에 호소하는 논증」.
- **회피**: 이감 2023_061(향상 찬반·후쿠야마·더글러스), 2023_058·2025_003(보스트롬·포스트휴먼 도입 — 보스트롬은 앵커 키워드라 1문장 허용), 2014 6평 본질 정의 문구.
- 다음 = philo-mold(원천 spine 위 골격 = 선행 요약, 마디 대응표 작성).
