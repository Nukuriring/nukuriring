# 카드 작성 지침 (Claude 작업용)

`00 안내.md`의 규칙을 전제로 하고, Claude가 원자료에서 카드를 만들 때 지켜야 할 세부 규칙을 적습니다.

## 1. 작업 단위

- 1단계(자료별): 원자료를 읽고 `문헌/`에 문헌 노트를 쓰고, `_작업/후보/<그룹>.md`에 영구 노트 후보를 씁니다. 이 단계에서는 루만 번호를 붙이지 않습니다.
- 2단계(통합): 후보를 모아 중복을 합치고, 번호를 붙여 `영구/`에 카드를 쓰고, 구조 노트와 색인을 갱신합니다.

## 2. 문헌 노트

- 텍스트 한 편(논문, 책의 장, 강의)마다 하나를 만듭니다. 파일명은 `@저자연도 짧은제목.md`입니다. 예: `@Travis2004 The Silence of the Senses.md`
- frontmatter의 `read_via`에 그 텍스트를 공부한 원자료를 적습니다.
- '논증 구조'는 번호 매긴 단계로 재구성합니다. 원자료에 없는 단계를 지어내지 않습니다.
- '영진의 독해 메모'에는 영진 님이 원자료에서 직접 한 질문, 반론, 해석만 옮깁니다. 출처(날짜)를 붙입니다.
- 이미 같은 citekey의 문헌 노트가 있으면 새로 만들지 않고 해당 절에 내용을 보탭니다.

## 3. 후보 파일 형식

```
## C01 주장을 담은 제목 문장
- voice: 문헌 | 영진 | 종합
- 근거: [[@Citekey 제목]] 절·쪽; [[_원자료/경로]] (날짜)
- 관계 제안: C03의 다음 단계 / C02에 대한 반론 / 다른 주제 '…'와 대조
- 본문:
  3~8문장
```

## 4. 정확성

- 철학적 내용은 원자료에 근거해야 합니다. 원자료에 Claude의 설명만 있고 원문 확인이 안 되는 내용은 근거 줄에 '(대화 속 설명)'이라고 밝힙니다.
- 쪽수, 절 번호, 인용문은 원자료에 실제로 있는 것만 씁니다. 인용은 원어 그대로 짧게 씁니다.
- 저자의 주장과 해석자의 재구성을 구별합니다.

## 5. voice 판정

- `영진`: 영진 님이 대화의 사람 발화나 직접 쓴 글(Notion 발제·에세이 등)에서 스스로 밝힌 주장만 해당합니다. Claude가 제안하고 영진 님이 받아들이기만 한 내용은 `종합`으로 둡니다.
- `종합`: 둘 이상의 텍스트를 엮거나, 원자료에 없던 연결을 새로 제안한 카드입니다.
- `문헌`: 한 저자의 주장을 정리한 카드입니다.

## 6. 링크 형식

- 원자료: `[[_원자료/claude.ai/chats/파일명]]`, `[[_원자료/로컬/폴더/파일명]]` (확장자 생략)
- Notion: 마크다운 링크 `[제목](https://app.notion.com/p/…)`
- 문헌 노트: `[[@Citekey 제목]]`

## 7. 문체

카드는 영진 님이 다시 꺼내 읽을 글이므로 아래 규칙을 따릅니다.

- 문장은 서술어와 종결어미로 끝냅니다. 명사구나 연결어미로 문장을 끝내지 않습니다(목록 항목과 제목은 예외).
- 조사와 어미를 생략하지 않고, 의미 있는 문장 성분을 생략하지 않습니다. 보조사 '의'를 겹쳐 쓰지 않습니다. 예: '사본의 문구는 작업의 상황을' → '사본에 기재된 문구는 작업이 진행되는 상황을'
- 맥락에 맞는 한자어를 쓰고, 조사와 어미로 어휘 사이의 관계를 드러냅니다. 예: '지출 비용 추론 용도의 함수의 오류 상황에서' → '지출한 비용을 추론하는 함수에 오류가 발생하면'
- 일반 어휘 자리에 비유적 어휘를 쓰지 않습니다. 예: '분석의 흐름' → '분석의 방향성'
- 엠대시(—)를 쓰지 않고 콜론이나 접속사로 관계를 밝힙니다.
- 'A가 아니라 B' 형태의 구절과 전개를 쓰지 않습니다. 주장은 긍정형으로 바로 쓰고, 대립하는 입장은 '연결' 절에서 별도 카드로 잇습니다.
- 명사화를 줄이고 용언으로 끝맺습니다. 행위자를 주어로 세웁니다. 관형절은 한 겹까지만 씁니다. 문두 접속부사는 절제합니다.
- 가르치려 드는 어조, 많이 아는 티를 내는 어조를 피합니다.
- 고유명과 전문 용어는 정착된 번역어가 있으면 그것을 쓰고 처음 나올 때 원어를 병기합니다. 정착된 번역어가 없으면 원어를 그대로 씁니다.
