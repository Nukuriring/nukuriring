# P2 분할 반영 결과

- 42f3a → 42f3a1: 제목 바꿈 없음. 12문장을 7문장(예시와 두 관점의 구별)과 3문장(명제 태도 식별)으로 나눔. 새 번호는 42f3a 아래 가지.
- 44c3 → 44c3a: 제목 바꿈(실망 사례만). 원 카드는 실망 사례, 새 카드는 데카르트의 밀랍 맛 사례. 원 카드 첫 문장은 "두 가지 반례" 대신 "첫째 반례"로 고침.
- 48p2 → 48p2a: 제목 바꿈 없음. 앞 7문장은 원 카드, 책임과 삶 전체의 평가(3문장)는 새 카드.
- 48q1 → 48q1a: 제목 바꿈(20세기 단일론과 발전론 구도). 강성훈의 점진적 발전론은 새 카드로, 귀속을 위해 "강의에서"를 유지.
- 48r2 → 48r2a: 제목 바꿈(의심하는 인물 배치). 전략적 거짓말은 새 카드로(voice 종합 유지).
- 48r3 → 48r3a: 제목 바꿈(극장 비유와 메타극). 인식과 반전, 비극과의 연결은 새 카드로(voice 종합 유지).
- 53i8 → 53i8a: 제목 바꿈(인판스 콘셉투스와 실종 이론). 능력 규정과 괴물과 법인은 새 카드로, 첫 문장에 "필기에 따르면" 귀속을 보탬.
- 53n3 → 53n3a: 제목 바꿈(종류별 형상과 좋음의 개념). 세 존재자 구분은 3문장 새 카드로(초안이 지적한 대로 짧음).
- 61a5 → 61a5a: 제목 바꿈 없음. 세 문제와 뜻의 도입은 원 카드, 지칭 표현 분류와 지시체와 외연과 이름 이론은 새 카드로. 새 카드 sources는 원 카드처럼 빈 목록.
- 61a7 → 61a7a: 제목 바꿈(동음이의와 다의와 유의). 반의어와 상하 관계와 부분 관계는 새 카드로, 마지막 우려 사항 문장은 원 카드에 남김.
- 63z → 63z1: 제목 바꿈 없음. 현재 본문(voice 종합, 주어 '공저 논문은') 기준으로 나눔. 치료적 기획의 성격 4문장과 voice 사유 문장은 원 카드에 두고, 전쟁과 공허한 소망 4문장은 새 카드로 옮겨 voice 사유 문장을 양쪽에 붙임. 새 카드 첫 문장은 '이 만족'을 풀어 씀. 63z의 aliases는 그대로 둠.

공통: 새 카드는 모두 status 초안, created 2026-10-13, verify류와 aliases 없음. 원 카드 파일 이름은 바꾸지 않아 H1과 파일명이 다른 카드가 7장 있음(제목이 바뀐 44c3, 48q1, 48r2, 48r3, 53i8, 53n3, 61a7). 새 카드의 상위 링크는 현재(옛) 파일명을 가리키므로 나중에 스크립트로 맞춰야 함.
