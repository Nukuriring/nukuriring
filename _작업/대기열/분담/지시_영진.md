# 영진 voice 부분 판정 카드 검토 노트 지시

목표: 영진 voice 카드 가운데 근거 대조에서 '부분' 판정을 받은 카드마다, 영진 님이 한 화면에서 판단할 수 있도록 문제 문장과 원문 대목을 나란히 모읍니다. 카드는 고치지 않습니다.

먼저 `_작업/영진 카드 근거 대조 지침.md`를 읽습니다. 카드마다 '부분' 판정 사유는 `_작업/검증/영진카드_*.md` 표의 메모 칸에 있습니다(Grep으로 `| <id> |`를 찾습니다. `영진카드_합치기후.md`가 있으면 그쪽이 최신입니다).

카드마다 할 일:
1. 카드를 읽고, 메모가 지적한 문제 문장을 카드에서 그대로 옮깁니다.
2. 카드의 `## 출처`를 따라 원자료에서 해당 대목을 찾아 원문 그대로 옮깁니다(300자 이내). Notion 원자료는 문단 하나가 한 줄이라 Read가 줄을 자르므로, Grep `-o`와 `.{0,300}어구.{0,300}` 패턴으로 읽습니다.
3. 문제 유형을 하나 고릅니다: `한정어 탈락`(원문의 유보가 단정이 됨) · `타 저자 논지 혼입`(다른 저자의 주장이 영진 주장처럼 들어옴) · `귀속 불확실`(영진 님 발화인지 강의자·Claude 발화인지 불분명) · `과잉 일반화` · `기타`.
4. 처리 선택지 초안을 씁니다: (가) 수정안 문장(원문 강도에 맞춘 고친 문장), (나) voice를 문헌·종합으로 바꿀 경우 그 이유. 둘 중 무엇을 권하는지 한 줄.

출력: 지시받은 결과 파일 한 개에, 모든 카드를 마친 뒤 Write 한 번으로 씁니다. 형식:

```
---
type: 작업
---
# 영진 부분 판정 검토 <묶음 이름>

## [[<카드 파일명>|<id>]] · <문제 유형>
- 카드 문장: "…"
- 원문(<원자료 이름>): "…"
- 차이: 한 문장
- 수정안: "…"
- voice 변경 시: 문헌 | 종합 | 해당 없음, 이유
- 권고: 수정 | voice 변경 | 그대로 둠
- [ ] 수정안 채택 - [ ] voice 변경 - [ ] 그대로 둠 - [ ] 직접 고침
```

규칙:
- 원문은 글자 그대로 옮기고 고치지 않습니다. 찾지 못하면 '원문 못 찾음'과 Grep한 어구를 적습니다.
- 학번·금액 같은 개인 정보는 옮기지 않습니다.
- 문장은 '~다' 평서형, 엠대시 금지.
- 카드, 원자료, 다른 파일은 고치거나 쓰지 않습니다. 결과 파일만 씁니다.
- 최종 답신은 200자 안팎으로 카드 수와 권고별 개수만 적습니다.
