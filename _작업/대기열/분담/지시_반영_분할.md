# 길이 초과 카드 분할 반영 지시

영진 님이 `_작업/대기열/분할초안/L*.md`의 '분할' 권고를 승인했습니다. 배정된 카드를 초안대로 나눕니다. 먼저 `_작업/작성 지침.md`(카드 형식, 번호 체계, 제목 규칙, 문체 §7)와 `00 안내.md`의 번호 규칙을 읽습니다.

카드마다 할 일:
1. 초안 파일에서 그 카드의 절(`## [[<id> …|<id>]] … → 권고: 분할`)을 찾아 새 카드 구성(제목, 본문, 문장 대응)을 읽고, 지금 카드 파일을 읽습니다. 초안을 만든 뒤 카드가 바뀌었으면(제목·본문이 초안의 원문과 다르면) 지금 본문을 기준으로 같은 나눔을 다시 적용합니다.
2. **원 카드**: 본문을 첫째 새 카드의 본문으로 바꾸고, 제목(H1)이 첫째 새 카드의 제목과 다르면 H1도 바꿉니다(맨 앞 번호 유지). 초안이 제목 교환이 필요하다고 적은 경우(예: 20f9, 20f11)는 원 카드가 지금 제목의 주장을 유지하도록 나눔 순서를 정합니다.
3. **새 카드**: 번호를 정합니다. 초안의 번호 후보를 쓰되, `영구/<번호> *.md`를 Glob해 이미 있으면 같은 줄기의 다음 빈 번호를 씁니다(가지는 원 카드 번호 뒤에 문자나 숫자를 하나 붙임: `20f9` → `20f9a`, `7g` → `7g1`처럼 번호 체계의 교대 규칙을 따름). 파일 `영구/<번호> <제목>.md`를 Write로 만듭니다. frontmatter는 원 카드에서 `id`(새 번호), `type`, `voice`, `status: 초안`, `tags`, `sources`, `cluster`, `group`을 옮기고 `created: 2026-10-13`을 씁니다. `verify`류와 `aliases`는 넣지 않습니다. 본문 아래에 `## 연결`을 두고 `- 상위: [[<원 카드 파일명>]]`과 `- [[<원 카드 파일명>]]: 같은 카드에서 나뉜 앞부분이다.` 같은 근거 한 줄을 넣고, 원 카드의 `## 출처` 절을 그대로 옮깁니다.
4. 원 카드의 `## 연결` 끝에 `- [[<새 카드 파일명>]]: 이 카드에서 나뉜 뒷부분이다.` 한 줄을 더합니다.

규칙:
- 원 카드는 Edit로, 새 카드는 Write로 씁니다. Bash로 파일을 쓰지 않습니다. 원 카드 파일 이름은 바꾸지 않습니다(나중에 스크립트가 맞춤). 제목에는 `\ / : * ? " < > | # ^ [ ]`를 쓰지 않습니다.
- 초안에 없는 내용을 보태지 않습니다. 각 카드는 3~8문장입니다. voice와 귀속 표현, 한정어를 지킵니다. '~다' 평서형, 엠대시 금지.
- status가 `검토됨`·`다시씀`인 카드는 건너뜁니다.
- 결과 파일(지시받은 경로)에 카드마다 `- <원 id> → <새 id들>: 제목 바꿈 여부, 한 줄 설명`을 씁니다.
- 최종 답신은 200자 안팎으로 나눈 카드 수, 새로 만든 카드 번호, 문제만 적습니다.
