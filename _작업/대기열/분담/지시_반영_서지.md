# 서지 후보 반영 지시

영진 님이 `_작업/대기열/서지 후보/<묶음>.md`의 후보 반영을 Claude 판단에 맡겼습니다. 문헌 노트마다 확신도에 따라 서지를 채웁니다.

노트마다 할 일:
1. 후보 파일의 그 노트 절과 문헌 노트(`문헌/<이름>.md`)를 읽습니다.
2. 확신도 **높음** 후보: 문헌 노트의 해당 항목(frontmatter 필드나 본문의 서지 줄)에 값을 채우고, 그 항목에 붙은 '확인 필요' 표시를 지웁니다. 노트 맨 아래(또는 기존 서지 절)에 `- 서지 확인(2026-10-13, 웹): <URL>` 근거 줄을 더합니다.
3. 확신도 **중간** 후보: 값을 넣되 '확인 필요' 표시는 남기고 `(후보: <값>, <URL>)`처럼 후보임을 밝힙니다.
4. **낮음**, '못 찾음', '특정 불가', '조사 대상 없음': 노트를 고치지 않습니다.
5. 후보가 노트의 기존 값과 충돌하면(예: 연도가 다름) 기존 값을 지우지 않고 `(웹 확인 값: …)`을 덧붙이고 '확인 필요'를 남깁니다.

규칙:
- 문헌 노트만 Edit로 고칩니다. 파일 이름(`@저자연도 제목`)은 바꾸지 않습니다. 카드와 원자료는 고치지 않습니다.
- 후보 파일에 없는 값을 새로 만들지 않습니다. 웹 검색도 다시 하지 않습니다.
- 결과 파일(지시받은 경로)에 노트마다 `- <노트 이름>: 채움 N항목 | 후보로 둠 N | 그대로`를 씁니다.
- 최종 답신은 200자 안팎으로 처리 수와 '확인 필요'가 사라진 노트 수만 적습니다.
