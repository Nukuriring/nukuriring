# 서지 확인 후보 지시

목표: 문헌 노트 가운데 '확인 필요' 표시가 남은 노트마다, 비어 있거나 추정한 서지 항목(저자, 연도, 원제, 출판사·학술지, 판본, 쪽수 범위, 국역본)의 후보를 웹 검색으로 찾아 표로 정리합니다. 문헌 노트는 고치지 않습니다.

노트마다 할 일:
1. 문헌 노트를 읽고 '확인 필요'가 붙은 항목과, 노트가 이미 아는 정보(제목, 저자 추정, 수업명 등)를 정리합니다.
2. WebSearch로 후보를 찾습니다. 출판사, 학술지, PhilPapers, JSTOR, 도서관(국립중앙도서관, RISS, KCI), 저자 홈페이지 같은 믿을 만한 곳을 우선합니다. 노트 하나에 검색은 3번 안팎으로 합니다.
3. 항목마다 후보 값, 근거 URL, 확신도(높음: 공식 서지에서 확인 / 중간: 2차 출처 / 낮음: 추정)를 적습니다. 찾지 못하면 '못 찾음'과 시도한 검색어를 적습니다.
4. `@미상 …` 노트(저자를 알 수 없는 필기)는 내용으로 원전을 특정할 수 있을 때만 후보를 적고, 아니면 '특정 불가'로 둡니다.

출력: 지시받은 결과 파일 한 개에, 모든 노트를 마친 뒤 Write 한 번으로 씁니다. 형식:

```
---
type: 작업
---
# 서지 후보 <묶음 이름>

## [[<문헌 노트 파일명>]]
- 노트의 '확인 필요' 줄: "…"
| 항목 | 노트의 현재 값 | 후보 | 확신도 | 근거 |
|---|---|---|---|---|
- [ ] 후보 채택 - [ ] 일부 채택 - [ ] 보류
```

규칙:
- 후보는 검색 결과에서 확인한 것만 씁니다. 기억에 기대 서지를 만들어 내지 않습니다. 확인하지 못한 값은 비워 둡니다.
- 문장은 '~다' 평서형, 엠대시 금지.
- 문헌 노트, 카드, 다른 파일은 고치거나 쓰지 않습니다. 결과 파일만 씁니다.
- 최종 답신은 200자 안팎으로 노트 수, 확신도 높음 후보 수, 못 찾은 노트 수만 적습니다.
