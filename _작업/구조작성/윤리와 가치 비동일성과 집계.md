# 윤리와 가치 비동일성과 집계

이 구조 노트는 파핏의 비동일성 문제와 그 응답들, 그리고 개인 단위의 평가와 전체 단위의 평가가 갈라지는 집계 문제를 다룬 카드들을 엮습니다. 줄기는 여섯 개입니다. 비동일성 문제와 비인격적 총합 원리(1), 광의 원리와 평가적 어림(2), 권리와 문턱과 비교 없는 해악으로 해악 개념을 고치는 시도(3), 가드너의 존재 설명(4)을 차례로 읽습니다. 이어서 같은 평가 문제가 무한한 인구에서 나타나는 홍과 러셀의 논의(5)와 슈팅룸의 위험 평가(6)를 읽습니다. 필멸을 다룬 뢰브의 논증(25l)은 [[윤리와 가치 의지와 좋은 삶]]에 두었습니다. 묶음 H1의 25부터 25k3까지를 모두 반영했습니다.

## 1. 비동일성 문제와 총합 원리
1. {25}: 선택이 누가 존재할지를 바꾸면 해악 기반 판정이 막힌다는 비동일성 문제의 진입 카드
2. {25a}: 협의 인격 영향 원리를 결과 층위와 행위 층위로 나누는 파핏 2017의 정식화
3. {25b}: 비동일성 문제를 정체성 영향과 존재 선호의 두 전제로 정리하는 목광수의 독해
4. {25c}: 총합 원리가 문제를 풀지만 혐오스러운 결론을 함축한다는 첫 대안의 평가
5. {25c1}, {25c2}: 미래 세대 정책에서 두 난점이 딜레마를 이룬다는 정식화와, 롤즈의 정의로운 저축 원칙이 둘을 함께 피한다는 평가

## 2. 광의 원리와 평가적 어림
1. {25d}: 존재하게 되는 일이 내재적 이익일 수 있다고 보는 광의 원리의 출발점
2. {25d1}: 광의 원리를 집합 차원과 개별 차원으로 나누어 혐오스러운 결론을 피하는 이원 구성
3. {25e}: 평가적 어림과 비이행성으로 연속체 논증의 전제를 기각하는 파핏 2016의 길
4. {25e1}: 임계 수준 견해가 혐오스러운 결론을 피하는 대신 다른 난점을 낳는다는 평가

## 3. 해악 개념의 수정: 권리, 문턱, 비교 없는 해악
1. {25f}: 처지의 변화로 환원되지 않는 권리 침해로 잘못을 설명하는 우드워드의 길
2. {25g}, {25g1}: 기본 수준에 못 미치는 처지를 해악으로 보는 마이어의 문턱 개념과, 이를 임계 수준 견해와 층위로 대조하는 종합
3. {25h}, {25h1}: 나쁜 상태를 야기하는 일을 해악의 충분조건으로 삼는 하만의 설명과, 대안이 있을 때만 생기는 그름을 설명하지 못한다는 채펠의 반론

## 4. 가드너의 존재 설명
1. {25i}: 당사자의 존재를 반사실 조건문의 전건에 넣어 해악을 정의하는 존재 설명
2. {25i1}: Dim Vision을 흐린 시야와 잘 보지 못함이라는 두 조건문으로 처리하는 방식
3. {25i1a}, {25i1b}: Dim Vision이 개선점을 보여 주지 못한다는 영진 님의 지적과, 상태 술어에 따라 판정이 뒤집힐 수 있다는 부담
4. {25i2}: 경로를 밝히는 조건문으로 비교 세계를 정하는 비동일성 적용
5. {25i3}, {25i4}: 해악이 불가피할수록 가하지 않을 이유가 약해진다는 필연성 원리와, 총합 이론이 비인격적 가치에 개입한다는 지적

## 5. 무한 집계: 사전적 파레토와 상태별 우월성
1. {25j}: 무한한 인구에서 사전적 파레토와 상태별 우월성이 충돌한다는 진입 카드
2. {25j1}, {25j2}: 같은 표를 가로로 읽느냐 세로로 읽느냐에 따라 판정이 갈리는 사례와, 개인에게는 무차별하지만 모든 상태에서 한 선택지가 우월한 사례
3. {25j3}: 네 원리가 사람 축과 상태 축에서 쌍대를 이룬다는 정리
4. {25j4}, {25j5}: 사전적 파레토를 버리면 개인이 가치의 그릇이 되는 대가와, 나머지 세 원리를 버리는 길의 대가

## 6. 위험과 집계: 슈팅룸
1. {25k}: 개인의 사망 확률은 36분의 1 이하인데 사망자는 참가자의 약 90퍼센트인 슈팅룸의 진입 카드
2. {25k1}: 90퍼센트라는 수치가 종료 사건과 무관한 산수라는 점
3. {25k2}: 개인의 사전 위험이 주변분포여서 사회적 평가에 필요한 결합분포를 정하지 못한다는 점
4. {25k3}: 에르고딕성 논변이 파산 확률의 합이 발산할 때만 확실한 파산을 낳는다는 조건

## 줄기를 가로지르는 실
- **혐오스러운 결론**: {25c} → {25d1} → {25e} → {25e1} (총합 원리의 귀결에서 광의 원리, 평가적 어림, 임계 수준 견해로 이어지는 응답의 계열)
- **기준선**: {25e1} → {25g} → {25g1} (임계 수준과 문턱이 같은 기준선을 다른 층위에 쓴다는 대조로 이어짐)
- **해악의 정의**: {25g} → {25h} → {25h1} → {25i} → {25i1a} (문턱 해악에서 비교 없는 해악을 거쳐 존재 설명과 그 비판으로 이어짐)
- **비인격적 가치**: {25c} → {25i4} (총합 원리가 지는 부담에서 가드너의 지적으로 이어짐)
- **사전과 사후**: {25j4} → {25k2} (사전적 파레토를 버리는 대가에서 사전 위험이 평가에 쓸모가 있는지의 문제로 이어짐)
- **재참가 금지**: {25k3} → {25l7} (슈팅룸의 조건에서 필멸과의 유비로 이어짐)
- **향상 논쟁**: {25} → {26} (존재할 사람을 바꾸는 선택이라는 점에서 향상 논쟁과 이어짐)
