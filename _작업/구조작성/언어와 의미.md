# 언어와 의미

이 구조 노트는 '언어와 의미' 클러스터의 개요입니다. 카드가 240장이므로 하위 구조 노트 셋으로 나누었고, 이 노트는 어디에서 어떤 순서로 읽기 시작하면 되는지를 안내합니다. 클러스터는 트래비스의 상황 민감성과 프레게 독해(6번, 7번, 38번 줄기), 논자시 준비로 읽은 의미론 고전(8번 줄기), 지칭과 허구와 오스틴의 언어철학(9번 줄기)으로 이루어집니다. 61번 줄기(의미론 입문 필기, 언어분석)는 원자료 처리가 중단되어 진입 카드 `61`이 없고 {61a}부터 {61a9}까지 열 장만 반영되었습니다. 그래서 이 줄기는 일부만 반영된 상태로 두고, {61a}를 임시 진입점으로 씁니다.

## 1. 하위 구조 노트
1. [[언어와 의미 트래비스의 상황 민감성과 오스틴]]: 그라이스의 말해진 것 개념에 대한 1985년 비판, 성숙기 의미관과 영진 님의 해석, 오스틴의 낱말 의미론·진리론·수행문 논의, 르카나티와의 대립(카드 약 40장)
2. [[언어와 의미 트래비스의 프레게 독해]]: 『Frege: The Pure Business of Being True』의 1·2장, 4~6장, 8장을 읽은 카드와 박정일 대조, 사고의 개별화, 굴절 논쟁 부록(카드 약 90장)
3. [[언어와 의미 의미론의 고전과 지칭]]: 의미론 입문 필기, 프레게·러셀·콰인·에이어·그라이스, 허구적 이름, 단칭 명제와 지표사, 고유명 논의, 구조적 합리성 논문 구상(카드 약 110장)

## 2. 줄기의 진입 카드
1. {6}: 트래비스의 1985년 논문에서 시작하는 상황 민감성 줄기의 진입 카드이다. 하위 노트 1에서 읽는다.
2. {6m}: 같은 6번 줄기에서 프레게 독해가 시작되는 자리이다. 하위 노트 2의 1절에서 읽는다.
3. {7}: 프레게 독해의 참임 논의(8장)로 들어가는 진입 카드이다. 하위 노트 2에서 읽는다.
4. {38}: 사고의 공공성(4장)에서 시작하는 정독 줄기의 진입 카드이다. 하위 노트 2의 7절부터 읽는다.
5. {8}: 프레게에서 콰인까지 의미를 묻는 단위가 넓어지는 과정을 세우는 고전 줄기의 진입 카드이다. 하위 노트 3의 2절에서 읽는다.
6. {9}: 직접 지칭 의미론이 받는 두 압력을 세우는 지칭·허구 줄기의 진입 카드이다. 하위 노트 3의 6절에서 읽는다.
7. {9c}: 오스틴의 낱말 의미와 진리론 가지의 진입 카드이다. 하위 노트 1의 3절에서 읽는다.
8. {61a}: 61번 줄기의 임시 진입점이다. 하위 노트 3의 1절에서 읽는다.

## 읽는 순서에 대한 제안
- 상황 민감성이 궁금하면 하위 노트 1에서 시작합니다. 1985년 논문의 귀류({6d})와 성숙기 정의({6j1})를 먼저 읽고, 오스틴의 진리론({9c3})과 이어서 보면 계보가 드러납니다.
- 프레게 독해를 처음 따라간다면 하위 노트 2의 1절에서 3절까지(1·2장)를 읽고, 8장의 참임 논의({7})와 4~6장({38}, {38i}, {38j})로 넘어갑니다. 사고의 개별화와 단칭 사고({7f})는 영진 님의 입장이 모인 곳입니다.
- 고전 의미론은 하위 노트 3에서 입문 필기({61a})로 용어를 잡은 뒤 프레게와 러셀({8})에서 콰인과 에이어, 그라이스 순서로 읽으면 됩니다. 허구와 지칭({9})은 그 뒤에 읽습니다.
- 영진 님의 입장이 직접 담긴 카드는 {6k}, {6k1}, {6k2}, {7f}, {7f3}, {7g3}, {38i5a}, {9d1}, {9d6c1}입니다.

## 클러스터 안에서 겹치는 곳
- 6m과 7b, 6m3과 38c, 7d와 38i5는 1장, 8장, 4장, 5장에서 같은 논점을 다시 다룹니다. 하위 노트 2의 '정리 후보'에 기록했습니다.
- 8a의 뜻 도입과 9b의 인지적 가치 논증, 8b4a1과 9d3의 지칭 실패 문장 처리는 하위 노트 3에서 짝으로 읽습니다.
- 7h의 고유명 논의와 7f3의 단칭 사고 논의는 서로 다른 하위 노트에 있지만 같은 비판(트래비스의 사고 개별화)을 공유하므로 함께 읽습니다.
- 6a의 그라이스 장치와 8e의 그라이스 의미 분석은 하위 노트 1과 3에 나뉘어 있으므로 8e2를 먼저 읽은 뒤 6a로 가면 비판의 표적이 분명해집니다.
- 오스틴의 {9c4}는 지각의 철학 줄기의 {1d}와 같은 논의를 다룹니다.
