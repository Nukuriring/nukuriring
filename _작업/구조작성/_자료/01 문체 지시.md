# 구조 노트 문체 통일 지시 ('~니다' → '~다')

영진 님이 구조 노트 문체를 '~다' 평서형으로 맞추기로 했습니다(2026-10-13). 배정받은 원본(`_작업/구조작성/<이름>.md`)마다 다음을 합니다.

- 문장 끝의 '~습니다/~ㅂ니다'를 같은 뜻의 '~다' 평서형으로 바꿉니다. 예: 다룹니다 → 다룬다, 읽습니다 → 읽는다, 시작합니다 → 시작한다, 됩니다 → 된다, 입니다 → 이다, 있습니다 → 있다, 없습니다 → 없다, 나눴습니다 → 나눴다, 적었습니다 → 적었다, 좋습니다 → 좋다. 동사와 형용사의 활용을 구별합니다(읽는다 / 좋다).
- '~하십시오', '~하세요' 같은 권유형은 '~한다' 또는 '~하면 된다'로 바꿉니다.
- 내용, 순서, `{번호}` 자리표시자, `[[링크]]`, frontmatter, 제목(#)은 바꾸지 않습니다. 문장 끝 말고는 고치지 않습니다.
- 다 고친 뒤 `python3 _작업/스크립트/render_hub.py . <고친 원본들>`로 렌더링해 `UNKNOWN ID`·`MISSING LINK`가 없는지 확인합니다. `grep -c '니다\.' <파일>`이 0이 될 때까지 고칩니다(인용문 안의 '니다'는 그대로 둠).
- 배정받지 않은 파일, 카드, 문헌 노트는 고치지 않습니다. git, struct.py, merge_index.py는 실행하지 않습니다.
- 최종 답신은 처리한 파일 수와 남은 '니다' 수만 적습니다.
