# AI와 윤리

이 구조 노트는 'AI와 윤리' 클러스터의 개요이고, 카드가 45장이어서 하위 구조 노트를 나누지 않았다. 자료는 영진 님의 기말 논문 「실행 투명성과 정상 작동」, Barocas와 Selbst 논문 발제(NH1 묶음의 67a~67e), 버크너의 『Deep Learning: A Philosophical Introduction』 발제(67n~67u)이다. 줄기는 넷이다. 투명성과 책임(1)과 정확도와 형평성(2)은 딥러닝을 사회에 배치된 시스템으로 보는 쪽이고, 딥러닝의 구조와 성공(3)과 딥러닝과 마음(4)은 딥러닝을 마음의 모델로 보는 쪽이다. 두 쪽은 모델의 내부를 어떻게 이해하고 평가할 것인가라는 물음에서 만난다. 처음 읽는다면 진입 카드 {67}에서 시작한다. 같은 논문을 다룬 선행 카드가 다른 묶음에 있어서 겹침을 마지막 절에 기록했다.

## 1. 투명성과 책임
1. {67}: 두 방향(사회에 배치된 시스템, 마음의 학습 모델)을 안내하는 진입 카드(종합)
2. {67a}: 불투명성이 평가와 구제를 어렵게 해 책임 소재의 쟁점이 된다는 문제 제기. 기말 논문 서론에 해당한다.
3. {67a1}, {67a2}: 투명성을 인식론적으로 읽는 두 논자, 설명 대신 예측을 주는 딥러닝에서 얻는 이해의 본성과 이상화된 모델로 가능한 설명적 이해
4. {67b}: 기말 논문의 중심 주장, 달성 방법이 결여한 지식에 달려 있다는 결론
5. {67b1}, {67b2}: 계산 현상학의 방법론적 제안과 그 근거가 되는 메를로퐁티의 베르트하이머 실험 분석
6. {67b3}, {67b4}: 영진 님이 유도 제약과 구조적 상수를 읽는 방식, 딥드림 사례로 정상 작동의 이탈을 보이는 대목
7. {67e}: 정상 작동을 정하는 일과 정확도와 형평성의 상충을 정하는 일을 사실 지식과 명시적 규범 선택의 결합으로 묶는 종합 카드. 1절과 2절을 잇는다.

## 2. 정확도와 형평성
1. {67c}: 정확도와 형평성의 충돌을 사회가 추구할 가치 질서의 점검 요청으로 읽는 발제의 물음
2. {67c1}: 규범 윤리 입장을 명시하는 일의 효과
3. {67c2}, {67c3}, {67c4}, {67c5}: 롤스, 공리주의, 칸트, 센과 누스바움이 상충을 각각 어디에서 정당화하거나 막는지 보이는 네 입장
4. {67c6}: 네 입장이 먼저 정해야 하는 정보가 서로 다르다는 비교(종합)
5. {67d}: 속성 선택의 비용 편익 기준이 오류를 고칠 유인을 주지 못하는 이유, 발제의 정리
6. {67d1}, {67d2}: 과거 결정의 편견 학습과 표본 수집의 지역 편차를 보이는 두 사례
7. {67d3}, {67d4}: 마스킹을 입증하기 어려운 법적 구조, 편향된 지표를 목표 변수로 쓸 때의 이중 강화

## 3. 딥러닝의 구조와 성공
1. {67n}: 오차 역전파로 학습하는 인공신경망의 정의. 3절과 4절의 출발점이다.
2. {67o}: 현대 DCNN이 이전 신경망과 달라지는 네 구조적 지점
3. {67o1}, {67o2}: 깊이가 복잡한 함수를 같은 노드 수로 계산하게 하는 이유, 합성곱과 ReLU와 맥스 풀링의 패턴 검출
4. {67o3}: 조립 라인 유비를 다종적 구조와 간헐적 연결에까지 넓히는 영진 님의 확장
5. {67p}: 딥러닝의 성공을 설명하는 세 관점을 보완 관계로 소개하는 카드
6. {67p1}, {67p2}, {67p2a}, {67p3}, {67p3a}: 계층적 특징 구성, 잡음 조정과 설계 요소의 가정, 선형 영역의 지수적 증가
7. {67p4}: 세 설명을 부분 구조의 반복 재사용으로 묶는 공통 측면

## 4. 딥러닝과 마음
1. {67q}: DCNN을 타뷸라 라사 가설의 입증으로 읽는 경험주의의 해석
2. {67q1}, {67q2}: 내장된 구조적 편향을 들어 입증을 막는 본유주의의 응답, 이를 잡음 조정 설명의 사전 편향과 같은 설계 요소로 묶는 종합. {67p2}와 이어진다.
3. {67r}, {67r1}: 데이터 양의 차이를 다른 메커니즘의 논거로 쓰는 논의와 인간의 학습 데이터가 많다는 반론
4. {67s}, {67s1}: 적대적 예제를 인간과 다른 패턴 인식의 논거로 쓰는 논의와 착시를 들어 단정을 막는 반론
5. {67t}, {67t1}: DCNN으로 마음의 블랙박스를 열 수 있다고 보는 기계론적 설명과 수학적이고 기능적인 설명
6. {67u}, {67u1}: AI가 인간의 학습 방식을 바꾸고 있다는 영진 님의 관찰과 이를 흉내내기로 볼지 학습의 본질적 변화로 볼지의 물음. 이 클러스터에서 영진 님의 입장으로 끝나는 카드이다.

## 줄기를 가로지르는 실
- **불투명성**: {67a} → {67b} → {67t} (사회적 책임의 문제로 제기된 불투명성이 실행 지식의 문제가 되고, 마음의 블랙박스를 여는 문제로 다시 나타난다)
- **정상 작동과 규범 선택**: {67b3} → {67e} → {67c} (정상 작동을 정하는 일과 상충을 정하는 일이 같은 구조를 가진다)
- **내장된 구조와 사전 편향**: {67p2} → {67q1} → {67q2} (잡음 조정 설명과 본유주의의 응답이 같은 설계 요소를 가리킨다)
- **인간과 같은 방식인가**: {67r} → {67s} → {67u1} (학습의 데이터 양, 패턴 인식, 학습 방식의 변화에서 같은 물음이 반복된다)
- **오류가 몰리는 집단**: {67d} → {67d2} → {67c6} (오류의 분포가 정확도와 형평성의 상충을 평가하는 정보를 정한다)
- **현상학적 이해**: {67b1} → {67b2} → {67o3} (살아진 세계에서 인지를 수학화하는 제안이 모델 구조를 읽는 방식으로 이어진다)

## 다른 구조 노트와 이어지는 곳
- [[정치·사회·역사·법 기술과 법과 인격]]: 같은 클러스터 안의 선행 구조 노트이다. §1 알고리즘 차별과 법의 {51h} 계열이 {67a}, {67c}, {67d}와 같은 논문을 다루고, §2 로봇과 책임의 {51h2d}는 책임을 설계하고 쓰는 인간에게 돌리는 논리로 {67a}의 책임 소재 쟁점과 이어진다. §3 AI 인격 논쟁의 {27h}, {27h3}은 기계의 도덕적 지위를 다루어, 이 노트가 다루지 않는 AI 자체의 지위 논쟁과 이어진다. §8 언러닝 문제의 {27j}, {27j1}은 {67q1}, {67r}의 생득적 구조와 학습 데이터 양 논의와 이어진다.
- [[정치·사회·역사·법 인종과 알고리즘 공정성]]: {52d}의 공정성 지표 비판이 {67c}의 상충 논의와 같은 문제를 다른 이론으로 다룬다.
- [[정치·사회·역사·법]]: 위 두 하위 노트가 속한 클러스터 개요이다.
- [[자기지식과 투명성]]: {42u}가 이 클러스터와 그 노트에 모두 걸려 있다. 거기서 말하는 투명성은 자기지식 문헌의 투명성이고 이 노트의 투명성은 계산 시스템의 투명성이어서 낱말만 같다. 두 투명성을 혼동하지 않도록 색인에서 구분한다.
- [[윤리와 가치]]: {67c2}~{67c4}의 롤스, 공리주의, 칸트가 규범 이론 하위 노트의 공리주의와 의무론 논의와 이어지고, 기계의 도덕적 지위({27h3}의 쿠헬버그)는 책임의 적용 범위 논의와 이어진다.
- [[과학철학]]: {67t}, {67t1}의 기계론적 설명과 수학적 기능적 설명이 설명 모형을 다룬 {66a} 계열의 설명 비판과 이어지고, {66c} 계열이 {67b1}과 같은 계산 현상학 문헌을 다룬다.
- [[경제학과 경제사]]: {67d}의 비용 편익 기준이 낳는 유인 문제가 합리적 선택 논의와 키워드 수준에서 이어진다.
- [[행위와 실천이성]]: {44b9}가 보상 학습 알고리즘을 가진 신경망의 욕구를 물어 {67n}의 학습 원리와 이어진다.

- {67q} → {63c3} ([[근세철학]]): DCNN을 타뷸라 라사의 입증으로 읽는 경험주의 독해는 본유 관념 옹호를 막는 로크의 논변을 기계에서 시험하는 셈이다.
- {67c3} → {47a3} ([[윤리와 가치]]): 공정성과 정확도의 가중치를 효용으로 정하는 논변은 밀이 요구한 불편부당을 모델 설계에 옮긴 형태이다.
