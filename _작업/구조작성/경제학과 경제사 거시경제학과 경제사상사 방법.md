# 경제학과 경제사 거시경제학과 경제사상사 방법

이 구조 노트는 백하우스의 『Interpreting Macroeconomics』와 스노든과 베인의 『Modern Macroeconomics』를 정리한 카드들을 엮는다. 줄기는 일곱 개이다. 경제사상사를 어떻게 쓸 것인가(1)와 이론의 시대와 상대주의 논쟁(2)에서 방법의 물음을 세우고, 케인스 이전의 실업론(3)과 케인스 이후의 두 이야기(4), 라카토슈 기준에 따른 평가(5)로 역사 서술을 따라간 뒤, 교과서의 고전학파 모형(6)에서 세이의 법칙과 화폐의 중립성을 이론 쪽에서 확인하고, 두 문헌이 만나는 지점(7)으로 마무리한다. 책의 3~7장과 10~12장은 정리글이 없어 개요에 근거해 반영했다. 영진 님이 직접 밝힌 입장은 이 노트에 없고 문헌 카드와 종합 카드로 이루어져 있다.

## 1. 경제사상사를 어떻게 쓸 것인가
1. {31}: 고전학파 모형, 케인스 이후의 논쟁, 서술 방법의 세 층위로 읽는 진입 카드
2. {31a}: 이론의 평가와 역사적 설명을 겸하는 다원주의
3. {31a1}: 과학철학, 수사학, 두꺼운 역사, 탈정전화가 목표를 각각 다르게 잡는 지점
4. {31a2}: 로티의 네 장르로 두 재구성을 함께 쓰는 길
5. {31a3}, {31a4}: 토대주의와 구성주의의 양자택일 거부, 두꺼운 역사 옹호 논거에 대한 회의

## 2. 이론의 시대와 상대주의
1. {31b}: 성장, 배분, 정체를 묻는 세 시대와 이론 사이의 독립성 주장
2. {31b1}, {31b1a}: 이론의 네 수준 구별과 고전파 이론이 진부해진 수준과 그렇지 않은 수준
3. {31b2}, {31b3}: 암묵적 이론화로 읽는 반론, 한계주의 막간설에 대한 반례
4. {31b4}: 이론 전통을 기원으로 비판하는 일의 오류
5. {31b5}: 시대 독립성과 쿤의 외부 기준 부재를 대비하는 종합

## 3. 케인스 이전의 실업론
1. {31c}: 현대 개념과 당대 이론 틀의 두 잣대로 읽기
2. {31c1}: 홉슨의 화폐 정의와 수량설, 승수
3. {31c2}: 워커의 조정 실패 설명과 독립 지출 개념의 부재
4. {31c3}: 미첼과 클라크의 불확실성 어휘가 다른 틀에서 다른 뜻을 지닌 점

## 4. 케인스 이후 거시경제학의 두 이야기
1. {31d}: 변수 제거의 이야기와 케인스주의 대 통화주의의 이야기로 나누는 서술
2. {31d1}, {31d2}, {31d3}: 형식 모형과 IS-LM, 미시적 기초, 합리적 기대와 새고전학파로 이어지는 세 단계
3. {31d4}: 케인스적 실업을 다시 규정해 온 경로
4. {31d5}: 통화주의 논거의 이동
5. {31d6}, {31d7}: 세 검정이 논쟁을 끝내지 못한 사정과 결합 가설로 읽는 해석
6. {31d8}: 이론 조정이 임시방편이 아니었다는 8장의 결론

## 5. 방법론적 평가: 케인스 경제학의 부상과 쇠퇴
1. {31e}: 선험주의, 반증주의, 라카토슈의 기준으로 평가하는 9장의 진입 카드
2. {31e1}, {31e2}: 소박한 반증주의의 한계와 초기 진보성의 증거
3. {31e3}: 소비함수 수수께끼가 항상소득 가설의 진보를 낳은 사례
4. {31e4}: 1970년대 이후 이론의 공격과 증거의 응답
5. {31e5}, {31e6}: 라카토슈적 재구성과 신왈라스 프로그램으로서의 거시경제학
6. {31e7}, {31e8}: 수사 대신 문제 적합성으로 설명하는 12장, 프리드먼의 위치

## 6. 교과서의 고전학파 모형
1. {31f}: 다섯 가정과 세 구성 요소로 짠 양식화된 재구성
2. {31f1}, {31f2}: 노동수요곡선과 비자발적 실업만 배제되는 완전고용 균형
3. {31f3}: 이자율이 저축과 투자를 맞추는 고리
4. {31f4}, {31f4a}: 세이의 법칙을 두 단계와 약한 판본과 강한 판본으로 나누어 읽기
5. {31f5}: 맬서스, 밀, 케인스가 문제 삼은 서로 다른 지점
6. {31f6}, {31f7}: 절약의 역설과 승수, 명목임금 인하 처방의 거부
7. {31f8}, {31f9}, {31f10}: 수량설의 두 판본과 고전적 이분법, 명목이자율과 통화량
8. {31f11}, {31f11a}: 화폐 중립성이 장기의 이야기라는 점과 지금 논쟁의 사례

## 7. 처방의 틀과 재구성
1. {31g}: 케인스의 두 진영 구분이 처방을 가르는 틀이면서 경제학사를 다시 짠 재구성이라는 종합

## 줄기를 가로지르는 실
- **쿤과 비교 불가능성**: {31a1} → {31b5} → {31e1} (도전들의 정리에서 시대 독립성의 비교를 거쳐 반증주의의 한계로 이어짐)
- **결합 가설**: {31d6} → {31d7} → {31d8} (세 검정의 불확정성을 결합 가설로 읽고 결론으로 거두는 과정)
- **세이의 법칙의 읽기**: {31f3} → {31f4} → {31f5} → {31g} (모형의 고리에서 판본 구분, 세 사람의 비판 지점, 처방의 틀로 옮겨 감)
- **화폐의 중립성**: {31f9} → {31f11} → {31d3} → {31d5} (고전적 이분법이 단기 비중립성과 새고전학파의 자연율 가설로 이어짐)
- **불확실성의 어휘**: {31c3} → {31e5} (케인스 이전의 어휘 사용이 연구 프로그램의 재구성에서 다시 평가됨)
- **라카토슈 기준의 적용**: {31e1} → {31e5} → {31e6} → {31e7} (기준이 선택되고 재구성되고 사례에 적용되는 순서)
