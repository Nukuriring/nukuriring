# 정치·사회·역사·법 정치체제와 정치철학

이 구조 노트는 정치체제가 어떻게 바뀌고 유지되는지, 사회의 기본 구조를 어떤 원칙으로 정당화하는지를 다룬 카드들을 엮습니다. 줄기는 일곱 개입니다. 아리스토텔레스 『정치학』 5권(1), 6권(2), 4권 11장과 7-8권(3) 필기에서 출발하고, 롤스와 매킨타이어의 정의론 논쟁(4)과 시민 불복종(5)을 거쳐, 헌법 제정의 기준(6)과 체제 변동의 역사적 사례(7)로 나아갑니다. NP1 묶음에서는 51a-51c의 『정치학』 필기를, G1 묶음에서는 27a, 27c, 27d, 27f, 27g 계열과 진입 카드 27을 반영했습니다. 27f(아우구스투스)와 27g(튜더 시대) 카드는 보고서 본문이 원자료에 없어 대화 요약의 범위에 머물러 있습니다.

## 1. 아리스토텔레스: 체제 변화와 파당 (『정치학』 5권)
1. {51}, {51a}: 필기 전체의 진입 카드(종합)와 5권의 출발점. 체제 변화를 동등성 요구의 충돌로 읽는 틀
2. {51a1}, {51a1a}, {51a1b}: 민주정과 과두정이 동등성의 한 면을 전체로 오해한다는 진단, 파당의 두 방향, 민주정의 상대적 안정성
3. {51a2}, {51a2a}, {51a2b}, {51a2c}, {51a2d}: 파당을 성향과 목적과 원인으로 나누고, 원인의 결합과 비례, 계급 구성에서 분열의 깊이를 재는 분석
4. {51a2e}: 힘과 속임수와 설득으로 체제가 바뀌는 방식, 설득이 끝까지 이어질 때의 자발적 지배
5. {51a3}, {51a3a}, {51a3b}: 민주정, 과두정, 귀족정과 혼합정이 각각 무너지는 경로
6. {51a4}, {51a4a}, {51a4b}, {51a4c}, {51a4d}, {51a4e}: 파괴 요인의 반대를 보존책으로 삼는 처방. 관직, 달래기, 관직자의 자격, 중용, 교육
7. {51a5}, {51a5a}, {51a5b}: 왕정과 참주정의 구별과 참주정의 두 보존책
8. {51a5c}: 소크라테스의 체제 변화론에 대한 비판

## 2. 체제의 종류와 제도의 조합 (『정치학』 6권)
1. {51b}: 심의, 관직, 사법의 조합으로 체제를 나누는 6권의 출발점
2. {51b1}, {51b2}: 민주정이 여럿인 까닭과 자유라는 근본 원리
3. {51b2a}, {51b2b}, {51b2c}: 민주정의 제도 목록, 수에 따른 동등성, 500명과 1000명 사례가 보이는 두 방식의 부정의
4. {51b3}, {51b4}: 농민 민주정과 극단적 민주정, 민주정의 보존책
5. {51b5}, {51b5a}: 최선의 과두정과 혼합정의 근접, 군대의 종류가 체제의 강도를 정하는 점
6. {51b6}: 관직의 기능별 분류와 최고 권위 관직의 선출 방식

## 3. 최선의 체제와 교육 (4권 11장, 7-8권)
1. {51c}, {51c8}: 영진 님이 읽은 4권 11장의 물음과, 현실적 최선과 이상 폴리스를 서로 다른 층위로 읽는 종합 카드
2. {51c1}, {51c1a}, {51c1b}, {51c1c}, {51c1d}: 최선의 체제에 앞서 가장 바람직한 삶을 규정하는 일, 개인의 행복과 폴리스의 행복의 동일성, 활동적 삶
3. {51c2}, {51c2a}, {51c2b}, {51c2c}: 폴리스의 크기, 영토, 바다, 기후
4. {51c3}, {51c3a}, {51c3b}, {51c3c}: 필수 요소와 시민의 자격, 토지와 공동식사, 도시 배치
5. {51c4}, {51c4a}, {51c4b}, {51c4c}: 잘됨의 두 요소, 덕의 사용, 번갈아 지배하는 방식, 일과 여가의 구분
6. {51c5}, {51c6}: 혼인과 양육에 대한 입법, 하나의 목적에서 나오는 공공 교육
7. {51c7}, {51c7a}, {51c7b}, {51c7c}: 음악 교육의 목적과 연주, 선법의 선택

## 4. 롤스와 매킨타이어: 정의의 기초
1. {27a}: 원초적 입장의 가상 합의에서 정의 원칙을 끌어내는 롤스의 구도
2. {27a1}, {27a1a}: 합의 주체가 공동체와 유리된 자아라는 매킨타이어의 비판, 덕이 실현되는 사회적 실천과 내적 선
3. {27a1b}, {27a1b1}: 합리성을 전통에 묶으면서 전통 간 비교를 허용하는 방식, 살아 있는 전통. 상대주의와 보수주의 반론에 대한 응수
4. {27a2}: 원초적 입장을 표현 장치로 읽는 변호와 선택자의 동기 구조에 대한 재비판(종합)
5. {27a3}, {27a3a}, {27a3b}: 후기 롤스의 정치적 자유주의, 전통 의존 테제와의 관계, 공적 이성 제약이 받는 비판(종합)

## 5. 시민 불복종
1. {27a4}: 공적이고 비폭력적이며 법에 충실한 행위로 시민 불복종을 한정하는 롤스의 정의와 준정의 사회 전제
2. {27a4a}: 롤스 이후 논의가 세 조건을 모두 문제 삼는 전환(종합)

## 6. 헌법 제정과 개정
1. {27d}: 헌법 질서 전체가 근본적으로 바뀔 때에만 제정을 인정하는 영진 님의 기준
2. {27d1}: 제정과 개정을 가르는 기준 후보인 양과 질과 절차적 단절
3. {27d2}, {27d2a}: 개정 절차의 효력을 빌리는 논변의 순환과, 국민주권에 기댄 반론이 국민투표의 진정성에서 부딪히는 한계

## 7. 체제 변동의 사례와 모델 이전
1. {27}: 개념과 모델은 성립 조건을 함께 옮길 때에만 새 사례를 분석한다는 G1 묶음 전체의 진입 카드(종합)
2. {27c}, {27c1}: 셰바르드나제의 엘리트 포섭을 다룬 『좁은 회랑』 서술과 이 모델을 다른 사례로 옮길 때의 성립 조건
3. {27f}: 공화정 복원의 언어로 군주정을 세운 아우구스투스
4. {27g}, {27g1}: 튜더 혁명론을 둘러싼 논쟁과 가디너 평가의 쟁점

## 줄기를 가로지르는 실
- **체제의 위장과 변환**: {51a3} → {51a5b} → {27f} (인민 선도자가 민주정을 참주정으로 바꾸는 경로, 왕처럼 보이려는 참주, 공화정의 언어를 쓴 군주정으로 이어지는 연결은 카드 작성자의 해석입니다)
- **동등성**: {51a} → {51b2b} → {27a} (동등성에 대한 상이한 요구의 충돌, 수에 따른 동등성, 기본 구조의 정의 원칙으로 같은 물음이 되돌아옵니다)
- **교육과 덕**: {51a4e} → {51c6} → {27a1a} (체제에 맞게 지배하는 능력을 기르는 교육, 공공 교육, 사회적 실천 안에서 길러지는 덕)
- **서로 다른 층위의 물음**: {51c8} → {27} → {27c1} (층위가 다른 물음을 구별해 읽는 태도가 모델 이전의 성립 조건 확인으로 이어집니다)
- **전통과 내부 논쟁**: {27a1b1} → {27a3a} → {51a4d} (전통 안의 논쟁이 이어지는 방식, 정치적 자유주의가 확인해 주는 전통 의존, 극단을 피하는 중용)
