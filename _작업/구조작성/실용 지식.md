# 실용 지식

이 구조 노트는 '실용 지식' 클러스터의 개요이다. 자료는 Notion에 옮겨 둔 시험 대비 필기 세 과목, 곧 부동산학개론(69a~69f)과 회계원리(69g)와 컴퓨터활용능력(69h)이고, 카드는 진입 카드 {69}를 포함해 89장이다. 세 과목은 개념을 정의하고 대상을 분류하고 계산이나 기록의 절차를 밝히는 순서로 지식을 정리하며, 내용은 서로 독립적이다. 그래서 하위 구조 노트를 나누지 않고 일곱 줄기를 과목 순서대로 배열했고, 과목 사이에서 개념이 겹치는 곳(감가, 유량과 저량)은 뒤쪽 '줄기를 가로지르는 실'에 모았다. voice는 문헌이 85장이고 영진 님의 입장은 {69g3a} 한 장이며 종합은 세 장이다. 필기의 교재 서지는 모두 확인되지 않았고, 확인이 필요한 항목은 '정리 후보'에 적었다.

## 1. 부동산의 개념과 토지의 특성
1. {69}: 세 과목 전체의 진입 카드. 정의, 분류, 절차의 순서로 세 과목을 읽는 안내
2. {69a}: 부동산을 법적, 경제적, 물리적 개념으로 나누는 출발점
3. {69a1}, {69a2}: 협의와 광의의 범위, 토지 소유권이 미치는 상하의 범위(지표권, 지하권, 공중권)
4. {69a3}, {69a4}, {69a5}: 경제적 개념의 다섯 성격, 공급이 한정된 자연물이라는 성격, 접근성에 따른 위치가치
5. {69b}: 토지의 자연적 특성 다섯과 인문적 특성 셋을 묶는 카드
6. {69b1}, {69b2}, {69b3}, {69b4}, {69b5}, {69b6}: 부동성, 영속성, 부증성, 개별성, 인접성, 용도의 다양성을 하나씩 다룬 가지
7. {69b7}, {69b8}: 특성이 분석 개념과 평가 방식의 근거가 되는 대응표, 그리고 특성이 원가법과 직접환원법의 적용 가능성을 가르는 종합

## 2. 용도에 따른 분류
1. {69c}: 지역종별과 토지종별, 후보지와 이행지로 나누는 분류의 틀
2. {69c1}, {69c2}: 감정평가와 법령에서 달라지는 용어 정의, 법적 단위(필지)와 경제적 단위(획지)의 구분
3. {69c3}, {69c4}, {69c5}: 나지와 건부지, 맹지, 지형과 법적 제약이 있는 토지
4. {69c6}, {69c7}: 유휴지와 휴한지의 구별, 주택의 유형

## 3. 감정평가 3방식
1. {69d}: 비용성, 시장성, 수익성에 따른 세 방식과 가액, 임료의 구분
2. {69d1}, {69d1a}: 원가법의 산식과 토지에 쓰기 어려운 한계
3. {69d2}: 감가수정과 회계의 감가상각을 대조해 두 과목을 잇는 카드
4. {69d3}, {69d4}, {69d4a}, {69d4b}: 감가요인, 내용연수에 의한 감가 방법(정액법, 정률법, 상환기금법), 내용연수에 의하지 않는 방법
5. {69d5}: 임료를 구하는 적산법
6. {69d6}, {69d6a}: 거래사례비교법의 보정 절차와 적용의 한계
7. {69d7}: 임대사례비교법과 공시지가기준법
8. {69d8}, {69d8a}, {69d8b}: 수익환원법의 구조, 환원율의 산정, 수익이 없는 부동산에 적용하기 어려운 한계

## 4. 가격공시제도
1. {69e}: 표준지공시지가의 주체와 대상
2. {69e1}: 개별공시지가가 세금과 부담금의 기준이 되는 방식
3. {69e2}, {69e3}: 주택과 비주거용 부동산에서 표준과 개별로 나누는 같은 구조

## 5. 수요와 공급
1. {69f}: 수요량의 변화와 수요의 변화를 가르는 출발 카드
2. {69f1}, {69f1a}: 유량과 저량의 정의, 이를 재무제표에 대응시킨 종합
3. {69f2}: 수요의 법칙과 대체효과, 소득효과
4. {69f3}, {69f4}, {69f5}: 수요곡선을 옮기는 요인(소득, 관련재 가격, 기대)
5. {69f6}: 조세와 대출금리가 공급곡선을 옮기는 방향

## 6. 회계원리
1. {69g}: 회계의 정의와 이용자, 회계기간
2. {69g1}, {69g2}, {69g3}: 두 재무제표와 당기순이익이 둘을 잇는 방식
3. {69g3a}: 회계의 본질을 항목의 귀속으로 읽는 영진 님의 메모. 이 줄기에서 유일한 영진 voice 카드
4. {69g4}, {69g5}: 계정의 기록 규칙, 회계상 거래의 정의
5. {69g6}, {69g7}: 거래의 이중성과 복식부기, 거래 8요소의 차변과 대변 배치
6. {69g8}, {69g9}, {69g9a}: 분개에서 전표, 분개장, 총계정원장으로 이어지는 기록 절차와 장부의 종류

## 7. 컴퓨터활용능력
1. {69h}: CPU의 레지스터와 누산기에서 출발하는 진입 카드
2. {69h1}, {69h2}, {69h3}: 기억 장치의 속도 순서, 플래시 메모리, 문자 코드
3. {69h4}, {69h5}: IP 주소와 도메인
4. {69h6}, {69h7}, {69h8}, {69h9}, {69h10}: 멀티미디어의 특징, 그래픽 기법, 비트맵과 벡터, 오디오, 동영상
5. {69h11}, {69h12}, {69h13}, {69h14}: 통신 방향, 망 구성 형태, 통신망의 규모, 장비와 OSI 7계층
6. {69h15}, {69h16}, {69h17}: 프로토콜의 역할, 응용 프로토콜, 연결 확인 명령어
7. {69h18}, {69h19}, {69h20}, {69h21}: 보안 위협의 유형, 방화벽의 한계, 대칭키와 비대칭키
8. {69h22}, {69h23}, {69h24}, {69h25}: 언어 번역 방식, 객체 지향, 서버와 클라이언트, 클립보드

## 줄기를 가로지르는 실
- **감가**: {69b2} → {69d1} → {69d2} → {69g1} (토지는 영속성 때문에 감가상각을 적용하지 않고, 원가법의 감가수정은 회계의 감가상각과 기초와 연한이 다르다)
- **유량과 저량**: {69f1} → {69f1a} → {69g1} → {69g2} → {69g3} (저량은 재무상태표에, 유량은 포괄손익계산서에 대응하고 당기순이익이 둘을 잇는다)
- **토지의 특성과 평가 방식**: {69b} → {69b7} → {69b8} → {69d1a} → {69d8b} (특성이 방식의 적용 범위를 정한다)
- **비슷한 용어의 구별**: {69c1} → {69c2} → {69c6} → {69h18} (정의가 가까운 용어를 기준에 따라 가르는 필기의 방식이 두 과목에 같게 나타난다)
- **기록과 분류**: {69g3a} → {69g4} → {69g8} → {69g9} (항목을 어느 계정에 귀속시킬지 정하는 일에서 장부 체계까지)
- **특성에서 평가로 가는 대응 방식**: {69a5} → {69b5} → {69d6} (위치와 인접성이 가치에 미치는 영향이 지역요인과 개별요인의 비교로 쓰인다)

## 다른 구조 노트와 이어지는 곳
- [[법학]]: {69a2}의 토지 소유권(지표권, 지하권, 공중권)이 소유권을 다루는 {68n}과 이어진다.
- [[정치·사회·역사·법]]: 부동산 거래와 권리 관계를 다루는 {27e}가 {69a}, {69e}와 같은 영역에 있고, 법이 몸과 재산을 분류하는 방식을 다룬 {51h5}가 {69a}의 법적 개념과 키워드 수준에서 이어진다.
- [[경제학과 경제사]]: {69f}의 수요곡선과 수요의 법칙이 {29d5}의 수요와 공급 방정식과 이어지고, {31b1a}와 {31f1}의 수요 논의가 {69f}의 수요곡선 이동 논의와 개념이 겹친다. 투자 판정을 다룬 {34}는 {69g2}의 손익 대비와 키워드 수준에서 이어진다.
- [[창작과 에세이]]: 회계의 본질을 항목의 귀속으로 읽는 {69g3a}가 가죽 구두 장면을 회계로 읽는 {35h1}, 장부에 적는 일을 다룬 {35g}와 이어진다.

## 정리 후보
- {69g6}: 복식부기를 15세기 이탈리아의 루카 파치올리가 체계화했다는 문장이 필기의 다른 부분과 문체가 달라 외부 설명을 붙여 넣은 것으로 보인다. 출처 확인이 필요하다.
- {69h2}: 필기는 플래시 메모리를 휘발성이라고 적었으나 EEPROM 설명과 어긋나 카드에서 비휘발성으로 고쳤다. 확인이 필요하다. 같은 필기에서 {69h3}의 유니코드 표현 수도 오기를 65,536으로 고쳤다.
- {69d4}, {69d6}: 정액법 산식의 괄호 위치를 말로 푼 문단에 맞춰 읽었고, 거래사례비교법 산식에 면적 항이 있어 교재 확인이 필요하다.
- {69c5}, {69c7}, {69e}, {69e1}, {69e2}, {69e3}: 빈지의 법령상 정의, 다중주택의 면적 기준, 공시 시기와 약칭 법령 등이 개정될 수 있어 현행 규정 확인이 필요하다.
- {69b2}와 {69d2}: 토지에 감가상각을 적용하지 않는다는 내용이 겹친다. 감가수정과 감가상각의 대조는 {69d2}에, 영속성의 귀결은 {69b2}에 있어 역할은 다르다.

- {69d1a}와 {69b8}: 원가법이 토지에 쓰기 어렵다는 내용이 겹친다. 앞은 감정평가 필기의 규정이고 뒤는 두 필기를 맞댄 종합이다.
- {69d8b}와 {69d8}: 수익환원법의 한계와 구조가 인접해 있어 합칠 수 있는지 볼 만하다.
- {69f1a}와 {69f1}, {69g1}, {69g2}: 유량과 저량의 재무제표 대응이 세 카드에 나뉘어 있어 중복이 의심된다.
- 문헌 노트 일곱 편 모두 교재 저자와 연도가 필기에 없어 서지 확인이 필요하다.
