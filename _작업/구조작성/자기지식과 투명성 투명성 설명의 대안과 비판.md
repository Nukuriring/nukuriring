# 자기지식과 투명성 투명성 설명의 대안과 비판

이 구조 노트는 모런의 투명성 설명에 대응하거나 이를 대체하려는 이론들을 다룬 카드들을 엮는다. 줄기는 다섯 개이다. 콕스의 숙고 모델(1)과 애시웰의 욕구 투명성 논의(2)를 먼저 읽고, 바이른의 BEL을 비판하는 박의 합리적 행위자 설명(3)을 지나, 모런의 숙고 조건을 비판하며 비정립적 의식을 내세우는 보일의 설명(4)으로 가며, 내감 이론을 겨누는 슈메이커의 자기맹 논증(5)으로 마친다. 묶음 NJ1(41번 줄기)의 카드 가운데 41d부터 41h까지의 가지를 반영했고, 모런과 에반스 자신의 설명은 같은 클러스터의 `자기지식과 투명성 모런과 에반스`에 있다.

## 1. 콕스: 기본 주체에서 자기를 아는 주체로
1. {41d}: 문제 설정. 기본적인 합리적 주체에 무엇을 더해야 자기지식이 생기는지 묻는 평가 틀
2. {41d1}: 기본 주체가 이미 자기를 안다는 답과 추론 모델의 부적합성
3. {41d2}, {41d3}: 자기 스캔 모델의 한계, 비증거적 추론 규칙이 평범한 추론 능력의 확장이 못 되는 이유
4. {41d4}: 투명성 관계를 욕구와 의도로 일반화하는 시도와 그 한계
5. {41d5}, {41d5a}: 콕스가 선택하는 숙고 모델과 그 모델에 제기되는 반론에 대한 응답

## 2. 애시웰: 욕구의 투명성
1. {41e}: 가치 판단에 기대는 욕구 투명성의 한계와 대안의 방향
2. {41e1}: 욕구가 있는지 묻는 일을 바람직함 판단으로 푸는 절차의 소개
3. {41e2}, {41e2a}: 모런의 설명이 욕구에 적용되는 방식, 범위 반론과 괴리 반론
4. {41e3}, {41e3a}: 바이른의 DTR과 DD, 그에 대한 애시웰의 비판

## 3. 박: 투명성 퍼즐과 합리적 행위자 설명
1. {41f}: 투명성 퍼즐을 심리학적 문제와 인식론적 문제로 나누는 틀
2. {41f1}, {41f1a}, {41f1a1}: 바이른의 BEL 설명과 미친 추론이라는 지적, 신빙성과 안전성만으로 옹호할 때의 문제
3. {41f1b}, {41f1c}, {41f1d}: 추론 개념을 둘러싼 딜레마, 영진 님의 두 평가(넓은 추론 개념의 전제, 추론주의적 설명이 심리학적 문제를 푼다는 점)
4. {41f2}, {41f2a}, {41f2b}: 박이 재구성한 모런의 설명과 그 설명이 숙고 상황에 갇힌다는 지적
5. {41f3}, {41f3a}, {41f3b}, {41f3c}: 이유 기반 인식과 암묵적 이해로 푸는 심리학적 문제, 자기귀속의 절차, 특권적 접근의 설명
6. {41f4}, {41f4a}, {41f4b}, {41f4c}: 버지를 본뜬 인식적 보증 논증과 brute error 면역, 자기기만에 대한 부담

## 4. 보일: 비정립적 의식과 반성주의
### 4.1 모런과 바이른에 대한 비판
1. {41g}: 보일의 중심 테제. 자기지식을 암묵적 알아챔의 반성적 표현으로 읽음
2. {41g1}, {41g1a}, {41g1b}: 상관 모형 비판의 배경, 사소한 앎이라는 카삼의 지적, 일인칭 관점과 삼인칭 관점의 구분
3. {41g2}, {41g2a}, {41g2b}, {41g2c}: 모런의 숙고 조건이 너무 강하다는 비판과 의식적 믿음에 한정해 통찰을 간직하는 방안
4. {41g3}, {41g3a}, {41g3b}, {41g3c}: BEL의 이점과 딜레마, 의도의 경우, 소외된 관전자라는 귀결
5. {41g4}, {41g4a}: 피콕의 의식적 판단 설명과 그에 대한 비판

### 4.2 반성주의와 사르트르
1. {41g5}: 보일의 대안. 세계를 다루는 일에 이미 든 앎을 반성으로 명료화함
2. {41g5a}, {41g5b}, {41g5c}: 사르트르의 네 명제와 정립적 의식 및 비정립적 의식, 반성의 작용
3. {41g6}, {41g6a}, {41g6b}, {41g6c}: 의도 기반 will과 단언에서 비정립적 의식이 표현되는 방식
4. {41g7}, {41g7a}: 암묵적 자기지식을 전제하는 설명과 반성적 표현이 자각을 빚는지에 대한 영진 님의 물음

### 4.3 비정립적 의식의 구조
1. {41g8}, {41g8a}: 세계를 의식하는 방식에 대한 비정립적 의식으로 투명성을 설명하는 새 해법
2. {41g9}, {41g9a}: 주체로서의 표상과 특정 주체의 표상의 구별, 바깥 지향의 관점
3. {41g10}, {41g10a}, {41g10b}: 명시적 자기지식 없는 의식적 믿음, 편향된 심사자 사례, 영진 님의 구조적 합리성 독해
4. {41g11}, {41g11a}, {41g11b}: 제시 양상에 표현되는 비정립적 의식과 그 정당화, 지적 반응성의 요건
5. {41g12}: 소외되지 않은 자기지식의 선결 조건
6. {41g13}, {41g13a}, {41g13b}: 반자기중심주의 도전, 설탕 봉지 사례, 에반스의 내포 차이

### 4.4 반성과 합리성
1. {41g14}, {41g14a}, {41g14b}: 반성을 독자적 인지 단계로 보는 데서 생기는 모호성과 반성적 믿음의 조건
2. {41g15}, {41g15a}, {41g15b}: 합리성이 자기의식을 요구한다는 논증에 대한 의심과 구조적 합리성 논의로 들어가는 입구
3. {41g16}, {41g16a}: 추론의 취함과 실천적 취함을 명시적 상위 표상 없이 이해하는 방안

## 5. 슈메이커: 자기맹과 내감 이론
1. {41h}: 자기맹 불가능성 논증과 내감 이론 비판의 틀
2. {41h1}, {41h2}, {41h3}: 자기맹의 정의, 행동과 믿음이 내성적 알아챔을 전제한다는 논증, 사고 실험
3. {41h4}, {41h5}: 믿음과 욕구에 대한 독립된 두 논증, 인과 관계에 서는 두 존재의 연결 문제
4. {41h6}, {41h6a}, {41h7}, {41h7a}: 리 승수의 반론과 영진 님의 보충, 내감 이론가의 응답

## 줄기를 가로지르는 실
- **BEL 비판**: {41f1a} → {41f1b} → {41g3a} → {41g3c} (바이른의 추론 설명이 합리적 이해를 요구하는 딜레마에서 소외된 관전자라는 귀결로)
- **소외된 관전자**: {41g3c} → {41g4a} → {41g12} → {41g14a} (투명한 귀속을 비심리적 사실에 두는 설명의 문제에서 비정립적 의식의 선결 조건으로)
- **암묵적 이해**: {41f3} → {41f4a} → {41g5} → {41g6b} (박의 이유 기반 인식과 보일의 반성적 전환이 모두 명시적 자기귀속 이전의 이해에 기대는 점)
- **욕구와 가치 판단**: {41e1} → {41e2a} → {41e3a} (모런식 절차의 범위를 욕구에서 시험하는 흐름)
- **합리성과 자기의식**: {41g15} → {41g15a} → {41g10b} → {41h6a} (합리성과 자기 접근의 연관이 구조적 합리성과 자기맹 논의로 번지는 지점)

## 다른 구조 노트와 이어지는 곳
- [[자기지식과 투명성]]: {41g}와 {41d}는 {22e}의 자기지식 이론 분류에서 행위자성 쪽 이론과 이어지고, {41g15}는 {22e7a}의 합리적 행위자성 논의와 이어진다.
- [[행위와 실천이성]]: {41e}의 욕구 투명성과 {41g3b}의 의도 기반 will은 욕구와 의도의 지위를 다루는 논의와 이어진다.
- [[인식론]]: {41f4}의 암묵적 이해와 인식적 보증 논증은 인식적 보증과 권리부여 논의와 이어진다.
- [[자기지식과 투명성 모런과 에반스]]: {41g2}는 {41b4}와 {41b16b}의 숙고 조건을 비판하고, {41f1a}는 {41a6}의 BEL 논의와 이어진다.
- [[자기지식과 투명성 추론과 구조적 합리성]]: {41g15a}는 {41n}과 {41l5}로 이어지고, {41f4}는 {41r3}의 인식적 보증 구분과 만난다.
