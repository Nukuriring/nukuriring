# 자기지식과 투명성 외재주의와 선험적 앎

이 구조 노트는 심적 내용이 주체 바깥의 사실에 기대어 정해진다는 외재주의가 자기 생각의 내용을 선험적으로 안다는 주장과 양립하는지를 둘러싼 논쟁을 엮습니다. 줄기는 네 개입니다. 외재주의와 넓은 내용·좁은 내용의 문제를 정리하고(1), 양립론의 두 길인 데이빗슨과 버지를 읽은 뒤(2), 환원 논증(3)과 느린 전환 논증(4)이라는 두 유형의 비양립론을 각각 버지와 브루크너의 응답과 함께 읽고, 마지막으로 보증 전달과 권리부여 논의(5)로 회의주의와 이어지는 지점을 살핍니다. 심리철학연습(자기지식) 수업 필기(묶음 NJ2)의 외재주의 단원이 거의 전부이고, 게르틀러 항목 정리(묶음 X1)에서 보고시안의 딜레마 카드 하나를 가져왔습니다. 자기지식의 다른 이론들은 [[자기지식과 투명성 내성과 대면과 내감]]과 [[자기지식과 투명성 모런과 합리적 행위자성]]에서 이어집니다.

## 1. 외재주의와 넓은 내용
1. {42a}: 외재주의가 자기지식의 첫 문제를 만드는 경로
2. {42a1}: 외재주의를 수반 개념으로 정식화하는 읽기
3. {42a2}, {42a3}: 퍼트넘의 쌍둥이 지구와 버지의 관절염, 곧 환경과 언어 공동체에 기댄 두 사고실험
4. {42a4}, {42a5}: 환경 외재주의와 사회적 외재주의의 구분, 그리고 넓은 내용의 범위
5. {42a6}, {42a7}, {42a8}: 좁은 내용으로 특권적 접근을 대신하려는 시도와 그 시도가 막히는 지점
6. {22d}: 관계적으로 개별화되는 태도에 대한 접근을 겨누는 보고시안의 삼중 딜레마

## 2. 양립론: 데이빗슨과 버지
1. {42b}: 양립론과 두 유형의 비양립론이 부딪히는 판의 개요
2. {42b1}, {42b1a}, {42b1b}: 데이빗슨의 해석주의와, 외재주의가 상태의 소재를 바꾸지 않아도 남는 인식론의 물음
3. {42b1c}, {42b1d}: 말의 인과적 기원에서 일인칭 권위를 끌어내는 논증과 그 논증의 빈틈
4. {42b2}: 가능 조건을 몰라도 생각을 안다는 버지의 양립론
5. {42b2a}, {42b2b}: 반성적 생각의 자기검증성과 거친 오류의 불가능
6. {42b2c}: 느린 전환 시나리오의 제시

## 3. 비양립론 1: 환원 논증
1. {42b3}: 두 유형의 비양립론을 가르는 개요
2. {42b3a}, {42b3b}: 맥킨지의 귀류 논증과 개념적 함축 읽기
3. {42b3c}: 브루크너가 반개인주의의 특징적 테제로 돌려놓는 응답
4. {42b3d}, {42b3e}: 개념적 함축을 받아들여도 자기지식의 선험성이 남는다는 반론
5. {42b4}, {42b4a}: 보고시안의 귀류 논증과 마른 지구의 딜레마

## 4. 비양립론 2: 느린 전환 논증
1. {42b5}: 변별 능력 없는 주체가 자기 생각을 선험적으로 알 수 없다는 논증
2. {42b5a}: 지각 지식을 끌어들여 변별 요구를 거부하는 버지의 응답
3. {42b6}, {42b6a}: 보고시안의 기억 논증과 보존 기억을 통한 버지의 답
4. {42b6b}: 두 개념의 공존과 애매어 가정의 시험대

## 5. 권리부여와 보증 전달
1. {42c}: 버지와 라이트가 권리부여를 들여오는 서로 다른 길
2. {42c1}, {42c2}, {42c3}: 보증 폐쇄와 전달의 구분, 선결 조건의 뜻
3. {42c4}: 얼룩말 논증으로 보이는 지각적 보증의 선결 조건
4. {42c5}, {42c6}: 내용 착각에 같은 진단을 적용해 맥킨지 논증과 퍼트넘의 증명을 다루는 방식
