# 고전어

이 구조 노트는 '고전어' 클러스터의 개요입니다. 카드가 46장이어서 하위 구조 노트로 나누지 않았습니다. 자료는 Notion의 라틴어, 독일어, 그리스어 수업 필기(NZ1, 70번 줄기)와 플라우투스 강의 필기, 그리고 영진 님이 『Miles Gloriosus』를 읽고 쓴 글입니다. 줄기는 네 개이고, 진입 카드 {70}에서 시작해 문법 세 줄기(라틴어, 독일어, 그리스어)를 훑은 뒤 플라우투스 독해로 넘어가는 순서를 권합니다. 문법 카드는 수업 필기를 옮긴 것이고, 영진 voice 카드는 모두 플라우투스 독해 줄기에 있습니다.

## 1. 라틴어 문법
1. {70}: 문법 규칙 카드와 플라우투스 독해 카드의 두 갈래를 안내하는 진입 카드
2. {70a}, {70a1}, {70a2}, {70a3}, {70a4}: 형용사의 비교급과 최상급에서 시작해 불규칙 어간, -er형과 -ilis형, 부사, quam 비교로 이어짐
3. {70b}, {70b1}, {70b2}, {70b3}, {70b4}, {70b5}: 완료 어간을 기준으로 완료와 과거완료, 분사, 미래, 미래완료, 명령법을 차례로 정리함
4. {70c}, {70c1}, {70c2}: unus 계열 형용사의 변화에서 의문문과 관계대명사로 나아감
5. {70d}, {70d1}, {70d2}: in의 격 지배에서 전치사 없는 탈격과 도시 이름의 방향 표현으로 이어짐

## 2. 독일어 문법
1. {70e}, {70e1}: 규칙 동사 현재형 어미와 어간 모음이 바뀌는 예외
2. {70e2}, {70e3}: 동사 둘째 자리와 문장 끝 부정사로 이루어진 어순 규칙
3. {70e4}, {70e5}, {70e8}: 3격과 4격의 쓰임, es gibt, 재귀대명사를 격 체계로 묶음
4. {70e6}, {70e7}, {70e9}: 비교급, als와 so wie, all-의 변화

## 3. 그리스어 문법
1. {70h}: 조건문 네 유형을 법과 시제의 조합으로 분류하는 진입 카드
2. {70h1}, {70h2}, {70h3}: 일반, 반사실, 미래 조건문의 형태
3. {70h4}, {70h5}: 분사 조건과 양보절, αν과 εαν이 쓰이는 자리
4. {70h6}: 그리스어 문법과 작문 수업의 연습 10번과 11번
5. {70i}: 한정적 분사의 쓰임으로, 조건문 줄기의 분사 조건({70h4})과 이어짐

## 4. 플라우투스와 『Miles Gloriosus』
1. {70f}, {70f1}, {70f2}: 작가의 시대 배경, 신희극의 정형, 필기가 든 플라우투스의 특징
2. {70g}: 영진 님이 희곡을 앎과 무지와 진리의 개념에 얽힌 인식론적 희곡으로 읽는 논지
3. {70g1}, {70g2}: 알라존을 세우는 첫 장면과, 믿음 자체를 바꾸려는 팔라이스트리오의 작전
4. {70g3}, {70g4}, {70g5}: 스켈레드루스의 믿음의 책임, 소크라테스식 문답과 아포리아, 인식자와 발화자 지위의 포기
5. {70g6}: 루르키오 장면과 결말을 인식론적 독해로 설명할 수 있는지를 묻는 남은 물음

## 줄기를 가로지르는 실
- **비교**: {70a} → {70e6} → {70e7} (라틴어의 비교급 접미사가 독일어 -er, als와 so wie 구문과 짝을 이룸)
- **분사**: {70b2} → {70h4} → {70i} (라틴어 현재분사, 그리스어의 조건 분사, 한정적 분사로 이어짐)
- **조건과 미래**: {70b4} → {70h3} (라틴어 미래완료와 그리스어 미래 조건문이 앞서 끝나는 일과 가능성을 다룸)
- **격과 방향**: {70d} → {70e4} (라틴어 in의 탈격과 대격, 독일어 3격과 4격이 장소와 방향을 가름)
- **문법에서 희곡으로**: {70} → {70f} → {70g} (같은 필기 안에서 라틴어 수업과 플라우투스 강의가 이어짐)
- **앎과 믿음**: {70g} → {70g3} → {70g5} (믿음의 책임에서 인식자 지위의 포기로 나아감)

## 다른 구조 노트와 이어지는 곳
- [[인식론]]: {70g3}에서 스켈레드루스가 증거에 반응하는 믿음의 책임을 지킨다는 읽기가 증거와 앎을 묻는 {17j2}와 개념이 겹칩니다. 줄기 전체의 안내는 {62}입니다.
- [[증언 인식론]]: {70g5}의 발화자 지위는 근거 없는 수용을 묻는 {14}와 키워드 수준에서 이어집니다.
- [[영문학과 문학비평]]: {70g1}의 알라존과 {70g2}의 속임수가 이아고가 오델로의 앎을 바꾸는 {54a}, {54a2}와 비교됩니다. 영문학 줄기의 개관은 {54}입니다.
- [[고대철학]]: {70g4}의 소크라테스식 문답과 아포리아가 {48}, {49}의 소크라테스 논박과 비교됩니다. {70g4}는 진리를 향하는 문답과 지위를 포기하게 하는 문답을 구별합니다.

## 정리 후보
- {70a}와 {70e6}, {70e7}: 라틴어와 독일어의 비교급 카드이고 문법 범주가 같아 범주별 색인을 둘 때 묶을 수 있습니다.
- {70b2}, {70h4}, {70i}: 분사를 다루는 세 카드이고 언어가 달라 겹치지는 않으나 범주별로 묶을 수 있습니다.
- {70f}: 연대(기원전 254년, 240년, 215년)를 필기에 적힌 대로 옮겼고 외부 자료로 확인하지 않았습니다.

## 다른 클러스터로 가는 길
- {70g4} → {48c} ([[고대철학]]): 팔라이스트리오의 문답이 만드는 아포리아는 무지의 자각과 불만이 탐구를 일으킨다는 소크라테스적 조건의 사례이면서, 상대에게 지위를 포기하게 하는 쪽으로 쓰인다는 점에서 원형과 대조된다.
