# 개념 태그 지시

1. `_작업/연결/태그/어휘.md`(공통 개념 태그 294개)와 배정받은 꾸러미 `_작업/연결/태그/꾸러미/tN.md`를 한 메시지에서 동시에 Read로 읽습니다. 꾸러미에는 카드 290장 안팎의 번호, 클러스터, 제목(한 문장 주장)이 있습니다.
2. 카드마다 **어휘에 있는 태그만** 골라 붙입니다. 태그 이름은 어휘의 `- ` 뒤, 콜론 앞 글자를 그대로 씁니다(띄어쓰기·괄호 포함).
   - 카드의 주장이 실제로 다루는 개념·문제만 고릅니다. 제목에 낱말이 나온다는 이유만으로 고르지 않습니다.
   - 한 장에 1~3개, 꼭 맞는 것이 없으면 0개(빈칸)입니다. 억지로 채우지 않습니다.
   - 클러스터 이름과 같은 범주의 넓은 태그보다, 다른 클러스터 카드와도 만날 수 있는 구체적인 태그를 우선합니다.
3. 결과를 `_작업/연결/태그/결과/tN.md`에 한 번만 씁니다. 한 줄에 카드 하나, 형식은 `번호: 태그1; 태그2` 입니다. 다른 내용은 쓰지 않습니다.
4. 카드 파일과 다른 파일은 열지도 쓰지도 않습니다. 최종 답신은 태그를 붙인 카드 수와 빈칸 카드 수만 적습니다.
