# 보관함 운영 안내 (7단계)

영진 님이 이 보관함을 매일 쓰는 방법을 정리한 문서다. Claude는 같은 내용을 스킬(`묻기`, `점검`, `묶음작업`, `마무리`, `찾기`)로 따른다.

## 어디서 쓰는가

| 어디서 | 할 수 있는 일 | 위키가 쓰이는가 |
|---|---|---|
| PC의 Claude Code (보관함 폴더에서 `claude` 실행) | 질문, 자료 수집, 점검, 임베딩 계산까지 전부 | 쓰인다. 폴더에 들어가면 `CLAUDE.md`와 스킬을 자동으로 읽는다 |
| 웹·모바일의 Claude Code (claude.ai/code, Claude 앱의 Code) | 질문, 수집, 점검. 임베딩 계산만 PC | 쓰인다. 저장소 `Nukuriring/nukuriring`를 고르고 시작하면 세션 시작 훅이 검색 도구를 설치하고 기준 브랜치 상태를 알려 준다 |
| claude.ai 일반 채팅 | 보관함과 상관없는 대화 | 자동으로는 쓰이지 않는다. 일반 채팅은 이 폴더를 보지 못한다. 보관함 질문은 위 두 곳에서 한다 |
| Obsidian | 카드 읽기, 그래프, 대기열 대시보드(`_작업/대기열/00 대기열.md`) | 사람이 읽는 창이다 |

정리하면, 이 위키를 쓰려면 **Claude Code(PC든 웹·앱이든)에서 이 저장소를 열고 묻는다.** 휴대폰에서도 Claude 앱의 Code에서 같은 저장소로 세션을 열면 된다.

## 어떻게 묻는가 (`묻기` 스킬)
그냥 말로 물으면 된다. Claude가 색인과 구조 노트, 검색으로 카드를 찾고, 카드 링크와 voice(저자 주장 · 영진 님 입장 · Claude 해석)를 구분해 답한다.

- "증언 인식론에서 환원주의에 대한 가장 강한 반론을 보관함에서 찾아 줘"
- "칸트 역사철학과 이어지는 다른 클러스터 카드가 뭐가 있어?"
- "자유의지와 책임으로 LEET 지문을 짠다면 보관함에 어떤 대립 구도가 있어?"
- "지난번 질문 정리한 거 보여 줘" (`질문/` 폴더)

쓸 만한 답은 `질문/날짜 질문 요지.md`로 저장되고, 답에서 새 연결이 나오면 종합 카드 후보로 제안된다.

## 새 자료를 넣을 때 (`묶음작업` 스킬)
1. 자료(대화 내보내기, 노트, Notion 페이지)를 `_원자료/`에 넣거나 세션에 붙여 넣고 "이거 수집해 줘"라고 한다.
2. Claude가 겹침을 먼저 검색하고, 카드를 만들고, 검증하고, 연결을 걸고, 구조 노트에 넣고, 커밋한다.
3. 많으면 작업자를 병렬로 돌린다.

## 정기 점검 (`점검` 스킬)
- 주 1회 "점검해 줘". lint, 끊긴 링크, 검증 안 된 새 카드, 연결이 적은 카드, 구조 노트에 빠진 카드, 낡은 임베딩을 세어 `_작업/점검/날짜.md`로 남기고 할 일 세 가지를 알려 준다.
- 카드가 많이 바뀐 뒤(또는 한 달에 한 번) PC에서 임베딩을 갱신한다: `py -3.12 -P _작업/스크립트/embed.py .` (바뀐 카드만 다시 계산, 중간 저장).

## 지킬 것
- **기준 브랜치**: `claude/great-einstein-58fp2d`. PC에서는 `git pull`과 `git push`만 쓰면 된다(브랜치 연결 완료). 웹 세션은 시작할 때 이 브랜치를 받는다.
- **동시에 고치지 않기**: PC와 웹 세션이 같은 카드를 동시에 고치지 않는다. 한쪽에서 끝내고 push한 뒤 다른 쪽에서 pull한다.
- **Obsidian 닫기**: pull, 대량 반영 전에는 Obsidian을 닫는다.
- **카드 잠금**: 영진 님이 직접 고친 카드는 status를 `검토됨`이나 `다시씀`으로 바꾸면 Claude가 허락 없이 고치지 않는다.
- **Claude 제안 표시**: 연결 줄 끝의 `(제안: Claude)`는 Claude가 넣은 연결이라는 출처 표시다. 확인한 줄은 지워도 되고 그대로 둬도 된다.
